จำลองโมเดล kicked-Ising 127 ควอนตัมบิต

ในคู่มือนี้ เราใช้แพ็กเกจ pauli-prop เพื่อจำลองพลวัตเชิงเวลาของโมเดล kicked-Ising 127 ควอนตัมบิตบนแลตทิซ heavy-hex ด้วยคอมพิวเตอร์แบบคลาสสิก และประมาณค่าแมกนีไทเซชันต่อไซต์เดี่ยว ⟨Z62⟩\langle Z_{62} \rangle⟨Z62​⟩ แฮมิลโทเนียนที่พิจารณาคือ:

H=−J∑⟨i,j⟩ZiZj+h∑iXiH = -J\sum\limits_{\langle i,j \rangle} Z_iZ_j + h\sum\limits_iX_iH=−J⟨i,j⟩∑​Zi​Zj​+hi∑​Xi​

โดยที่ J>0J>0J>0 อธิบายการคับปลิงของสปินที่อยู่ใกล้กันที่สุด, i<ji<ji<j และ hhh คือสนามตามขวางส่วนกลาง การแยกส่วนแบบ Trotter อันดับหนึ่งของตัวดำเนินการที่วิวัฒน์ตามเวลาจะถูกสร้างเป็นควอนตัมเซอร์กิต UUU ตลอด 202020 ขั้นของ Trotter ค่าคงที่การคับปลิง JJJ จะถูกกำหนดเป็น J=−π2J=-\frac{\pi}{2}J=−2π​ ทำให้ UUU เป็น Clifford ทุกครั้งที่ hmod  π2=0h\mod\frac{\pi}{2}=0hmod2π​=0

ขั้นตอนการทำงาน:

  • สร้างควอนตัมเซอร์กิตที่สร้างโมเดล Ising แบบ Trotter

    • แปรค่า hhh ระหว่างจุด Clifford คือ 0.00.00.0 และ π2\frac{\pi}{2}2π​

  • เลือกไซต์ตรงกลางของแลตทิซ (ควอนตัมบิต 626262) และประมาณค่าแมกนีไทเซชันหลังผ่าน 202020 ขั้นของ Trotter สำหรับแต่ละเซอร์กิต

  • สังเกตแมกนีไทเซชันที่ลดลงจาก 1.01.01.0 ไปเป็น 0.00.00.0 เมื่อ hhh เคลื่อนจากจุด Clifford หนึ่งไปอีกจุดหนึ่ง

สร้างเซอร์กิต​

ก่อนอื่น เราใช้ FakeSherbrooke จาก qiskit-ibm-runtime เพื่อหาดัชนีขอบของ coupling map ของ QPU Eagle 127 ควอนตัมบิต เมื่อได้ดัชนีขอบแล้ว เราสร้างเซอร์กิต Trotter สำหรับค่า hhh ต่าง ๆ ที่ต้องการจำลอง เซอร์กิตเหล่านี้จะสร้าง Trotterization อันดับหนึ่งของแฮมิลโทเนียนโดยใช้ 20 ขั้นของ Trotter และเกต 5420 เกต

import numpy as np
from qiskit import QuantumCircuit
from qiskit_ibm_runtime.fake_provider import FakeSherbrooke

# Get the edges in the device coupling map
backend = FakeSherbrooke()
edges = backend.coupling_map.get_edges()

# Num Trotter steps
num_steps = 20

# Create Trotter circuits with varying global fields
hs = [i * np.pi / 32 for i in range(17)]
circuits = []
for h in hs:
    circuit = QuantumCircuit(backend.num_qubits)
    for _ in range(num_steps):
        circuit.rx(h, [i for i in range(backend.num_qubits)])
        for edge in edges:
            circuit.rzz(-np.pi / 2, edge[0], edge[1])
    circuits.append(circuit)

จำลองพลวัตเชิงเวลาด้วย Pauli propagation​

ถัดไป เราระบุออบเซอร์เวเบิล OOO ที่ต้องการวัด ในกรณีนี้ เราประมาณค่า ⟨Z62⟩\langle Z_{62} \rangle⟨Z62​⟩

เพื่อศึกษาแมกนีไทเซชันระหว่างจุด Clifford เราแพร็อพาเกต OOO ไปยังจุดเริ่มต้นของเซอร์กิต UUU โดยประมาณ ได้ออบเซอร์เวเบิลใหม่ O′≈U†OUO^\prime \approx U^{\dagger}OUO′≈U†OU

ระหว่างการแพร็อพาเกต จำนวนพจน์ในออบเซอร์เวเบิลที่วิวัฒน์จะเพิ่มขึ้นแบบเอ็กซ์โพเนนเชียลตามจำนวนเกต จึงมักจำเป็นต้องจำกัดขนาดที่มันจะเติบโตได้ ในที่นี้ เราจำกัดจำนวนพจน์ใน O′O^\primeO′ ไว้ที่ 10510^5105 และตัดพจน์ที่มีสัมประสิทธิ์น้อยกว่า 10−510^{-5}10−5 ทิ้ง การตัดพจน์ทำให้เกิดความคลาดเคลื่อนบางส่วน เมื่อได้ O′O^\primeO′ แล้ว เราก็สามารถประมาณค่าคาดหมาย ⟨0∣U†OU∣0⟩=⟨0∣O′∣0⟩\langle0|U^{\dagger}OU|0\rangle = \langle0|O^\prime|0\rangle⟨0∣U†OU∣0⟩=⟨0∣O′∣0⟩ ได้อย่างง่ายดาย โดยรวมสัมประสิทธิ์ของพจน์แนวทแยงใน O′O^\primeO′ (พจน์ที่ประกอบด้วย I หรือ Z บนทุกควอนตัมบิตเท่านั้น)

เรากำหนด frame='h' เพื่อระบุว่าต้องการวิวัฒน์ออบเซอร์เวเบิลในกรอบ Heisenberg (U†OUU^{\dagger}OUU†OU) ใช้ frame=s สำหรับวิวัฒนาการแบบ Schrödinger (UOU†UOU^{\dagger}UOU†)

import time

from pauli_prop import propagate_through_circuit
from qiskit.quantum_info import Pauli, SparsePauliOp

# Z_62 observable
id_pauli = Pauli("I" * backend.num_qubits)
observable = SparsePauliOp(id_pauli.dot(Pauli("Z"), [62]))

# Estimate the single-site magnetization for varying magnetic fields
times = []
approx_evs = []
for circuit in circuits:
    st = time.perf_counter()
    propagated_obs = propagate_through_circuit(
        observable, circuit, 100_000, 1e-5, frame="h"
    )[0]
    times.append(time.perf_counter() - st)
    approx_evs.append(
        float(
            propagated_obs.coeffs[~propagated_obs.paulis.x.any(axis=1)].sum()
        )
    )
print(f"Finished {len(circuits)} simulations in {sum(times):.0f}s")
Finished 17 simulations in 494s

แสดงผลเป็นภาพ​

สุดท้าย เราพล็อตแมกนีไทเซชันเป็นฟังก์ชันของ hhh เมื่อ h=0h=0h=0 เซอร์กิตจะไม่กระทบสถานะเริ่มต้นในฐานการคำนวณ และเรารู้ว่า ⟨0∣O∣0⟩=1.0\langle0|O|0\rangle = 1.0⟨0∣O∣0⟩=1.0 เมื่อ hhh ห่างจาก 000 มากขึ้น แมกนีไทเซชันจะลดลงแบบเอกภาพจนกระทั่ง hhh ถึงมุม Clifford ถัดไป π2\frac{\pi}{2}2π​ และแมกนีไทเซชันลู่เข้าสู่ 000

import matplotlib.pyplot as plt

plt.xlabel(r"$R_x$ angle $\theta_h$")
plt.ylabel(r"$\langle Z_{62} \rangle$")
plt.plot(hs, approx_evs, marker="o")
