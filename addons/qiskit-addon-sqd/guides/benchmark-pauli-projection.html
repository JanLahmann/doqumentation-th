เบนช์มาร์กการโปรเจกต์ตัวดำเนินการ Pauli

การกระทำของ Pauli string บนสถานะฐานการคำนวณ​

การกระทำของ Pauli string บนสถานะฐานการคำนวณค่อนข้างตรงไปตรงมา และให้ผลเป็นสถานะฐานการคำนวณเพียงสถานะเดียว นี่เป็นผลโดยตรงจากโครงสร้างของเมทริกซ์ Pauli ซึ่งมีสมาชิกที่ไม่เป็นศูนย์เพียงตัวเดียวในแต่ละแถว ดังนั้น การกระทำของมันต่อ qubit คือ:

σx∣0⟩=∣1⟩\sigma_x |0 \rangle = |1 \rangleσx​∣0⟩=∣1⟩ σx∣1⟩=∣0⟩\sigma_x |1 \rangle = |0 \rangleσx​∣1⟩=∣0⟩
σy∣0⟩=i∣1⟩\sigma_y |0 \rangle = i|1 \rangleσy​∣0⟩=i∣1⟩ σy∣1⟩=−i∣0⟩\sigma_y |1 \rangle = -i|0 \rangleσy​∣1⟩=−i∣0⟩
σz∣0⟩=∣0⟩\sigma_z |0 \rangle = |0 \rangleσz​∣0⟩=∣0⟩ σz∣1⟩=−∣1⟩\sigma_z |1 \rangle = -|1 \rangleσz​∣1⟩=−∣1⟩
I∣0⟩=∣0⟩I |0 \rangle = |0 \rangleI∣0⟩=∣0⟩ I∣1⟩=∣1⟩I |1 \rangle = |1 \rangleI∣1⟩=∣1⟩

แต่ละบิตบน bitstring ที่ใช้ระบุฐานการคำนวณจะถูกกำกับด้วย x∈{0,1}x \in \{0, 1 \}x∈{0,1} เพื่อให้การimplement เบาที่สุดเท่าที่จะทำได้ เราจะ แทน bitstring ด้วยตัวแปร bool: 0→False0\rightarrow \textrm{False}0→False และ 1→True1\rightarrow \textrm{True}1→True

เพื่อแทนการกระทำของตัวดำเนินการ Pauli แต่ละตัวบนสถานะฐานการคำนวณ เราจะกำหนดตัวแปรสามตัวให้มัน: diag, sign, imag

  • diag ระบุว่าตัวดำเนินการเป็นเมทริกซ์แนวทแยงหรือไม่:

    • diag(I)=True\textrm{diag}(I) = \textrm{True}diag(I)=True

    • diag(σx)=False\textrm{diag}(\sigma_x) = \textrm{False}diag(σx​)=False

    • diag(σy)=False\textrm{diag}(\sigma_y) = \textrm{False}diag(σy​)=False

    • diag(σz)=True\textrm{diag}(\sigma_z) = \textrm{True}diag(σz​)=True

  • sign ระบุว่ามีการเปลี่ยนเครื่องหมายในสมาชิกเมทริกซ์ที่เชื่อมกับ 0 หรือ 1 หรือไม่:

    • sign(I)=False\textrm{sign}(I) = \textrm{False}sign(I)=False

    • sign(σx)=False\textrm{sign}(\sigma_x) = \textrm{False}sign(σx​)=False

    • sign(σy)=True\textrm{sign}(\sigma_y) = \textrm{True}sign(σy​)=True

    • sign(σz)=True\textrm{sign}(\sigma_z) = \textrm{True}sign(σz​)=True

  • imag ระบุว่าสมาชิกเมทริกซ์มีส่วนที่เป็นจำนวนเชิงซ้อนหรือไม่:

    • imag(I)=False\textrm{imag}(I) = \textrm{False}imag(I)=False

    • imag(σx)=False\textrm{imag}(\sigma_x) = \textrm{False}imag(σx​)=False

    • imag(σy)=True\textrm{imag}(\sigma_y) = \textrm{True}imag(σy​)=True

    • imag(σz)=False\textrm{imag}(\sigma_z) = \textrm{False}imag(σz​)=False

เราใช้ σ∈{I,σx,σyσz}\sigma \in \{ I, \sigma_x, \sigma_y \sigma_z\}σ∈{I,σx​,σy​σz​} แทนตัวดำเนินการ Pauli ใด ๆ การกระทำของตัวดำเนินการ Pauli บนสถานะฐานการคำนวณ จึงแทนได้ด้วยการดำเนินการเชิงตรรกะ:

σ∣x⟩=∣x==diag(σ)⟩(−1)x and sign(σ)(i)imag(σ).\sigma |x \rangle = |x == \textrm{diag}(\sigma) \rangle (-1)^{x\textrm{ and sign}(\sigma)} (i)^{\textrm{imag}(\sigma)}.σ∣x⟩=∣x==diag(σ)⟩(−1)x and sign(σ)(i)imag(σ).

def connected_element_and_amplitude_bool(
    x: bool, diag: bool, sign: bool, imag: bool
) -> tuple[bool, complex]:
    """
    Finds the connected element to computational basis state |x> under
    the action of the Pauli operator represented by (diag, sign, imag).

    Args:
        x: Value of the bit, either True or False.
        diag: Whether the Pauli operator is diagonal (I, Z)
        sigma: Whether the Pauli operator's rows differ in sign (Y, Z)
        imag: Whether the Pauli operator is purely imaginary (Y)

    Returns:
        A length-2 tuple:
            - The connected element to x, either False or True
            - The matrix element
    """
    return x == diag, (-1) ** (x and sign) * (1j) ** (imag)

sigma_indices = [0, 1, 2, 3]
sigma_string = ["I", "SX", "SZ", "SY"]
sigma_diag = [True, False, True, False]
sigma_sign = [False, False, True, True]
sigma_imag = [False, False, False, True]
qubit_values = [False, True]

for xi in sigma_indices:
    print("-------------------")
    print(sigma_string[xi])
    for x in qubit_values:
        x_p, matrix_element = connected_element_and_amplitude_bool(
            x, sigma_diag[xi], sigma_sign[xi], sigma_imag[xi]
        )
        print(
            "|"
            + str(x)
            + "> -->  |"
            + str(x_p)
            + ">    ME:"
            + str(matrix_element)
        )

เราสร้าง bitstring จำนวนมาก (50 ล้าน) สำหรับระบบ 40 qubit:

import numpy as np
from qiskit_addon_sqd.qubit import sort_and_remove_duplicates

rand_seed = 22
np.random.seed(rand_seed)

# Generate some random bitstrings for testing

def random_bitstrings(n_samples, n_qubits):
    return (
        np.round(np.random.rand(n_samples, n_qubits))
        .astype("int")
        .astype("bool")
    )

n_qubits = 40
bts_matrix = random_bitstrings(50_000_000, n_qubits)

# We need to sort the bitstrings and only keep the unique ones
# NOTE: It is essential for the projection code to have the bitstrings sorted!
bts_matrix = sort_and_remove_duplicates(bts_matrix).astype("bool")

# Final subspace dimension after getting rid of duplicated bitstrings
d = bts_matrix.shape[0]

print("Total number of unique bitstrings: " + str(d))
Total number of unique bitstrings: 49998839

เบนช์มาร์กฟังก์ชันการโปรเจกต์ Pauli ของ SQD​

Pauli string ที่พิจารณาคือ σz⊗...⊗σz\sigma_z \otimes ... \otimes \sigma_zσz​⊗...⊗σz​

เราพิจารณามิติของซับสเปซที่ต่างกันโดยการสไลซ์เมทริกซ์ของ bitstring เราจับเวลาการโปรเจกต์ซับสเปซสำหรับขนาดซับสเปซที่ต่างกัน

import time

from qiskit.quantum_info import Pauli
from qiskit_addon_sqd.qubit import matrix_elements_from_pauli

pauli = Pauli("Z" * n_qubits)

# Different subspace sizes to test
d_list = np.linspace(d / 1000, d, 20).astype("int")

# To store the walltime
time_array = np.zeros(20)

for i in range(20):
    int_bts_matrix = bts_matrix[: d_list[i], :]
    time_1 = time.time()
    _ = matrix_elements_from_pauli(int_bts_matrix, pauli)
    time_array[i] = time.time() - time_1
    print(f"Iteration {i} took {round(time_array[i], 6)}s")
