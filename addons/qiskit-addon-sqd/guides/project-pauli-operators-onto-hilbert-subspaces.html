โปรเจกต์ตัวดำเนินการ Pauli ลงปริภูมิย่อยของฮิลเบิร์ต

เราแสดงวิธีต่าง ๆ ในการโปรเจกต์ผลรวมเชิงเส้นแบบถ่วงน้ำหนักของ Pauli string ลงในปริภูมิย่อยที่กำหนดโดยเซตย่อยขนาด ddd ของสถานะฐานการคำนวณ ตัวดำเนินการที่ ถูกโปรเจกต์จะถูกเก็บเป็น scipy.sparse.coo_matrix ขนาด d×dd \times dd×d

เป็นตัวอย่าง เราพิจารณาแฮมิลโทเนียนของแบบจำลองไฮเซนเบิร์กหนึ่งมิติที่มีเงื่อนไขขอบเขตเป็นคาบ และสปิน L=22L = 22L=22 ตัว:

H=∑⟨i,j⟩(σixσjx+σiyσjy+σizσjz).H = \sum_{\langle i, j \rangle}\left( \sigma^x_i\sigma^x_j + \sigma^y_i\sigma^y_j + \sigma^z_i\sigma^z_j \right).H=⟨i,j⟩∑​(σix​σjx​+σiy​σjy​+σiz​σjz​).

แพ็กเกจนี้มีเครื่องมือสองอย่างสำหรับทำการโปรเจกต์นี้:

  • qiskit_addon_sqd.qubit.matrix_elements_from_pauli(): ฟังก์ชันระดับล่างที่คืนค่าสมาชิกเมทริกซ์ที่ไม่เป็นศูนย์ของ Pauli string และดัชนีที่สอดคล้องกันของสมาชิกที่ไม่เป็นศูนย์

  • qiskit_addon_sqd.qubit.project_operator_to_subspace(): a higher-level function that directly returns a scipy.sparse matrix.

คู่มือนี้แสดงวิธีใช้เครื่องมือทั้งสองนี้เพื่อสร้างตัวดำเนินการแบบเบาบางตัวเดียวกัน

การนิยามปริภูมิย่อย​

ในตัวอย่างนี้ เราสร้างบิตสตริงสุ่มความยาว 22 เพื่อให้ฟังก์ชันการโปรเจกต์ ทำงานได้ตามที่คาด บิตสตริงที่กำหนดปริภูมิย่อยต้องไม่ซ้ำกันและเรียงลำดับจากน้อยไปมาก ตามการแทนค่าเป็นจำนวนเต็มไม่มีเครื่องหมาย

import numpy as np
from qiskit_addon_sqd.qubit import sort_and_remove_duplicates

num_spins = 22
rand_seed = 22
np.random.seed(rand_seed)

def random_bitstrings(n_samples, n_qubits):
    return (
        np.round(np.random.rand(n_samples, n_qubits))
        .astype("int")
        .astype("bool")
    )

bitstring_matrix = random_bitstrings(50_000, num_spins)

# NOTE: It is essential for the projection code to have the bitstrings sorted!
bitstring_matrix = sort_and_remove_duplicates(bitstring_matrix)

print("Subspace dimension: " + str(bitstring_matrix.shape[0]))
print("Full Hilbert space dimension: " + str(2**num_spins))

from qiskit_addon_sqd.qubit import matrix_elements_from_pauli
from scipy.sparse import coo_matrix

d = bitstring_matrix.shape[0]

# Initialize the coo_matrix object
operator_from_matrix_elements = coo_matrix((d, d), dtype="complex128")

for pauli in hamiltonian.paulis:
    matrix_elements, row_indices, col_indices = matrix_elements_from_pauli(
        bitstring_matrix, pauli
    )
    operator_from_matrix_elements += coo_matrix(
        (matrix_elements, (row_indices, col_indices)), (d, d)
    )
