ทำความเข้าใจตัวเลือกเปลือกเปิดเทียบกับเปลือกปิด และผลต่อการสร้างปริภูมิย่อย

ในคู่มือนี้ เราจะแสดงวิธีเลือกมิติของปริภูมิย่อยในแพ็กเกจ qiskit_addon_sqd เพื่อประมวลผลภายหลังตัวอย่างควอนตัมโดยใช้ เทคนิคการกู้คืนคอนฟิกูเรชันแบบสอดคล้องในตัวเอง

ที่สำคัญกว่านั้น คู่มือนี้ยังชี้ให้เห็นความแตกต่างบางอย่างในพฤติกรรมการสร้างปริภูมิย่อยเมื่อรันในโหมด open_shell = False หรือ open_shell = True:

  • open_shell = False ใช้ได้เฉพาะเมื่อจำนวนอิเล็กตรอนสปินขึ้นและสปินลงเท่ากัน

  • ต้องใช้ open_shell = True เมื่อจำนวนอิเล็กตรอนสปินขึ้นและสปินลงต่างกัน และใช้ได้เช่นกันเมื่อจำนวนอิเล็กตรอนสปินขึ้นและสปินลงเท่ากัน อย่างไรก็ตาม ในกรณีหลังนี้ ขนาดของปริภูมิย่อยที่สร้างขึ้นระหว่าง open_shell = False และ open_shell = True จะต่างกัน ตามที่อธิบายในคู่มือนี้

หมายเหตุ: การจัดการคอนฟิกูเรชันอิเล็กตรอน (บิตสตริง) บางอย่างในแพ็กเกจนี้มีเป้าหมายเพื่อรักษาสมมาตรสปินรวม S2S^2S2 ตัวแก้ Selected Configuration Interaction (SCI) มาตรฐานไม่สามารถบังคับการอนุรักษ์ S2S^2S2 ได้อย่างแน่นอน จึงทำได้โดยประมาณผ่านตัวคูณลากรองจ์

การเลือกคอนฟิกูเรชันอิเล็กตรอนที่ป้อนให้ตัวแก้สถานะเฉพาะก็มีผลอย่างมากต่อการอนุรักษ์สปินเช่นกัน ตัวอย่างเช่น ในระบบ (อิเล็กตรอน 2 ตัว ออร์บิทัล 2 ตัว) เราอาจสุ่มได้คอนฟิกูเรชัน ∣1001⟩|1001\rangle∣1001⟩ (ซึ่งมีการกระตุ้นสปินขึ้นหนึ่งครั้งจากสถานะ RHF ∣0101⟩|0101\rangle∣0101⟩) ซึ่งเป็นผลรวมเชิงเส้นของสถานะซิงเกลต์และทริปเลตเปลือกเปิด คือ (∣1001⟩±∣0110⟩)/2(|1001\rangle ± |0110\rangle) /\sqrt{2}(∣1001⟩±∣0110⟩)/2​ ตามลำดับ ถ้าไม่ได้สุ่มคอนฟิกูเรชัน |0110⟩ ก็จะสร้างฟังก์ชันเฉพาะของสปินรวมไม่ได้เลยทั้งสองแบบ นำไปสู่การปนเปื้อนของสปินหรือความซ้ำซ้อน (คอนฟิกูเรชัน |1001⟩ ถูกใช้ในการคำนวณ CI แต่มีสัมประสิทธิ์ 0 ในเวกเตอร์ CI) เมื่อคอมพิวเตอร์ควอนตัมสร้างตัวอย่างเดียวคือ ∣1001⟩|1001\rangle∣1001⟩ แพ็กเกจ sqd จัดการสถานการณ์นี้ดังนี้:

  • open_shell = False:

    1. บิตสตริง 100110011001 ถูกแบ่งครึ่ง แทนคอนฟิกูเรชันสปินขึ้นและสปินลง: 101010 (ขึ้น) และ 010101 (ลง)

    2. สร้างรายการของคอนฟิกูเรชันที่มีสปินโพลาไรซ์และไม่ซ้ำกัน: U=[01,10]\mathcal{U} = [01, 10]U=[01,10]

    3. จากนั้นเราพิจารณาการจับคู่ที่เป็นไปได้ทั้งหมดของสมาชิกใน U\mathcal{U}U เพื่อสร้างเบซิส: {∣0101⟩,∣0110⟩,∣1001⟩,∣1010⟩}\left \{ |0101\rangle, |0110\rangle , |1001\rangle , |1010\rangle \right \}{∣0101⟩,∣0110⟩,∣1001⟩,∣1010⟩} ซึ่งมีทั้งสถานะซิงเกลต์และทริปเลต

  • open_shell = True:

    1. ต่างจากกรณี open_shell = False เราไม่รวมครึ่งของบิตสตริงเพื่อสร้างเบซิส

ตัวอย่างนี้แสดงวิธีจัดการบิตสตริงในระบบ (อิเล็กตรอน 2 ตัว ออร์บิทัล 4 ตัว)

ระบุพจนานุกรมของผลการวัดด้วยตนเอง:

counts_dict = {
    "00010010": 1 / 2.0 - 0.01,
    "01001000": 1 / 2.0 - 0.01,
    "00010001": 0.02,
}

แปลงจำนวนนับ dict เป็นเมทริกซ์บิตสตริงและอาร์เรย์ความน่าจะเป็นสำหรับการประมวลผลภายหลัง:

from qiskit_addon_sqd.counts import counts_to_arrays

# Convert counts into bitstring and probability arrays
bitstring_matrix_full, probs_arr_full = counts_to_arrays(counts_dict)
print(bitstring_matrix_full)
print(probs_arr_full)

 [False  True False False  True False False False]
 [False False False  True False False False  True]]
[0.49 0.49 0.02]

สุ่มตัวอย่างย่อยหนึ่งแบตช์ขนาดสอง:

  • n_batches = 1: จำนวนแบตช์ของคอนฟิกูเรชันที่ใช้ในการเรียกตัวแก้สถานะเฉพาะแต่ละครั้ง

  • samples_per_batch = 2: จำนวนคอนฟิกูเรชันที่ไม่ซ้ำกันที่จะรวมในแต่ละแบตช์

from qiskit_addon_sqd.subsampling import (
    postselect_by_hamming_right_and_left,
    subsample,
)

n_batches = 1
samples_per_batch = 2

# seed for random number generator
rand_seed = 48

# Post-select the configurations with the correct Hamming weight on each half
bitstring_matrix_postsel, probs_arr_postsel = (
    postselect_by_hamming_right_and_left(
        bitstring_matrix_full,
        probs_arr_full,
        hamming_right=num_elec_a,
        hamming_left=num_elec_b,
    )
)

# Generate the batches
batches = subsample(
    bitstring_matrix_postsel,
    probs_arr_postsel,
    samples_per_batch,
    n_batches,
    rand_seed=rand_seed,
)

print(batches[0])
[[False False False  True False False  True False]
 [False  True False False  True False False False]]

รับการแทนค่าเลขฐานสิบของบิตสตริงสปินขึ้นและสปินลงที่ตัวแก้สถานะเฉพาะใช้

สมาชิกตัวแรกในทูเพิลสอดคล้องกับการแทนค่าเลขฐานสิบของคอนฟิกูเรชันสปินขึ้น ส่วนสมาชิกตัวที่สองในทูเพิลสอดคล้องกับการแทนค่าเลขฐานสิบของคอนฟิกูเรชันสปินลง:

from qiskit_addon_sqd.fermion import bitstring_matrix_to_ci_strs

ci_strs = bitstring_matrix_to_ci_strs(batches[0], open_shell=open_shell)
print(ci_strs)
(array([1, 2, 4, 8], dtype=int64), array([1, 2, 4, 8], dtype=int64))

สังเกตว่า แม้จำนวนตัวอย่างต่อแบตช์เป็นสอง และบิตสตริงที่สุ่มได้คือ 000100100001001000010010 และ 010010000100100001001000 แต่จะมีการสร้างคอนฟิกูเรชันอิเล็กตรอนสี่แบบต่อสปินชนิดหนึ่ง ในกรณีนี้ เซตของคอนฟิกูเรชันสปินโพลาไรซ์ที่ไม่ซ้ำกันคือ:

U={0001,0010,0100,1000}\mathcal{U} = \{ 0001, 0010, 0100, 1000 \}U={0001,0010,0100,1000}

ซึ่งการแทนค่าเลขฐานสิบคือ

U10={1,2,4,8}\mathcal{U}_{10} = \{ 1, 2, 4, 8 \}U10​={1,2,4,8}
