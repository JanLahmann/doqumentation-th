Addon utilities
สร้าง workflow ที่ขับเคลื่อนด้วย addon ได้เร็วขึ้นด้วยชุดฟังก์ชันสำหรับสร้าง Hamiltonian สร้าง Trotter time-evolution circuit และใช้ความสามารถด้าน error mitigation ล่าสุด

AI-QEM by LTM
ลดสัญญาณรบกวนของค่าคาดหวังจาก Estimator ด้วยโมเดล AI โดยไม่ใช้เวลา QPU เพิ่มเติม

AQC-Tensor
สร้าง circuit ที่มี fidelity สูงและ depth ลดลง โดยใช้ approximate quantum compilation ร่วมกับ tensor network

Qiskit Bosons
ทำงานกับระบบ boson โดยใช้โครงสร้างข้อมูลสำหรับ bosonic operator และ circuit รวมถึง framework สำหรับการเข้ารหัส boson เป็น qubit และการสังเคราะห์ circuit ผ่านการผสานรวมกับ Qiskit Transpiler
ดูเอกสาร →
Constrained Quantum Optimizer by Aqarios
แก้ปัญหา constrained binary optimization บนฮาร์ดแวร์ IBM Quantum โดยใช้ iterative warm-starting QAOA ร่วมกับ XY-mixer
ดูเอกสาร →
Dynamics Simulator by Q-CTRL
จำลองการวิวัฒนาการตามเวลาของโมเดล quantum many-body และประมาณ time trace ของค่าคาดหวัง พร้อมการกดทอนข้อผิดพลาดอัตโนมัติ
ดูเอกสาร →
Qiskit Fermions
ทำงานกับระบบ fermion โดยใช้โครงสร้างข้อมูลสำหรับ fermionic operator และ circuit รวมถึง framework สำหรับการเข้ารหัส fermion เป็น qubit และการสังเคราะห์ circuit ผ่านการผสานรวมกับ Qiskit Transpiler
ดูเอกสาร →
ffsim
จำลอง fermionic quantum circuit ที่คงค่าจำนวนอนุภาคและองค์ประกอบ z ของสปิน

Qiskit Fulqrum
ชุดเครื่องมือสำหรับแก้ปัญหา eigenproblem ของ Hamiltonian subspace ขนาดใหญ่ทั่วไป

HI-VQE Chemistry by Qunova Computing

IBM Quantum Compute

Iskay Quantum Optimizer by Kipu Quantum

Managed workflows
deploy quantum-classical workflow ของคุณเองไปยัง IBM Quantum Functions และรันบน managed classical compute

Matrix-free Measurement Mitigation (M3)
ลดข้อผิดพลาดจากการวัดโดยประมวลผลใน subspace ที่ลดขนาดซึ่งกำหนดจาก bitstring ที่มีสัญญาณรบกวน
ดูเอกสาร →
Qiskit Mitigation
สร้าง error mitigation pipeline แบบกำหนดเองด้วยเทคนิคต่าง ๆ เช่น Probabilistic Error Cancellation (PEC), Zero-Noise Extrapolation (ZNE), Twirled Readout Error eXtinction (TREX) และ Probabilistic Error Amplification (PEA) โดยตรงด้วย Samplomatic
ดูเอกสาร →
Multi-product formulas
ลด Trotter error ของพลวัต Hamiltonian ผ่านการรวมแบบถ่วงน้ำหนักของการรัน circuit หลายครั้ง
ดูเอกสาร →
Qiskit noise learning
สร้างการทดลองระบุลักษณะสัญญาณรบกวนควอนตัมแบบอิงการสุ่ม และ pipeline วิเคราะห์ด้วยการ fit โมเดล
ดูเอกสาร →
Operator backpropagation
ลด circuit depth ในการประมาณค่าคาดหวังโดยการ backpropagate observable ผ่าน circuit
ดูเอกสาร →
Optimization mapper
สร้างโมเดลปัญหา optimization และ map ไปเป็นรูปแบบที่คอมพิวเตอร์ควอนตัมเข้าใจได้
ดูเอกสาร →
Optimization Solver by Q-CTRL Fire Opal
เริ่มแก้ปัญหา optimization ระดับ utility-scale ด้วย Fire Opal Optimization Solver ของ Q-CTRL
ดูเอกสาร →
Orbit by Quantum Elements
ใช้ dynamical decoupling ที่มี overhead ต่ำเพื่อปรับปรุงประสิทธิภาพของ circuit บนฮาร์ดแวร์ควอนตัมของ IBM
ดูเอกสาร →
Parity Twine Optimizer by ParityQC
แก้ปัญหา optimization บนคอมพิวเตอร์ควอนตัมด้วย Parity Twine ซึ่งลดจำนวน gate และ circuit depth ให้น้อยที่สุด
ดูเอกสาร →
Pauli propagation
framework สำหรับประมาณการวิวัฒนาการของ operator ซึ่งใช้จำลองค่าคาดหวังและนำเทคนิค error mitigation มาใช้ เช่น propagated noise absorption (PNA) และ shaded lightcones
ดูเอกสาร →
Qiskit Paulice
เพิ่ม fidelity ของการแจกแจงที่สุ่มตัวอย่างโดยใช้ Pauli check ที่มีประสิทธิภาพต่อฮาร์ดแวร์ซึ่งอิงกับ spacetime code
ดูเอกสาร →
Performance Management by Q-CTRL
ใช้การกดทอนข้อผิดพลาดอัตโนมัติด้วย Fire Opal Performance Management ของ Q-CTRL
ดูเอกสาร →
Propagated noise absorption (PNA)
เทคนิคลดข้อผิดพลาดในค่าคาดหวังของ observable โดย 'absorb' ค่าผกผันของ noise channel ที่เรียนรู้ได้เข้าไปใน observable โดยใช้ Pauli propagation
ดูเอกสาร →
QESEM by Qedma
สร้างค่าคาดหวังแบบ unbiased ที่มีความแปรปรวนและ resource overhead ต่ำกว่า สำหรับ circuit ที่มี gate แบบเศษส่วนหรือแบบ parameterized และ observable ที่มี weight สูง
ดูเอกสาร →
Qiskit SDK
สร้าง ปรับให้เหมาะสม และรันโปรแกรมควอนตัมด้วยซอฟต์แวร์โอเพนซอร์สสำหรับทำงานกับ quantum circuit และรันบนฮาร์ดแวร์ควอนตัม
ดูเอกสาร →
QUICK-PDE by ColibriTD
ใช้การคำนวณควอนตัมกับ PDE แบบ multi-physics เตรียม simulation workflow สำหรับฮาร์ดแวร์ควอนตัม พร้อมควบคุมพารามิเตอร์การสร้างแบบจำลองทั้งด้านควอนตัมและด้านฟิสิกส์ได้อย่างเต็มที่
ดูเอกสาร →
Quantum Portfolio Optimizer by Global Data Quantum
แก้ปัญหา optimization ทางการเงิน เพื่อหากลยุทธ์พอร์ตโฟลิโอที่เหมาะสมที่สุดตามช่วงเวลา โดยลดความเสี่ยงและเพิ่มผลตอบแทนให้สูงสุด
ดูเอกสาร →
Rimay Quantum Feature Extraction by Kipu Quantum
สกัด feature ที่ผ่านการแปลงด้วยควอนตัมสำหรับ pipeline machine learning แบบคลาสสิก โดยใช้ digitized counterdiabatic evolution ของ spin-glass Hamiltonian
ดูเอกสาร →
Sample-based quantum diagonalization (SQD)
ประมาณ spectrum ของ quantum Hamiltonian โดยประมวลผลตัวอย่างที่มีสัญญาณรบกวนและทำ diagonalization ใน subspace ที่ลดขนาด
ดูเอกสาร →
Samplomatic
รองรับการสุ่มตัวอย่างแบบกำหนดเองสำหรับ directed execution model โดยใช้ circuit box ที่มี annotation เพื่อบันทึกเจตนาการออกแบบ เช่น twirling และการฉีดสัญญาณรบกวนฝั่งไคลเอนต์
ดูเอกสาร →
Selected Basis Diagonalization (SBD) eigensolver
SBD (Selected Basis Diagonalization) เป็นไลบรารีประสิทธิภาพสูงสำหรับการคำนวณเคมีควอนตัม
อ่านเอกสาร →
Shaded lightcones (SLC)
ลด sampling overhead ของ probabilistic error cancellation (PEC) โดยตัด term ของ noise model ที่มีผลต่อการประมาณค่า observable น้อยออก
ดูเอกสาร →
Singularity Machine Learning by Multiverse Computing
ปรับปรุงความแม่นยำและประสิทธิภาพการคำนวณของ workflow การจำแนกประเภทด้วย machine learning แบบคลาสสิก โดยใช้ quantum optimization ที่รันบนฮาร์ดแวร์ของ IBM
ดูเอกสาร →
SQD for HPC
การimplement SQD addon ที่พร้อมใช้กับ HPC เขียนด้วยมาตรฐาน C++17 สมัยใหม่ และออกแบบมาเพื่อรองรับ workflow และแอปพลิเคชัน HPC
ดูเอกสาร →
SQOA Solver by JIJ
แก้ปัญหาการหาค่าเหมาะที่สุดเชิงจัดหมู่ขนาดใหญ่ที่เขียนในรูป QUBO โดยผสานการหาค่าเหมาะที่สุดแบบ quantum random access เข้ากับ sample-based quantum diagonalization และการประมวลผลหลังการวัดแบบคลาสสิก
ดูเอกสาร →
Tensor-network error mitigation by Algorithmiq
ลด measurement overhead และความแปรปรวนสำหรับงานที่มี observable น้ำหนักต่ำและ circuit ที่ไม่มีลูป โดยให้ผลดีกว่า baseline การลดข้อผิดพลาดมาตรฐานอย่าง ZNE และ PEC
