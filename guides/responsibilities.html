ทำความเข้าใจความรับผิดชอบของคุณในการใช้ Qiskit Runtime

ตรวจสอบหัวข้อต่อไปนี้เพื่อดูความรับผิดชอบเฉพาะของคุณและของ IBM® เมื่อคุณใช้ Qiskit Runtime สำหรับข้อกำหนดการใช้งานโดยรวม ดู Terms and Notices สำหรับ IBM Cloud®

การจัดการเหตุการณ์และการดำเนินงาน​

การจัดการเหตุการณ์และการดำเนินงานครอบคลุมงานต่าง ๆ เช่น การตรวจสอบ การจัดการเหตุการณ์ ความพร้อมใช้งานสูง การระบุปัญหา การกู้คืน และการสำรองและกู้คืนสถานะเต็มรูปแบบ

งานความรับผิดชอบของ IBMความรับผิดชอบของคุณ
การจัดการสุขภาพโครงสร้างพื้นฐาน
  • ส่งมอบฟีเจอร์ใหม่ อัปเดต และแก้ไขบั๊กอย่างต่อเนื่องตามความจำเป็นอย่างโปร่งใส
  • แจ้งเตือนเกี่ยวกับการบำรุงรักษาตามแผน ประกาศด้านความปลอดภัย หรือการหยุดทำงานที่ไม่ได้วางแผน
  • ตั้งค่าการรับอีเมล เกี่ยวกับการแจ้งเตือนบริการ
  • ติดตามหน้า IBM Cloud status สำหรับประกาศทั่วไป
การตรวจสอบสุขภาพโครงสร้างพื้นฐานและการแจ้งเตือน
  • แก้ไขปัญหาสภาพแวดล้อมโครงสร้างพื้นฐานทั้งหมด
  • แจ้งลูกค้าเกี่ยวกับเหตุการณ์ที่เกี่ยวข้อง
  • ประเมินผลกระทบของแต่ละเหตุการณ์ที่รายงาน
  • ติดต่อ IBM Support ตามความจำเป็น
รักษา IBM Cloud SLA ด้านความพร้อมใช้งานสูงดำเนินการ Qiskit Runtime ตาม IBM Cloud Public Service Level Agreements (SLAs)ปฏิบัติตามแนวทางปฏิบัติที่ดีที่สุดด้านความพร้อมใช้งานสูง

การจัดการการเปลี่ยนแปลง​

การจัดการการเปลี่ยนแปลงครอบคลุมงานต่าง ๆ เช่น การนำใช้งาน การกำหนดค่า การอัปเกรด การแพตช์ การเปลี่ยนแปลงการกำหนดค่า และการลบ

งานความรับผิดชอบของ IBMความรับผิดชอบของคุณ
การอัปเกรดเวอร์ชันหลักให้ความพร้อมและเครื่องมือสำหรับการอัปเดตเวอร์ชันหลักย้ายไปยังเวอร์ชันที่รองรับก่อนสิ้นสุดการสนับสนุนสำหรับเวอร์ชันเก่า
การเปลี่ยนแปลงเวอร์ชัน APIกำหนดเวอร์ชัน REST APIsผสานรวมกับเวอร์ชัน REST APIs ที่ต้องการ
อัปเดต แก้ไข และฟีเจอร์ใหม่
  • ให้การอัปเดตสม่ำเสมอ แก้ไขบั๊ก และฟีเจอร์ใหม่ อย่างโปร่งใสตามโมเดลการส่งมอบต่อเนื่อง
  • โพสต์การแจ้งเตือนสำหรับการเปลี่ยนแปลงที่ส่งผลต่อลูกค้า
  • ตั้งค่าการรับการแจ้งเตือนทางอีเมล และติดตามหน้า IBM Cloud status สำหรับประกาศทั่วไป
  • อ่านการแจ้งเตือนที่ระบบสร้างขึ้นและประกาศแพลตฟอร์ม แล้วดำเนินการที่เหมาะสม

การจัดการข้อมูลระบุตัวตนและการเข้าถึง​

การจัดการข้อมูลระบุตัวตนและการเข้าถึงครอบคลุมงานต่าง ๆ เช่น การยืนยันตัวตน การอนุญาต การจัดการนโยบายการควบคุมการเข้าถึง และการอนุมัติ มอบ และเพิกถอนการเข้าถึง

งานความรับผิดชอบของ IBMความรับผิดชอบของคุณ
การควบคุมข้อมูลระบุตัวตนและการเข้าถึงให้ความสามารถในการจัดการและจำกัดการเข้าถึงทรัพยากรผ่าน IBM Cloudมอบ เพิกถอน และจัดการการเข้าถึงทรัพยากรผ่าน Cloud Identity and Access Management (IAM)
การยืนยันตัวตนบริการตรวจสอบว่ามีเพียงผู้ใช้ที่ผ่านการยืนยันตัวตนเท่านั้นที่มีสิทธิ์เข้าถึงบริการและทรัพยากร Qiskit Runtime ของคุณ
  • ปกป้อง API key ของคุณ จากการเข้าถึงโดยไม่ได้รับอนุญาต
  • หมุนเวียนและอัปเดต API keys ของคุณตามข้อกำหนดนโยบายความปลอดภัย
การสังเกตการณ์อนุญาตการผสานรวม IBM Cloud Activity Tracker Event Routing เพื่อตรวจสอบการกระทำของผู้ใช้ตั้งค่า IBM Cloud Activity Tracker Event Routing หรือฟังก์ชันอื่น ๆ เพื่อติดตามกิจกรรมของผู้ใช้

ความปลอดภัยและการปฏิบัติตามข้อบังคับ​

ความปลอดภัยและการปฏิบัติตามข้อบังคับครอบคลุมงานต่าง ๆ เช่น การดำเนินการควบคุมความปลอดภัยและการรับรองการปฏิบัติตามข้อกำหนด

งานความรับผิดชอบของ IBMความรับผิดชอบของคุณ
ทั่วไป
  • รักษาการควบคุมที่สอดคล้องกับมาตรฐานการปฏิบัติตามข้อกำหนดในอุตสาหกรรมต่าง ๆ
  • ตรวจสอบ แยก และกู้คืนการทำงานของบริการ
  • ตรวจสอบและรายงานสุขภาพของอินเทอร์เฟซบริการ
ตรวจสอบว่าไม่มีการให้ข้อมูลส่วนบุคคลหรือข้อมูลที่อยู่ภายใต้การควบคุม
ช่องโหว่ตรวจสอบเพื่อตรวจจับปัญหาช่องโหว่และการปฏิบัติตามข้อกำหนดด้านความปลอดภัย
  • รับทราบข้อมูลเกี่ยวกับช่องโหว่และปัญหาด้านความปลอดภัยที่อาจเกิดขึ้นผ่านประกาศด้านความปลอดภัยที่ให้แนวทางการแก้ไขที่เป็นไปได้
  • ตรวจสอบส่วนความปลอดภัยของ Qiskit GitHub repository ช่องโหว่ด้านความปลอดภัยทั้งหมดจะถูกโพสต์ที่นั่น
  • ตรวจสอบเว็บไซต์ IBM Cloud status เพื่อค้นหาประกาศและประกาศด้านความปลอดภัยเกี่ยวกับเหตุการณ์สำคัญที่ส่งผลต่อแพลตฟอร์ม IBM Cloud โครงสร้างพื้นฐาน และบริการหลัก
การเข้ารหัสเข้ารหัสข้อมูลเมื่อส่งผ่านเครือข่ายสาธารณะและภายในเครือข่ายศูนย์ข้อมูลส่วนตัวของ Cloud Service วิธีการเข้ารหัส เช่น HTTPS และ TLS ใช้เพื่อปกป้องข้อมูลในขณะเคลื่อนย้ายตรวจสอบตามความจำเป็นว่าการเชื่อมต่อของคุณมีการเข้ารหัสแบบ end-to-end
ความปลอดภัย
  • ตรวจสอบความปลอดภัยของข้อมูลบนดิสก์และข้อมูลในขณะเคลื่อนย้ายภายในโครงสร้างพื้นฐานของตน
  • ให้บริการที่ปลอดภัยซึ่งสอดคล้องกับมาตรฐานสำคัญ
จำกัดการเข้าถึงของผู้ใช้ ไปยังทรัพยากรและกลุ่มทรัพยากรที่เหมาะสม

การกู้คืนระบบจากภัยพิบัติ​

งานความรับผิดชอบของ IBMความรับผิดชอบของคุณ
ทั่วไปกู้คืนหรือสร้างใหม่สภาพแวดล้อมการจัดสรรและทรัพยากรในพื้นที่ที่ได้รับผลกระทบ
  • ตรวจสอบสถานะของ instance และทรัพยากร
  • จัดสรรอินสแตนซ์ บริการ Qiskit Runtime ใหม่ในพื้นที่สำรอง หากมี
การกู้คืนบริการกู้คืนและฟื้นฟูความสามารถของบริการ Qiskit Runtime สู่การดำเนินงานปกติโดยอัตโนมัติส่ง job ที่ได้รับผลกระทบอีกครั้งหลังจากการกู้คืน
การสำรองข้อมูลการกำหนดค่าของผู้ใช้IBM ไม่รับผิดชอบต่อการสำรองข้อมูลการกำหนดค่าของผู้ใช้สำรองข้อมูลการกำหนดค่าตามความจำเป็น
การสำรองและกู้คืน workloadIBM ไม่รับผิดชอบต่อการสำรองหรือกู้คืนข้อมูล workload ของผู้ใช้สำรองและกู้คืน workload ของคุณตามความจำเป็น
