AI-QEM รุ่นปัจจุบันมีข้อจำกัดดังต่อไปนี้:

  • การลดข้อผิดพลาดจำกัดเฉพาะตระกูลโปรเซสเซอร์ Heron LTM วางแผนรองรับ backend เพิ่มเติมในเวอร์ชันถัดไป

  • การลดข้อผิดพลาดถูกใช้แบบเลือกเฉพาะ การลดข้อผิดพลาดจะทำเฉพาะเมื่อค่าสัมบูรณ์ของ expectation value เป็นไปตาม ∣⟨O⟩noisy∣≥0.1|\langle O \rangle_{noisy}| \geq 0.1∣⟨O⟩noisy​∣≥0.1 เพื่อให้ใช้การลดข้อผิดพลาดเฉพาะที่คาดว่าจะให้ประโยชน์อย่างมีนัยสำคัญ

ข้อจำกัดเหล่านี้สะท้อนขอบเขตปัจจุบันของ AI-QEM รุ่นในอนาคตอาจผ่อนคลายข้อจำกัดเหล่านี้เมื่อ LTM เพิ่มการรองรับ workflow, backend และฟีเจอร์เพิ่มเติม

ภาพรวม​

Quantum error mitigation (QEM) ครอบคลุมโปรโตคอลเชิงอัลกอริทึม เช่น zero-noise extrapolation (ZNE) [2] และ probabilistic error cancellation (PEC) [3] ซึ่งออกแบบมาเพื่อลดอคติที่เกิดจาก noise ใน expectation value บนฮาร์ดแวร์ noisy intermediate-scale quantum (NISQ) โดยไม่ต้องใช้ qubit จำนวนมหาศาลแบบ fault tolerance เต็มรูปแบบ วิธีการเหล่านี้สำคัญอย่างยิ่งต่อการได้ผลการจำลองทางฟิสิกส์และผล benchmark ที่เชื่อถือได้จากโปรเซสเซอร์ปัจจุบัน แม้ในช่วงไม่กี่ปีมานี้จะมีการพัฒนาวิธี QEM จำนวนมาก แต่เกือบทั้งหมดมีข้อแลกเปลี่ยนพื้นฐานร่วมกัน คือต้องใช้เวลา QPU มากขึ้นอย่างมากเพื่อให้ได้ความแม่นยำ ข้อจำกัดหลักของวิธีเหล่านี้คือ sampling overhead ที่เพิ่มแบบเอกซ์โปเนนเชียล เพราะการสร้างสัญญาณที่ไม่เอนเอียงจาก circuit ที่มี noise ทำให้ความแปรปรวนทางสถิติของ estimator เพิ่มขึ้นอย่างมาก ดังนั้นการรับมือกับระดับ noise ที่สูงขึ้นจึงต้องใช้ measurement shot มากขึ้นหลายระดับขนาด ซึ่งนำไปสู่เวลารัน QPU ที่นานขึ้นอย่างมากและคอขวดของฮาร์ดแวร์ที่รุนแรง [4, 5, 6]

ด้วย AI-QEM คุณสามารถรัน quantum circuit บน QPU ที่มี noise และได้ expectation value ที่ดีขึ้นเมื่อเทียบกับเทคนิคลดข้อผิดพลาดแบบ AI อื่นๆ โดยไม่มี overhead เวลารัน QPU เพิ่มเติม แนวทางนี้ใช้ deep neural network ที่มีสถาปัตยกรรม graph convolutional network (GCN)-Transformer เครือข่ายนี้ถูกฝึกด้วย feature ที่รวมโครงสร้างของ circuit, topology ของ backend, observable แบบ Pauli และการ calibrate ของ qubit และทำนายตัวประกอบแก้ไข แทนด้วย ζ\zetaζ การหาร expectation value ที่มี noise ด้วย ζ\zetaζ จะได้ expectation value ที่ดีขึ้น การทดลองแสดงว่า AI-QEM ให้ผลลัพธ์ดีกว่าวิธีลดข้อผิดพลาดแบบ AI อื่นๆ โดยเฉพาะกับ circuit ที่มี depth (จำนวนชั้นของ gate) และ width (จำนวน qubit) มาก ทำให้เหมาะกับการทดลองควอนตัมระดับ utility ตารางในส่วนBenchmarks แสดงว่าโมเดลที่ใช้ GCN-Transformer เหนือกว่าโมเดลที่ใช้ random forest (RF) ในช่วง 80 ถึง 150 qubit โดยมี mean absolute error (MAE) เท่ากับ 0.343 MAE คือค่าเฉลี่ย ของผลต่างสัมบูรณ์ระหว่าง expectation value ในอุดมคติกับ expectation value หลังจากโมเดลลดข้อผิดพลาดของผลลัพธ์ฮาร์ดแวร์ที่มี noise โดยเฉลี่ยจากการกำหนดค่า circuit และ observable จำนวนมาก นอกจากนี้ เนื่องจากโมเดลไม่ขึ้นกับ circuit คุณจึงใช้กับ quantum circuit และงานประยุกต์ได้หลากหลายโดยไม่ต้องปรับแต่งเฉพาะ circuit

สำหรับคำอธิบายฉบับเต็มของส่วนประกอบพื้นฐานและการสาธิตระดับ utility ดูบทความ AI-QEM [1]

คำอธิบาย​

ใช้ LTM AI-QEM function เพื่อประมาณ expectation value ของ observable สำหรับ quantum circuit ที่กำหนด หากต้องการใช้ LTM AI-QEM ให้ระบุ quantum circuit ชุดของ observable ที่จะวัด และ QPU function ใช้เวลา QPU เท่ากับ IBM Quantum Estimator primitive และไม่ใช้เวลา QPU เพิ่มเติม

วิธีปกติในการคำนวณ expectation value ของ observable OOO คือแยก observable เป็นผลรวมของ Pauli operator, O=∑iciPiO=\sum_i{c_i}{P_i}O=∑i​ci​Pi​ แล้วคำนวณ expectation value ของแต่ละ Pauli operator, ⟨Pi⟩\langle P_i \rangle⟨Pi​⟩ แยกกัน จากนั้น expectation value ของ observable, ⟨O⟩\langle O \rangle⟨O⟩ ก็คือผลรวมเชิงเส้นแบบเดียวกันของ expectation value ของ Pauli: ⟨O⟩=∑ici⟨Pi⟩{\langle O \rangle}=\sum_i{c_i}{\langle P_i \rangle}⟨O⟩=∑i​ci​⟨Pi​⟩ ถ้าชุดของ Pauli operator สลับที่กันได้ การวัดที่ต้องใช้คำนวณ expectation value ของพวกมันก็ทำพร้อมกันได้ เมื่อคุณรัน circuit ด้วย LTM AI-QEM function ตัว function ใช้ Estimator primitive เพื่อรัน circuit บนฮาร์ดแวร์ตามปกติ โดยทำตามขั้นตอนเดียวกันคือแยก observable เป็น Pauli operator และคำนวณ expectation value ของแต่ละตัวแยกกัน จากนั้น GCN-Transformer ซึ่งเป็นสถาปัตยกรรม deep learning จะทำนายตัวประกอบแก้ไข ζi\zeta_iζi​ สำหรับแต่ละ Pauli operator PiP_iPi​ function ใช้ตัวประกอบแก้ไขนี้เพื่อแก้ expectation value ที่มี noise ของแต่ละ Pauli operator: ⟨Pi⟩mitigated=⟨Pi⟩noisyζi{\langle P_i \rangle}_{mitigated} = \frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}⟨Pi​⟩mitigated​=ζi​⟨Pi​⟩noisy​​ ดังนั้น expectation value ที่ลดข้อผิดพลาดแล้วคือ ⟨O⟩mitigated=∑ici⟨Pi⟩mitigated=∑ici⟨Pi⟩noisyζi{\langle O \rangle}_{mitigated} = \sum_i{c_i}{\langle {P_i} \rangle}_{mitigated} = \sum_i{c_i}{\frac{{\langle P_i \rangle}_{noisy}}{\zeta_i}}⟨O⟩mitigated​=∑i​ci​⟨Pi​⟩mitigated​=∑i​ci​ζi​⟨Pi​⟩noisy​​

workflow สำหรับการใช้ LTM AI-QEM function มีดังนี้:

  1. กำหนด circuit และ observable ของคุณ

  2. รัน LTM AI-QEM function โดยส่งคู่ของ circuit และ observable เป็น primitive unified bloc (PUB)

  3. ดึงผลลัพธ์ ซึ่งมี expectation value ของ observable เทียบกับ quantum circuit ที่สอดคล้องกันในแต่ละ PUB

ตัวอย่างทดสอบจำนวนมากแสดงให้เห็นเชิงประจักษ์ว่า LTM AI-QEM function ช่วยปรับปรุงการประมาณค่า observable function มีคุณสมบัติดังนี้:

  • การทดลองระดับ utility: ตัวอย่างทดสอบแสดงว่า AI-QEM ทำงานได้ดีกว่าวิธีแบบ AI อื่นๆ สำหรับ circuit ที่มี depth และ width มาก ดูผลลัพธ์ในส่วนBenchmarks

  • Primitive: function รองรับ Estimator primitive คุณจึงใช้คำนวณ expectation value ของ observable ใดๆ เทียบกับ quantum circuit ใดๆ ได้

  • Primitive unified bloc (PUB): LTM AI-QEM function รองรับ PUB ทุกประเภท (คือการกำหนดค่า circuit-observable ทุกแบบ) ที่ Estimator primitive รองรับ

เทคนิค AI-QEM เริ่มจากการสร้าง dataset ซึ่งสร้าง random quantum circuit ด้วยการตั้งค่าพารามิเตอร์ต่างๆ สำหรับแต่ละ circuit จะคำนวณทั้ง expectation value ในอุดมคติ (ได้จากการจำลอง) และ expectation value ที่มี noise (ได้จากการรันบนฮาร์ดแวร์) ผลลัพธ์เหล่านี้ พร้อมกับ quantum circuit ที่สอดคล้องกันและข้อมูล backend จะถูกเก็บไว้ใน dataset repository จากนั้นใช้ dataset ฝึกโมเดล machine learning หรือ deep learning ที่ลด noise ในการคำนวณควอนตัมได้ และบันทึกโมเดลที่ฝึกแล้วไว้ใช้ในอนาคต ระหว่างการ inference โมเดลที่ฝึกแล้วรับอินพุตเป็น quantum circuit, expectation value ที่มี noise ซึ่งคำนวณบนฮาร์ดแวร์, observable ที่เกี่ยวข้อง และข้อมูล backend จากนั้นโมเดลประมวลผลอินพุตเหล่านี้เพื่อให้ expectation value ที่ลด noise แล้ว

เช่นเดียวกับ Estimator primitive ฟังก์ชัน LTM AI-QEM รับ primitive unified blocs (PUB) เป็นอินพุต PUB คือ tuple ในรูปแบบ (circuit, observables, parameter_values, precision) โดยต้องมี parameter_values สำหรับ Circuit ที่มีพารามิเตอร์ ส่วน precision เป็นตัวเลือก

Circuit​

สถานะ Greenberger-Horne-Zeilinger (GHZ) แบบ nnn-qubit กำหนดโดย:

∣GHZ⟩n=∣0⟩⊗n+∣1⟩⊗n2=∣00…0⟩⏞n qubits+∣11…1⟩⏞n qubits2.|GHZ\rangle_{n} = \frac{\vert{0}\rangle^{\otimes{n}} + \vert{1}\rangle^{\otimes{n}}}{\sqrt2} = \frac{\overbrace{\vert{00}\dots{0}\rangle}^{\text{$n$ qubits}} + \overbrace{\vert{11}\dots{1}\rangle}^{\text{$n$ qubits}}}{\sqrt2}.∣GHZ⟩n​=2​∣0⟩⊗n+∣1⟩⊗n​=2​∣00…0⟩​n qubits​+∣11…1⟩​n qubits​​.

การสร้างสถานะ GHZ แบบ nnn-qubit ทำได้โดยเริ่มต้น Qubit ทั้งหมดในสถานะ ∣0⟩|0\rangle∣0⟩ แล้วใช้ Hadamard Gate กับ Qubit ตัวแรกเพื่อสร้างซูเปอร์โพซิชันที่เท่ากัน จากนั้นใช้ CNOT Gate ต่อเนื่องกันตลอดทั้งรีจิสเตอร์ โดยมี Qubit iii เป็นตัวควบคุมและ Qubit i+1i+1i+1 เป็นเป้าหมาย บันไดของ Gate พัวพันนี้จะส่งต่อซูเปอร์โพซิชันเริ่มต้นไปยัง Qubit ทั้งหมด ได้ผลลัพธ์เป็นสถานะ GHZ ที่พัวพันกัน

ออบเซอร์เวเบิล​

การวัดผลคูณเทนเซอร์สองส่วน Zi⊗ZjZ_i \otimes Z_jZi​⊗Zj​ บนสถานะ GHZ เป็นการประเมินสหสัมพันธ์เชิงพาริตีระหว่าง Qubit สองตัวใดๆ ในรีจิสเตอร์ เนื่องจากสถานะ GHZ เป็นซูเปอร์โพซิชันของสถานะศูนย์ทั้งหมดและสถานะหนึ่งทั้งหมด Qubit สองตัวใดๆ จึงสัมพันธ์กันอย่างสมบูรณ์ ค่าเจาะจงเท่ากับ (+1×+1)=1(+1 \times +1) = 1(+1×+1)=1 สำหรับสาขา ∣00…0⟩\vert00\dots0\rangle∣00…0⟩ และ (−1×−1)=1(-1 \times -1) = 1(−1×−1)=1 สำหรับสาขา ∣11…1⟩\vert11\dots1\rangle∣11…1⟩ เนื่องจากทั้งสองสาขาให้ค่า +1 ค่าคาดหมายเชิงทฤษฎีจึงเท่ากับ 1 สร้าง observable ด้วยคลาส SparsePauliOp

ตัวอย่างที่ 2: Mirror circuit​

ตัวอย่างนี้ใช้ mirror circuit เพื่อคำนวณค่าคาดหมายของ observable ที่ส่งใน PUB ที่มีรูปทรงต่างกัน แสดงให้เห็นฟังก์ชัน LTM AI-QEM และความเข้ากันได้กับรูปทรง PUB ที่ต่างกัน พร้อมเปรียบเทียบผลลัพธ์ที่ลดข้อผิดพลาดแล้วกับผลลัพธ์ที่ยังไม่ได้ลดข้อผิดพลาด

mirror circuit คือ Circuit ที่ใช้ Circuit ที่สร้างแบบสุ่มแล้วตามด้วยอินเวอร์สของมัน ในการรันที่สมบูรณ์แบบและไม่มีสัญญาณรบกวน ทั้งสองครึ่งจะหักล้างกันและคืน Qubit กลับสู่สถานะเริ่มต้น ทำให้ Circuit นี้มีประโยชน์ในการศึกษาว่าสัญญาณรบกวนของฮาร์ดแวร์และรันไทม์ส่งผลต่อผลลัพธ์ที่คาดเดาได้อย่างไร

ในตัวอย่างนี้ คุณจะสร้าง PUB หลายตัว แต่ละ PUB จับคู่ mirror circuit ตัวเดียวกันกับ observable ที่ประกอบด้วยตัวดำเนินการ Pauli ซึ่งมีรูปทรงต่างกัน

ฟังก์ชัน LTM AI-QEM ประเมิน observable เหล่านี้ และส่งกลับทั้งค่าคาดหมายจากการรันที่มีสัญญาณรบกวนและค่าหลังลดข้อผิดพลาด ตัวอย่างนี้มีสองเป้าหมาย คือตรวจสอบว่าฟังก์ชันรองรับรูปแบบ PUB ที่รองรับ และเปรียบเทียบค่าคาดหมายที่ลดข้อผิดพลาดแล้วกับค่าที่มีสัญญาณรบกวน เพื่อดูว่าเวิร์กโฟลว์การลดข้อผิดพลาดคืนพฤติกรรมที่คาดหวังของ mirror circuit ได้ดีเพียงใด

ขั้นแรก สร้าง mirror circuit ที่มีห้า Qubit โดยสร้าง Circuit สุ่มด้วยฟังก์ชัน random_circuit ของ Qiskit ระบุจำนวน Qubit (n_qubits=5) ความลึกของ Circuit (depth=5) และ seed เพื่อให้ทำซ้ำได้ (seed=42) จากนั้นเพิ่ม barrier ที่ท้าย Circuit สุ่ม และใช้ unitary_overlap เพื่อสร้าง mirror circuit เนื่องจาก unitary_overlap(U1, U2) สร้าง Circuit ที่สอดคล้องกับ U2†U1U_{2}^{\dagger}U_{1}U2†​U1​ การส่ง Circuit เดียวกันเป็นทั้งสองอาร์กิวเมนต์จึงสร้าง mirror circuit ได้ barrier ป้องกันไม่ให้ Circuit กลายเป็นเอกลักษณ์ระหว่าง transpilation เอาต์พุตของโค้ดแสดงความลึกของ mirror circuit ซึ่งคาดว่าอยู่ที่ประมาณ 10 สำหรับ depth=5 บวกเลเยอร์ของ barrier

import numpy as np
from qiskit.circuit.library import unitary_overlap
from qiskit.circuit.random import random_circuit
from qiskit.quantum_info import SparsePauliOp

def create_mirror_circuit(
    n_qubits: int, depth: int, seed: int = 42
) -> QuantumCircuit:
    """Generates an n-qubit random circuit followed by its inverse (mirror) and measure all qubits."""  # noqa: E501
    circuit = random_circuit(n_qubits, depth=depth, seed=seed)
    circuit.barrier()
    mirror_circuit = unitary_overlap(circuit, circuit)
    return mirror_circuit

import numpy as np
from qiskit.primitives.containers import EstimatorPub

def _term_label(term):
    """{'ZZZZZ': 0.3, 'XXXXX': 0.5} -> '0.3 ZZZZZ\n+\n0.5 XXXXX'"""
    return "\n+\n".join(
        p if c == 1 else f"{c:g} {p}" for p, c in term.items()
    )

def plot_pub(pubs, result, index, ideal=None, title="", ax=None):

    data = result[index].data

        ("Unmitigated", data.noisy_evs, data.noisy_stds, "#d62728"),

                "Ideal",
                np.asarray(ideal, dtype=float),
                np.zeros(np.shape(ideal)),
                "#2ca02c",
            )
        )

    obs = pub.observables
    labels = np.empty(obs.shape, dtype=object)
    for idx in np.ndindex(obs.shape):

    x = np.arange(len(labels))
    width = 0.8 / len(series)
    offsets = (np.arange(len(series)) - (len(series) - 1) / 2) * width

    standalone = ax is None

ตัวอย่างที่ 3: ตรวจสอบว่า LTM AI-QEM ไม่มี QPU overhead เพิ่ม​

ตัวอย่างนี้แสดงว่าฟังก์ชัน LTM AI-QEM ไม่ใช้เวลา QPU เพิ่มเติม กล่าวคือ LTM AI-QEM ใช้เวลา QPU ไม่มากกว่า Estimator primitive ตัวอย่างนี้ใช้ mirror circuit อีกครั้ง โดยครั้งนี้ใช้ PUB สองประเภท ประเภทแรกเรียกว่าประเภท commuting ซึ่ง observable Pauli ทั้งหมดสับเปลี่ยนกัน ประเภทที่สองเรียกว่าประเภท non-commuting ซึ่งไม่มี observable Pauli ตัวใดสับเปลี่ยนกันเลย

สำหรับแต่ละประเภท observable ถูกนิยามสองวิธี คือเป็นรายการของตัวดำเนินการ Pauli (list_of_commuting และ list_of_non_commuting) และเป็นอ็อบเจกต์ SparsePauliOp เดียวที่แทนผลรวมของตัวดำเนินการ Pauli ทั้งหมดในรายการ (sum_of_commuting และ sum_of_non_commuting)

ประเภท commuting ใช้เวลาน้อยกว่าประเภท non-commuting เพราะ Qiskit จัดกลุ่มตัวดำเนินการ Pauli ที่สับเปลี่ยนกันและวัดในการตั้งค่าการวัดเดียวกัน ตัวอย่างนี้แสดงว่าการรันด้วยฟังก์ชัน LTM AI-QEM ใช้เวลา QPU เท่ากับการรันด้วย primitive EstimatorV2 ของ IBM Quantum

ตัวอย่างที่ 4: Brickwork Clifford circuit​

ตัวอย่างนี้จำลอง Circuit แบบ Clifford ตระกูลของ Circuit นี้มีประโยชน์เพราะคุณออกแบบการจำลองให้มีค่าคาดหมายที่ทราบได้ กล่าวคือ คุณออกแบบ Circuit และ observable ให้ค่าคาดหมายเป็น 1 เสมอ ดังนี้:

  1. จุดเริ่มต้น (stabilizer): เริ่มด้วยสถานะสุญญากาศ ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n การใช้ Pauli ZZZ หรือตัวดำเนินการเอกลักษณ์กับ ∣0⟩|0\rangle∣0⟩ ไม่เปลี่ยนสถานะ: Z∣0⟩=∣0⟩Z|0\rangle = |0\rangleZ∣0⟩=∣0⟩ และ I∣0⟩=∣0⟩I |0\rangle = |0\rangleI∣0⟩=∣0⟩ ดังนั้น สตริง Pauli PPP ใดๆ ที่เป็นผลคูณเทนเซอร์ของ ZZZ และ III เท่านั้น จะไม่เปลี่ยนสถานะศูนย์ทั้งหมด ∣0⟩⊗n|0\rangle^{{\otimes}n}∣0⟩⊗n: P∣0⟩⊗n=∣0⟩⊗nP |0\rangle^{{\otimes}n} = |0\rangle^{{\otimes}n}P∣0⟩⊗n=∣0⟩⊗n

  2. วิวัฒนาการแบบ Clifford: การใช้ยูนิทารี ULU_LUL​ กับสถานะจะได้ ∣ψ⟩=UL∣0⟩⊗n|\psi\rangle = U_L |0\rangle^{{\otimes}n}∣ψ⟩=UL​∣0⟩⊗n เพื่อหา observable ที่มีค่าคาดหมายของสถานะใหม่นี้เป็น 1 ให้ใช้การแปลงยูนิทารีเดียวกันกับตัวดำเนินการ: OL=ULPUL†O_L = U_L P U_L^{\dagger}OL​=UL​PUL†​ นี่คือภาพแบบไฮเซนเบิร์กของกลศาสตร์ควอนตัม

  3. เหตุใด observable จึงยังเป็นสตริง Pauli เดียว: หาก ULU_LUL​ มี Gate ที่ไม่ใช่ Clifford (เช่น T Gate หรือการหมุนตามอำเภอใจ) ULPUL†U_L P U_L^\daggerUL​PUL†​ จะขยายเป็นผลรวมของสตริง Pauli ที่ต่างกันจำนวนมาก คุณจะต้องวัด observable ที่ต่างกันหลายตัวและนำมารวมกันเพื่อให้ได้ 1 อย่างไรก็ตาม เนื่องจาก Circuit ใช้เฉพาะ Gate แบบ Clifford ทฤษฎีบท Gottesman-Knill จึงรับประกันว่า ULPUL†U_L P U_L^\daggerUL​PUL†​ จะแมปไปยังสตริง Pauli เพียงหนึ่งสตริงพอดี (ตัวอย่างเช่น XY−ZXX Y -Z XXY−ZX)

  4. การรับประกันทางคณิตศาสตร์: เนื่องจากโครงสร้างนี้ การคำนวณค่าคาดหมายจึงเป็นการแทนค่าทางพีชคณิตอย่างง่าย:

ก่อนอื่น ออกแบบ Circuit ควอนตัมที่มีเฉพาะ Gate แบบ Clifford ได้แก่ Gate Qubit เดียว HHH, SSS, XXX, YYY และ ZZZ และ Gate สอง Qubit CZCZCZ ฟังก์ชัน create_brickwork_clifford รับจำนวน Qubit (num_qubits) และ depth เป็นอาร์กิวเมนต์ และส่งกลับ Circuit ควอนตัมแบบ Clifford ที่มีจำนวน Qubit และความลึกตามที่กำหนด

import random
from qiskit import QuantumCircuit
from qiskit.circuit.library import HGate, SGate, XGate, YGate, ZGate

def create_brickwork_clifford(num_qubits: int, depth: int = 2):
    def get_random_1q_gate():
        gates = [HGate(), SGate(), XGate(), YGate(), ZGate()]
        return random.choice(gates)

    circuit = QuantumCircuit(num_qubits)
    for layer_idx in range(depth):
        for qubit in range(num_qubits):
            circuit.append(get_random_1q_gate(), [qubit])

        # Add CZ Gate in brickwork pattern
        if layer_idx % 2 == 0:
            for qubit in range(0, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
        else:
            for qubit in range(1, num_qubits - 1, 2):
                circuit.cz(qubit, qubit + 1)
    return circuit

from qiskit.quantum_info import Pauli, Clifford, SparsePauliOp
import numpy as np

num_qubits = 50
depth_list = list(range(30, 71, 5))
pauli_weight = 2

# Set random seed for reproducibility
random.seed(42)
np.random.seed(42)

circuits_list = []
observables_list = []

# Choose two unique random positions for 'Z'
z_positions = random.sample(range(num_qubits), pauli_weight)

# Build the Pauli string
pauli_str = ["I"] * num_qubits
for pos in z_positions:
    pauli_str[pos] = "Z"
Z_n = Pauli("".join(pauli_str))

for depth in depth_list:
    # Generate the brickwork stabilizer circuit
    circuit = create_brickwork_clifford(num_qubits, depth)
    circuits_list.append(circuit)

    # Get Clifford object for the circuit
    cliff = Clifford(circuit)
    # Evolve Z^n by the Clifford (Heisenberg picture, default)
    conj_pauli = Z_n.evolve(cliff, frame="s")
    # Convert to SparsePauliOp
    transformed_operator = SparsePauliOp(conj_pauli)
    observables_list.append(transformed_operator)

ดึงและแสดงผลลัพธ์​

หลังจาก job เสร็จสิ้น ให้รวบรวมค่าคาดหมายและส่วนเบี่ยงเบนมาตรฐานจากผลลัพธ์ของแต่ละ PUB สำหรับทุกความลึกของ Circuit ผลลัพธ์ประกอบด้วยค่าที่มีสัญญาณรบกวน (ยังไม่ลดข้อผิดพลาด) คือ noisy_evs และ noisy_stds และค่าหลังลดข้อผิดพลาดด้วย AI-QEM คือ mitigated_evs และ mitigated_stds

จากนั้นใช้ฟังก์ชัน plot_clifford_results เพื่อพล็อตค่าคาดหมายเทียบกับความลึกของ Circuit พล็อตประกอบด้วยสิ่งต่อไปนี้:

  • Unmitigated: ค่าคาดหมายดิบที่ฮาร์ดแวร์ส่งกลับ แสดงพร้อมแถบความคลาดเคลื่อนขนาด ±σ\pm\sigma±σ

  • Mitigated (AI-QEM): ค่าคาดหมายหลังลดข้อผิดพลาด แสดงพร้อมแถบความคลาดเคลื่อนเช่นกัน

  • Ideal (stabilizer simulation): ค่าคาดหมายที่ไม่มีสัญญาณรบกวน ⟨O⟩ideal=1\langle O \rangle_{\text{ideal}} = 1⟨O⟩ideal​=1 สำหรับทุกความลึก

  • Threshold: แถบสีเทาที่ครอบคลุม −0.1≤⟨O⟩≤0.1-0.1 \le \langle O \rangle \le 0.1−0.1≤⟨O⟩≤0.1 ค่าที่อยู่ในแถบนี้ไม่มีสัญญาณที่มีประโยชน์ให้ลดข้อผิดพลาด จึงปล่อยไว้โดยไม่ลดข้อผิดพลาด

# Extract results
results = clifford_job.result()

noisy_evs, noisy_stds = [], []
mitigated_evs, mitigated_stds = [], []

for pub_result in results:
    data = pub_result.data
    # Mitigated values
    mitigated_evs.append(data.evs)
    mitigated_stds.append(data.stds)
    # Noisy values (raw values returned by the hardware)
    noisy_evs.append(data.noisy_evs)
    noisy_stds.append(data.noisy_stds)
import matplotlib.pyplot as plt
import numpy as np

def plot_clifford_results(
    depth_list,
    noisy_evs,
    noisy_stds,
    mitigated_evs,
    mitigated_stds,
    ideal_evs,
):
    """Plot unmitigated, mitigated and ideal expectation values vs circuit depth."""
    style = dict(marker="*", markeredgecolor="black", markeredgewidth=0.5)

    plt.figure(figsize=(12, 6))
    plt.errorbar(
        depth_list,
        noisy_evs,
        yerr=noisy_stds,
        label="Unmitigated",
        capsize=4,
        **style,
    )
    plt.errorbar(
        depth_list,
        mitigated_evs,
        yerr=mitigated_stds,
        label="Mitigated (AI-QEM)",
        capsize=4,
        **style,
    )
    plt.plot(
        depth_list, ideal_evs, label="Ideal (Stabilizer simulation)", **style
    )
    # Threshold: Gray-out y = -0.1 to 0.1
    plt.axhspan(-0.1, 0.1, color="gray", alpha=0.3, label="Threshold")

    plt.xticks(depth_list)
    plt.xlabel("Circuit Depth")
    plt.ylabel("Expectation Value")
    plt.title("Clifford Circuit Simulation")
    plt.grid(alpha=0.3)
    plt.ylim(-0.2, 1.2)
    plt.legend(loc="upper left", bbox_to_anchor=(1, 1))
    plt.show()

# Flatten
clifford_results = {
    "noisy_evs": np.asarray(noisy_evs),
    "noisy_stds": np.asarray(noisy_stds),
    "mitigated_evs": np.asarray(mitigated_evs),
    "mitigated_stds": np.asarray(mitigated_stds),
    "ideal_evs": np.ones_like(noisy_evs),
}

plot_clifford_results(np.asarray(depth_list), **clifford_results)
