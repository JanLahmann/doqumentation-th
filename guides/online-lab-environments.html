สภาพแวดล้อมแล็บออนไลน์

นอกจากการดาวน์โหลดและติดตั้ง Qiskit เพื่อใช้งานบนเครื่องของคุณเอง ยังมีตัวเลือกอื่นสำหรับผู้ที่ต้องการทำงานในสภาพแวดล้อมการพัฒนาออนไลน์

ผู้ให้บริการหลายรายนำเสนอสภาพแวดล้อม Jupyter ออนไลน์ที่ติดตั้ง Qiskit ไว้ล่วงหน้าเพื่อการเริ่มต้นใช้งานที่รวดเร็วและสะดวก ผู้ให้บริการที่แนะนำได้แก่ผู้ให้บริการคลาวด์ OVHcloud และแพลตฟอร์มคลาวด์พัฒนาซอฟต์แวร์ควอนตัม qBraid

สภาพแวดล้อม notebook ที่แนะนำพร้อมติดตั้ง Qiskit ไว้ล่วงหน้า​

สภาพแวดล้อม Jupyter notebook ออนไลน์อื่นๆ อย่าง IBM Watson® Studio, Google Colab และ Microsoft Azure Machine Learning Studio สามารถใช้งานกับ Qiskit ได้โดยทำตามคำแนะนำที่เหมาะสม

OVHcloud AI notebooks​

ผู้ใช้ OVHcloud Public Cloud และ OVHcloud Startup สามารถใช้ OVHcloud quantum notebooks เพื่อเข้าถึง Qiskit และส่งงานไปยัง IBM® QPU ด้วยบัญชี IBM Quantum® หรือ IBM Cloud® ของตน สำหรับข้อมูลเพิ่มเติม เยี่ยมชมหน้า OVHcloud Documentation and tutorials

หมายเหตุ

OVHcloud AI notebooks ไม่พร้อมใช้งานในบางภูมิภาค เช่น สหรัฐอเมริกา นอกจากนี้ อินเทอร์เฟซผู้ใช้อาจมีลักษณะต่างกันในแต่ละภูมิภาค

ทำตามขั้นตอนเหล่านี้เพื่อเริ่มต้น:

  1. สร้างบัญชี IBM Cloud
  2. ตั้งค่าบัญชี OVHcloud
  3. สร้างโปรเจกต์ OVH Public Cloud
  4. ทำตามขั้นตอนใน Launch your first AI Notebook โดยเลือก Qiskit สำหรับ framework

qBraid Lab​

ผู้ใช้ Qiskit สามารถใช้สภาพแวดล้อม Python ที่กำหนดค่าล่วงหน้าของ qBraid ได้โดยทำตามคำแนะนำเหล่านี้ สำหรับข้อมูลเพิ่มเติม ดูที่ qBraid Docs

  1. ตั้งค่าบัญชีฟรีของ qBraid
  2. สร้างสภาพแวดล้อม Lab
  3. เปิด qBraid Lab คลิกไอคอน ENVS ทางขวา คลิก + ADD ที่ด้านบนของแถบด้านข้างใหม่ และค้นหา Qiskit แล้วคลิกเวอร์ชันที่ต้องการใช้ จากนั้นคลิก Install
  4. สร้าง Jupyter notebook โดยคลิก Python 3 [Qiskit] ในส่วน Notebook
  5. คุณสามารถติดตั้งแพ็กเกจ Python เพิ่มเติม (เช่น Qiskit v1.2) ใน notebook cell ได้โดยรัน %pip install [package_name] สำหรับข้อมูลเพิ่มเติม ดูหัวข้อ Pip (magic) commands

สภาพแวดล้อม notebook เพิ่มเติมสำหรับผู้ใช้ Qiskit​

สำหรับแพลตฟอร์มที่ไม่ได้กำหนดค่า Qiskit ไว้ล่วงหน้า ขั้นตอนการตั้งค่าจะคล้ายกัน ยกเว้นว่าคุณต้องติดตั้ง Qiskit เอง คุณจะสร้างบัญชี เริ่มโปรเจกต์ใหม่ (หรือ notebook หรือ workspace ขึ้นอยู่กับแพลตฟอร์ม) และติดตั้ง Qiskit

IBM Watson Studio​

  1. ตั้งค่า Watson Studio รุ่นทดลองฟรี
  2. สร้างโปรเจกต์ Watson Studio
  3. เพื่อติดตั้งแพ็กเกจ Qiskit และ dependencies ที่จำเป็น ให้เปิด notebook ใหม่และรันคำสั่งต่อไปนี้: 
    !pip install qiskit pylatexenc !yes | pip uninstall simplejson

Google Colab​

  1. สร้างบัญชี Google
  2. ไปที่ หน้า Google Colab และลงชื่อเข้าใช้ด้วยบัญชี Google ของคุณ
  3. สร้าง Colab notebook และติดตั้ง Qiskit โดยรันคำสั่งต่อไปนี้: 
    %pip install qiskit

Microsoft Azure Machine Learning Studio​

  1. สร้างบัญชี Azure
  2. สร้าง workspace
  3. สร้าง Jupyter notebook ใน workspace ของคุณ
  4. จาก notebook รันคำสั่งนี้เพื่อติดตั้ง Qiskit: 
     %pip install qiskit
