Logging สำหรับ Qiskit Runtime

บริการ IBM Cloud® เช่น Qiskit Runtime จะสร้าง platform logs ที่ใช้ตรวจสอบกิจกรรมที่ผิดปกติและการดำเนินการสำคัญในบัญชี รวมถึงแก้ไขปัญหาต่างๆ

สามารถใช้ IBM Cloud Logs Routing ซึ่งเป็น platform service เพื่อกำหนดเส้นทาง platform logs ในบัญชีไปยังปลายทางที่ต้องการโดยการกำหนดค่า tenant ที่ระบุว่า platform logs ถูกส่งไปที่ใด สำหรับข้อมูลเพิ่มเติม ดู About Logs Routing

สามารถใช้ IBM Cloud Logs เพื่อแสดงภาพและแจ้งเตือน platform logs ที่สร้างในบัญชีและถูกกำหนดเส้นทางโดย IBM Cloud Logs Routing ไปยัง IBM Cloud Logs instance

ตำแหน่งที่สร้าง platform logs​

IBM Cloud Container Registry สร้าง platform logs ที่แสดงใน logging instances ตารางต่อไปนี้แสดงตำแหน่งที่เปิดใช้งานการเก็บรวบรวม Container Registry service logs โดยอัตโนมัติ
