ตั้งค่าบัญชี IBM Cloud ของคุณ

ถ้าได้รับอีเมลเชิญให้เข้าร่วมบัญชี ให้ทำตามขั้นตอนใน ตั้งค่าบัญชี IBM Cloud ของคุณ - ผู้ใช้ที่ได้รับเชิญ แทน

คุณรัน workload บน IBM® quantum processing units (QPUs) ได้โดยการตั้งค่าบัญชีบน IBM Cloud® และยังต้อง ติดตั้งและตั้งค่า Qiskit และ IBM Quantum Compute client ด้วย

บัญชีผู้ใช้ของคุณเชื่อมต่อกับ instance อย่างน้อยหนึ่งรายการ ซึ่งระบุด้วย Cloud Resource Names (CRNs) เพื่อเข้าถึงบริการ IBM Quantum นอกจากนี้ ยังมี API token เฉพาะ (เรียกอีกชื่อว่า key) ที่กำหนดให้กับแต่ละบัญชี เพื่อให้เข้าถึง IBM Quantum จาก Qiskit ได้ สำหรับคำแนะนำในการเลือก instance เฉพาะ ดูที่ เชื่อมต่อกับ instance

ตั้งค่าเพื่อใช้งาน IBM Cloud​

ก่อนเริ่มต้น​

  1. ถ้ายังไม่มี ให้ตั้งค่า บัญชี IBM Cloud

    หมายเหตุ

    คุณสามารถเป็นสมาชิกของหลายบัญชี IBM Cloud พร้อมกันได้ สามารถเข้าถึงบัญชี IBM Cloud ใดก็ได้ตลอดเวลาผ่าน account switcher ในส่วน header ของ IBM Quantum Platform

  2. ล็อกอินเข้า IBM Quantum Platform ด้วย IBMid หรือบัญชี Google ถ้ายังไม่มี ระบบจะพาผ่านขั้นตอนการสร้าง (ข้อมูลล็อกอินเหล่านี้ไม่ใช่ข้อมูลบัญชี IBM Cloud)

  3. ตรวจสอบให้แน่ใจว่าเลือกบัญชีและภูมิภาคที่ถูกต้องใน account switcher ในส่วน header ดังที่แสดงในภาพต่อไปนี้

    ภูมิภาคควบคุมว่างานของคุณจะรันที่ไหนและข้อมูลงานจะถูกเก็บไว้ที่ใด คุณเข้าถึงภูมิภาคใดก็ได้โดยใช้ API key เดียวกัน แต่จะเห็นและเข้าถึงได้เฉพาะ instance ที่สร้างขึ้นในภูมิภาคที่คุณล็อกอินอยู่เท่านั้น

1. สร้าง instance​

คุณสร้าง instance ได้จากหน้า Instances ของ IBM Quantum Platform ดูคำแนะนำโดยละเอียดได้ที่ สร้าง instance

2. ทางเลือก: บันทึกข้อมูลการเข้าถึง​

ถ้าใช้งาน Python environment ที่น่าเชื่อถือ เช่น แล็ปท็อปส่วนตัว แนะนำให้ใช้เมธอด save_account() เพื่อ บันทึกข้อมูลล็อกอินไว้ในเครื่อง

3. เชื่อมต่อ Qiskit กับ service instance ของคุณ​

  • เริ่มต้นใช้งาน service ใน Python environment ที่น่าเชื่อถือ

  • เริ่มต้นใช้งาน service ใน environment ที่ไม่น่าเชื่อถือ (เช่น คอมพิวเตอร์สาธารณะ)

หมายเหตุ
  • ทำตาม คำแนะนำเหล่านี้ ถ้าต้องการเชื่อมต่อผ่าน REST API แทน Qiskit
  • ถ้าจำเป็น ใช้ ข้อมูลนี้ เพื่อกำหนดค่า firewall ให้เปิดการเข้าถึง IBM Quantum API endpoints

ขั้นตอนถัดไป​

คำแนะนำ
  • ภาพรวมของแผนที่มีให้เลือก
  • กำหนดค่า Qiskit SDK ในเครื่อง
  • ดู QPUs ที่พร้อมใช้งาน
  • ทำตามขั้นตอนใน Hello world เพื่อเขียนและรันโปรแกรม quantum
  • ตั้งค่าเพื่อใช้ IBM Quantum Platform กับ REST API
