การแยกแยะสถานะควอนตัมและ tomography

ในส่วนสุดท้ายของบทเรียน เราจะพูดถึงสั้นๆ สองงานที่เกี่ยวข้องกับการวัด: การแยกแยะสถานะควอนตัม และ quantum state tomography

  1. การแยกแยะสถานะควอนตัม

    สำหรับการแยกแยะสถานะควอนตัม เรามีคอลเลกชันสถานะควอนตัมที่รู้จัก ρ0,…,ρm−1\rho_0,\ldots,\rho_{m-1}ρ0​,…,ρm−1​ พร้อมกับ ความน่าจะเป็น p0,…,pm−1p_0,\ldots,p_{m-1}p0​,…,pm−1​ ที่เกี่ยวข้องกับสถานะเหล่านี้ วิธีกระชับในการแสดงสิ่งนี้คือบอกว่าเรามี ensemble

    {(p0,ρ0),…,(pm−1,ρm−1)}\{(p_0,\rho_0),\ldots,(p_{m-1},\rho_{m-1})\}{(p0​,ρ0​),…,(pm−1​,ρm−1​)}

    ของสถานะควอนตัม

    จำนวน a∈{0,…,m−1}a\in\{0,\ldots,m-1\}a∈{0,…,m−1} ถูกเลือกแบบสุ่มตามความน่าจะเป็น (p0,…,pm−1)(p_0,\ldots,p_{m-1})(p0​,…,pm−1​) และระบบ X\mathsf{X}X ถูกเตรียมในสถานะ ρa\rho_aρa​ เป้าหมายคือการระบุ โดยผ่านการวัด X\mathsf{X}X เพียงอย่างเดียว ว่าค่า aaa ใดถูกเลือก

    ดังนั้น เรามีทางเลือกจำนวนจำกัด พร้อมกับ prior — ซึ่งคือความรู้ของเราเกี่ยวกับความน่าจะเป็นที่แต่ละ aaa จะ ถูกเลือก — และเป้าหมายคือการระบุว่าทางเลือกใดเกิดขึ้นจริง อาจง่ายสำหรับการเลือกสถานะและความน่าจะเป็นบางอย่าง แต่สำหรับบางอย่างก็อาจเป็นไปไม่ได้ที่จะทำโดยไม่มีโอกาสผิดพลาด

  2. Quantum state tomography

    สำหรับ quantum state tomography เรามีสถานะควอนตัมของระบบที่ ไม่รู้จัก — ดังนั้นต่างจากการแยกแยะสถานะควอนตัม มักไม่มี prior หรือข้อมูลเกี่ยวกับทางเลือกที่เป็นไปได้

    แต่คราวนี้ ไม่ใช่แค่ copy เดียวของสถานะที่ถูกจัดให้ใช้ได้ แต่มี copies อิสระ จำนวนมากที่ถูกจัดให้ใช้ได้ นั่นคือ ระบบ NNN ตัวที่เหมือนกัน X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ แต่ละตัวถูกเตรียมอย่างอิสระในสถานะ ρ\rhoρ สำหรับจำนวน NNN บางค่า (อาจมาก) เป้าหมายคือการหาค่าประมาณของสถานะที่ไม่รู้จัก ในรูป density matrix โดยการวัดระบบต่างๆ

การแยกแยะระหว่างสองสถานะ​

กรณีที่ง่ายที่สุดสำหรับการแยกแยะสถานะควอนตัมคือมีสองสถานะ ρ0\rho_0ρ0​ และ ρ1\rho_1ρ1​ ที่ต้องแยกแยะ

ลองนึกถึงสถานการณ์ที่บิต aaa ถูกเลือกแบบสุ่ม: a=0a = 0a=0 ด้วยความน่าจะเป็น ppp และ a=1a = 1a=1 ด้วยความน่าจะเป็น 1−p1 - p1−p ระบบ X\mathsf{X}X ถูกเตรียมในสถานะ ρa\rho_aρa​ หมายถึง ρ0\rho_0ρ0​ หรือ ρ1\rho_1ρ1​ ขึ้นอยู่กับค่าของ aaa และถูกมอบให้เรา เป้าหมายของเราคือเดาค่าของ aaa อย่างถูกต้องโดยผ่านการวัดบน X\mathsf{X}X เพื่อให้แม่นยำ เราจะมุ่งหาการวัดที่ทำให้ความน่าจะเป็นที่การเดาถูกต้องสูงสุด

วิธีที่เหมาะสมในการแก้ปัญหานี้เริ่มจาก spectral decomposition ของความแตกต่างแบบ weighted ระหว่าง ρ0\rho_0ρ0​ และ ρ1\rho_1ρ1​ โดยน้ำหนักคือความน่าจะเป็นที่สอดคล้อง

เราสามารถทำให้ความน่าจะเป็นของการเดาถูกสูงสุดได้โดยเลือกการวัดแบบ projective {Π0,Π1}\{\Pi_0,\Pi_1\}{Π0​,Π1​} ดังนี้ ก่อนอื่นให้แบ่งสมาชิกของ {0,…,n−1}\{0,\ldots,n-1\}{0,…,n−1} ออกเป็นสองเซตที่ไม่ซ้อนทับกัน S0S_0S0​ และ S1S_1S1​ ขึ้นอยู่กับว่าค่าเฉพาะที่สอดคล้องของความแตกต่าง weighted ไม่ติดลบหรือติดลบ

นี่คือการวัดที่เหมาะสมที่สุดในสถานการณ์นี้ที่ทำให้ความน่าจะเป็นของการระบุสถานะที่เลือกผิดต่ำที่สุด

ความน่าจะเป็นของความถูกต้อง​

ทีนี้เราจะหาความน่าจะเป็นของความถูกต้องสำหรับการวัด {Π0,Π1}\{\Pi_0,\Pi_1\}{Π0​,Π1​}

การแยกแยะสามสถานะขึ้นไป​

สำหรับการแยกแยะสถานะควอนตัมเมื่อมีสามสถานะขึ้นไป ยังไม่มีวิธีแก้แบบ closed-form สำหรับการวัดที่เหมาะสมที่สุด แม้ว่าจะสามารถกำหนดปัญหาเป็น semidefinite program ได้ — ซึ่งช่วยให้ประมาณการวัดที่เหมาะสมที่สุดเชิงตัวเลขได้อย่างมีประสิทธิภาพด้วยคอมพิวเตอร์

นอกจากนี้ยังสามารถ ยืนยัน (หรือ หักล้าง) ความเหมาะสมที่สุดของการวัดที่กำหนดในงานแยกแยะสถานะผ่านเงื่อนไขที่เรียกว่า Holevo-Yuen-Kennedy-Lax โดยเฉพาะ สำหรับงานแยกแยะสถานะที่นิยามด้วย ensemble

{(p0,ρ0),…,(pm−1,ρm−1)},\{(p_0,\rho_0),\ldots,(p_{m-1},\rho_{m-1})\},{(p0​,ρ0​),…,(pm−1​,ρm−1​)},

การวัด {P0,…,Pm−1}\{P_0,\ldots,P_{m-1}\}{P0​,…,Pm−1​} เหมาะสมที่สุดก็ต่อเมื่อเมทริกซ์

Quantum state tomography​

สุดท้าย เราจะพูดถึงปัญหาของ quantum state tomography สั้นๆ สำหรับปัญหานี้ เราได้รับ copies อิสระจำนวนมาก NNN ของสถานะควอนตัมที่ไม่รู้จัก ρ\rhoρ และเป้าหมายคือการสร้างค่าประมาณ ρ~\tilde{\rho}ρ~​ ของ ρ\rhoρ เพื่อความชัดเจน หมายความว่าเราต้องการหาคำอธิบายเชิงคลาสสิกของ density matrix ρ~\tilde{\rho}ρ~​ ที่ใกล้เคียง ρ\rhoρ มากที่สุด

เราสามารถอธิบายการตั้งค่าในลักษณะต่อไปนี้ได้เช่นกัน density matrix ที่ไม่รู้จัก ρ\rhoρ ถูกเลือก และเราได้รับการเข้าถึงระบบควอนตัม NNN ตัว X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ ซึ่งแต่ละตัวถูกเตรียม อย่างอิสระ ในสถานะ ρ\rhoρ ดังนั้น สถานะของระบบรวม (X1,…,XN)(\mathsf{X}_1,\ldots,\mathsf{X}_N)(X1​,…,XN​) คือ

ρ⊗N=ρ⊗ρ⊗⋯⊗ρ(N times)\rho^{\otimes N} = \rho \otimes \rho \otimes \cdots \otimes \rho \quad \text{($N$ times)}ρ⊗N=ρ⊗ρ⊗⋯⊗ρ(N times)

เป้าหมายคือการวัดระบบ X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ และจากผลลัพธ์ของการวัดเหล่านั้น คำนวณ density matrix ρ~\tilde{\rho}ρ~​ ที่ประมาณ ρ\rhoρ ได้ใกล้เคียง ปรากฏว่านี่เป็นปัญหาที่น่าสนใจมากและมีการวิจัยอย่างต่อเนื่อง

อาจพิจารณากลยุทธ์ประเภทต่างๆ ในการแนวทางปัญหา ตัวอย่างเช่น เราสามารถจินตนาการกลยุทธ์ที่แต่ละระบบ X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ ถูกวัดแยกกัน ตามลำดับ ให้ผลลัพธ์การวัดเป็นลำดับ สามารถทำการเลือกเฉพาะที่แตกต่างกันสำหรับการวัดที่จะทำ รวมถึงการเลือกแบบ adaptive และ non-adaptive กล่าวอีกนัยหนึ่ง การเลือกว่าจะทำการวัดใดบนระบบใดระบบหนึ่งอาจขึ้นหรือไม่ขึ้นกับผลลัพธ์ของการวัดก่อนหน้า จากลำดับผลลัพธ์การวัด จะมีการหาค่าเดา ρ~\tilde{\rho}ρ~​ สำหรับสถานะ ρ\rhoρ — และอีกครั้งมีวิธีการต่างๆ ในการทำเช่นนี้

แนวทางทางเลือกคือทำการ วัดร่วม เดียวของคอลเลกชันทั้งหมด โดยมองว่า (X1,…,XN)(\mathsf{X}_1,\ldots,\mathsf{X}_N)(X1​,…,XN​) เป็นระบบเดียวและเลือกการวัดเดียวที่ผลลัพธ์คือค่าเดา ρ~\tilde{\rho}ρ~​ สำหรับสถานะ ρ\rhoρ ซึ่งอาจนำไปสู่การประมาณที่ดีกว่าที่เป็นไปได้สำหรับการวัดแยกของระบบแต่ละระบบ แม้ว่าการวัดร่วมบนระบบทั้งหมดพร้อมกันน่าจะยากกว่ามากในการนำไปปฏิบัติ

Qubit tomography โดยใช้การวัด Pauli​

ทีนี้เราจะพิจารณา quantum state tomography ในกรณีง่ายที่ ρ\rhoρ เป็น qubit density matrix สมมติว่าเราได้รับ qubit X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ ซึ่งแต่ละตัวอยู่ในสถานะ ρ\rhoρ อย่างอิสระ และเป้าหมายของเราคือคำนวณค่าประมาณ ρ~\tilde{\rho}ρ~​ ที่ใกล้เคียง ρ\rhoρ

กลยุทธ์ของเราคือแบ่ง NNN qubit X1,…,XN\mathsf{X}_1,\ldots,\mathsf{X}_NX1​,…,XN​ ออกเป็นสามกลุ่มที่มีขนาดใกล้เคียงกัน หนึ่งกลุ่มสำหรับแต่ละ Pauli matrix สามตัว σx,\sigma_x,σx​, σy,\sigma_y,σy​, และ σz\sigma_zσz​ จากนั้น qubit แต่ละตัวถูกวัดอย่างอิสระดังนี้

  1. สำหรับ qubit แต่ละตัวในกลุ่มที่เกี่ยวข้องกับ σx\sigma_xσx​ เราทำการวัด σx\sigma_xσx​ หมายความว่า qubit ถูกวัดด้วยฐาน {∣+⟩,∣−⟩}\{\vert + \rangle, \vert -\rangle\}{∣+⟩,∣−⟩} ซึ่งเป็นฐาน orthonormal ของ eigenvectors ของ σx\sigma_xσx​ และผลลัพธ์การวัดที่สอดคล้องคือค่าเฉพาะที่เกี่ยวข้องกับสอง eigenvectors: +1+1+1 สำหรับสถานะ ∣+⟩\vert + \rangle∣+⟩ และ −1-1−1 สำหรับสถานะ ∣−⟩\vert -\rangle∣−⟩ โดยการเฉลี่ยผลลัพธ์ทั้งหมดในสถานะของกลุ่มที่เกี่ยวข้องกับ σx\sigma_xσx​ เราจะได้ค่าประมาณของ expectation value

    ⟨+∣ρ∣+⟩−⟨−∣ρ∣−⟩=Tr⁡(σxρ).\langle + \vert \rho \vert + \rangle - \langle - \vert \rho \vert - \rangle = \operatorname{Tr}(\sigma_x \rho).⟨+∣ρ∣+⟩−⟨−∣ρ∣−⟩=Tr(σx​ρ).

  2. สำหรับ qubit แต่ละตัวในกลุ่มที่เกี่ยวข้องกับ σy\sigma_yσy​ เราทำการวัด σy\sigma_yσy​ การวัดดังกล่าวคล้ายกับการวัด σx\sigma_xσx​ ยกเว้นว่าฐานการวัดคือ {∣ ⁣+ ⁣i⟩,∣ ⁣− ⁣i⟩}\{\vert\! +\!i \rangle, \vert\! -\!i \rangle\}{∣+i⟩,∣−i⟩} ซึ่งเป็น eigenvectors ของ σy\sigma_yσy​ โดยการเฉลี่ยผลลัพธ์ทั้งหมดในสถานะของกลุ่มที่เกี่ยวข้องกับ σy\sigma_yσy​ เราจะได้ค่าประมาณของ expectation value

    ⟨+i∣ρ∣ ⁣+ ⁣i⟩−⟨−i∣ρ∣ ⁣− ⁣i⟩=Tr⁡(σyρ).\langle +i \vert \rho \vert \!+\!i \rangle - \langle -i \vert \rho \vert \!-\!i \rangle = \operatorname{Tr}(\sigma_y \rho).⟨+i∣ρ∣+i⟩−⟨−i∣ρ∣−i⟩=Tr(σy​ρ).

  3. สำหรับ qubit แต่ละตัวในกลุ่มที่เกี่ยวข้องกับ σz\sigma_zσz​ เราทำการวัด σz\sigma_zσz​ คราวนี้ฐานการวัดคือฐาน standard {∣0⟩,∣1⟩}\{\vert 0\rangle, \vert 1 \rangle\}{∣0⟩,∣1⟩} ซึ่งเป็น eigenvectors ของ σz\sigma_zσz​ โดยการเฉลี่ยผลลัพธ์ทั้งหมดในสถานะของกลุ่มที่เกี่ยวข้องกับ σz\sigma_zσz​ เราจะได้ค่าประมาณของ expectation value

    ⟨0∣ρ∣0⟩−⟨1∣ρ∣1⟩=Tr⁡(σzρ).\langle 0 \vert \rho \vert 0 \rangle - \langle 1 \vert \rho \vert 1 \rangle = \operatorname{Tr}(\sigma_z \rho).⟨0∣ρ∣0⟩−⟨1∣ρ∣1⟩=Tr(σz​ρ).

สิ่งสำคัญที่ต้องรู้คือ เมทริกซ์ ρ~\tilde{\rho}ρ~​ ที่ได้ในลักษณะนี้อาจไม่ใช่ density matrix โดยเฉพาะ แม้ว่ามันจะมี trace เท่ากับ 111 เสมอ แต่อาจไม่เป็น positive semidefinite มีกลยุทธ์ที่รู้จักหลายอย่างในการ "ปัดเศษ" ค่าประมาณ ρ~\tilde{\rho}ρ~​ ดังกล่าวให้เป็น density matrix หนึ่งในนั้นคือคำนวณ spectral decomposition แทนที่ค่าเฉพาะที่ติดลบด้วย 000 แล้วทำให้เป็นมาตรฐาน (โดยหารเมทริกซ์ที่ได้ด้วย trace)
