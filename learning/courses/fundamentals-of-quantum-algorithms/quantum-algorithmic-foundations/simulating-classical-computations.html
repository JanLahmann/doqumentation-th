การคำนวณแบบคลาสสิกบนคอมพิวเตอร์ควอนตัม

ต่อไปเราจะหันมาสนใจการใช้งานอัลกอริทึมคลาสสิกบนคอมพิวเตอร์ควอนตัม เราจะเห็นว่าการคำนวณใดๆ ที่ทำด้วยวงจรบูลีนคลาสสิกก็สามารถทำด้วย Circuit ควอนตัมที่มีต้นทุนการคำนวณ asymptotic ใกล้เคียงกันได้เช่นกัน ยิ่งกว่านั้น สิ่งนี้สามารถทำได้ในลักษณะ "สะอาด" ที่จะอธิบายในไม่ช้า ซึ่งเป็นข้อกำหนดสำคัญสำหรับการใช้การคำนวณเหล่านี้เป็นฟังก์ชันย่อยภายในการคำนวณควอนตัมขนาดใหญ่กว่า

การจำลองวงจรบูลีนด้วยวงจรควอนตัม​

วงจรบูลีนประกอบด้วย Gate AND, OR, NOT, และ FANOUT เพื่อจำลองวงจรบูลีนด้วยวงจรควอนตัม เราจะเริ่มต้นด้วยการแสดงให้เห็นว่า Gate ทั้งสี่ตัวนั้นสามารถจำลองด้วย Gate ควอนตัมได้อย่างไร เมื่อทำเสร็จแล้ว การแปลงวงจรบูลีนที่กำหนดเป็นวงจรควอนตัมเป็นเรื่องง่ายแค่การจำลองทีละ Gate เราจะต้องการเพียง NOT Gate, controlled-NOT Gate, และ Toffoli Gate ในการทำสิ่งนี้ ซึ่งทั้งหมดเป็นการดำเนินการแบบ deterministic นอกเหนือจากเป็น unitary

Toffoli Gate​

Toffoli Gate สามารถอธิบายได้อีกทางว่าเป็น controlled-controlled-NOT Gate ซึ่งมีการกระทำบนสถานะฐานมาตรฐานดังที่แสดงในภาพต่อไปนี้

โดยคำนึงว่าเราใช้แบบแผนการจัดเรียงของ Qiskit ซึ่ง Qubit ถูกจัดเรียงในลำดับนัยสำคัญที่เพิ่มขึ้นจากบนลงล่าง การแสดงแทนเมทริกซ์ของ Gate นี้มีดังนี้

อีกวิธีคิดเกี่ยวกับ Toffoli Gate คือโดยพื้นฐานแล้วมันเป็น query gate สำหรับฟังก์ชัน AND ในแง่ที่ว่ามันเป็นไปตามรูปแบบที่เราเห็นในบทเรียนก่อนหน้าสำหรับการใช้งาน unitary query gate ของฟังก์ชันใดๆ ที่มีอินพุตและเอาต์พุตเป็นสตริงไบนารี

Toffoli Gate ไม่ได้รวมอยู่ในชุด Gate ค่าเริ่มต้นที่พูดถึงก่อนหน้าในบทเรียน แต่เป็นไปได้ที่จะสร้าง Toffoli Gate จาก Gate H,H,H, T,T,T, T†,T^{\dagger},T†, และ CNOT ดังนี้

การจำลอง Boolean Gate ด้วย Toffoli, controlled-NOT, และ NOT Gate​

Toffoli Gate หนึ่งตัว ใช้ร่วมกับ NOT Gate สองสามตัว สามารถใช้งาน AND และ OR Gate ได้ และ FANOUT Gate สามารถใช้งานได้ง่ายโดยใช้ controlled-NOT Gate ดังที่ภาพต่อไปนี้แนะนำ

ในทั้งสามกรณี Qubit ที่ AND, OR, และ FANOUT Gate กระทำบนจะมาจากด้านซ้ายเป็นอินพุต และเรายังต้องการ Qubit workspace หนึ่งตัวที่เริ่มต้นในสถานะศูนย์สำหรับแต่ละตัว Qubit workspace เหล่านี้ปรากฏอยู่ในกล่องที่แสดงการใช้งาน Gate เพื่อแนะนำว่าเป็นของใหม่ และดังนั้นเป็นส่วนหนึ่งของต้นทุนของการใช้งานเหล่านี้

สำหรับ AND และ OR Gate เรายังมี Qubit สองตัวเหลืออยู่ นอกเหนือจาก Qubit เอาต์พุต ตัวอย่างเช่น ภายในกล่องในภาพที่แสดงการจำลองของ AND Gate Qubit สองตัวบนถูกปล่อยอยู่ในสถานะ ∣a⟩\vert a\rangle∣a⟩ และ ∣b⟩\vert b\rangle∣b⟩ Qubit เหล่านี้แสดงว่าอยู่ภายในกล่องเพราะไม่จำเป็นต้องใช้อีกต่อไปและไม่ได้เป็นส่วนหนึ่งของเอาต์พุต พวกมันสามารถถูกละเลยในตอนนี้ แม้ว่าเราจะหันมาสนใจพวกมันในไม่ช้า

Boolean Gate ที่เหลือคือ NOT Gate รวมอยู่ในชุด Gate ควอนตัมค่าเริ่มต้นของเรา ดังนั้นเราไม่จำเป็นต้องจำลองตัวนี้

การจำลอง Gate ต่อ Gate ของวงจรบูลีน​

ทีนี้สมมติว่าเรามีวงจรบูลีนธรรมดาชื่อ CCC ที่ประกอบด้วย AND, OR, NOT, และ FANOUT Gate และมีบิตอินพุต nnn บิตและเอาต์พุต mmm บิต กำหนด t=size⁡(C)t = \operatorname{size}(C)t=size(C) เป็นจำนวน Gate ใน CCC และตั้งชื่อ fff ให้กับฟังก์ชันที่ CCC คำนวณ ซึ่งมีรูปแบบ

f:Σn→Σmf:\Sigma^n\rightarrow\Sigma^mf:Σn→Σm

สำหรับ Σ={0,1}\Sigma = \{0,1\}Σ={0,1}

ทีนี้พิจารณาสิ่งที่เกิดขึ้นเมื่อเราไปทีละตัวผ่าน AND, OR, และ FANOUT Gate ของ CCC แทนที่แต่ละตัวด้วยการจำลองที่สอดคล้องกันที่อธิบายข้างต้น รวมถึงการเพิ่ม Qubit workspace ที่จำเป็น ตั้งชื่อวงจรที่ได้ว่า RRR และจัดเรียง Qubit ของ RRR ให้บิตอินพุต nnn บิตของ CCC สอดคล้องกับ Qubit บนสุด nnn ตัวของ RRR และ Qubit workspace อยู่ด้านล่าง

ที่นี่ kkk คือจำนวน Qubit workspace ที่จำเป็น ซึ่งหนึ่งตัวสำหรับแต่ละ AND, OR, และ FANOUT Gate ของ CCC และ ggg เป็นฟังก์ชันในรูปแบบ g:Σn→Σn+k−mg:\Sigma^n \rightarrow \Sigma^{n+k-m}g:Σn→Σn+k−m ที่อธิบายสถานะของ Qubit ที่เหลืออยู่ที่สร้างโดยการจำลอง Gate หลังจากรัน RRR ในภาพ Qubit ที่สอดคล้องกับเอาต์พุต f(x)f(x)f(x) อยู่ด้านบนและ Qubit ที่เหลืออยู่ที่จัดเก็บ g(x)g(x)g(x) อยู่ด้านล่าง เราสามารถบังคับให้เป็นเช่นนี้ได้ถ้าต้องการโดยจัดเรียง Qubit ใหม่โดยใช้ SWAP Gate ซึ่งสามารถใช้งานได้ด้วย controlled-NOT Gate สามตัวแบบนี้:

อย่างที่เราจะเห็นในส่วนถัดไป ไม่จำเป็นต้องจัดเรียง Qubit เอาต์พุตใหม่แบบนี้จริงๆ แต่ก็ง่ายพอที่จะทำถ้าเลือก

ฟังก์ชัน ggg ที่อธิบายสถานะคลาสสิกของ Qubit ที่เหลืออยู่ถูกกำหนดโดยวงจร CCC แต่จริงๆ แล้วเราไม่จำเป็นต้องกังวลมากนักเกี่ยวกับมัน เราไม่สนใจโดยเฉพาะว่า Qubit เหล่านี้อยู่ในสถานะอะไรเมื่อการคำนวณเสร็จสิ้น ตัวอักษร ggg มาหลัง fff ดังนั้นเป็นชื่อที่สมเหตุสมผลสำหรับฟังก์ชันนี้ด้วยเหตุนั้น แต่มีเหตุผลที่ดีกว่าในการเลือกชื่อ ggg มันย่อมาจาก garbage (ขยะ)

การเก็บกวาดขยะ​

ถ้าความสนใจเดียวของเราคือการประเมินฟังก์ชัน fff ที่คำนวณโดยวงจรบูลีน CCC ด้วยวงจรควอนตัม เราไม่จำเป็นต้องไปไกลกว่าการจำลอง Gate ต่อ Gate ที่อธิบายไว้ ซึ่งหมายความว่า นอกเหนือจากเอาต์พุตของฟังก์ชัน เราจะมีขยะหลายอย่างเหลืออยู่

อย่างไรก็ตาม สิ่งนี้ไม่เพียงพอถ้าเราต้องการดำเนินการคำนวณคลาสสิกเป็นฟังก์ชันย่อยภายในการคำนวณควอนตัมขนาดใหญ่กว่า เพราะ Qubit ขยะเหล่านั้นจะก่อให้เกิดปัญหา ปรากฏการณ์ interference มีความสำคัญอย่างยิ่งต่ออัลกอริทึมควอนตัม และ Qubit ขยะสามารถทำลายรูปแบบ interference ที่จำเป็นในการทำงานของอัลกอริทึมควอนตัม

โชคดี ไม่ยากที่จะเก็บกวาดขยะ กุญแจสำคัญคือการใช้ข้อเท็จจริงที่ว่าเนื่องจาก RRR เป็นวงจรควอนตัม เราสามารถรันมันย้อนกลับได้ โดยเพียงแทนที่แต่ละ Gate ด้วย inverse ของมันและใช้พวกมันในลำดับย้อนกลับ จึงได้วงจรควอนตัมสำหรับการดำเนินการ R†R^{\dagger}R† Toffoli Gate, CNOT Gate, และ NOT Gate จริงๆ แล้วเป็น inverse ของตัวเอง ดังนั้นการรัน RRR ย้อนกลับเป็นเรื่องของการใช้ Gate ในลำดับย้อนกลับเท่านั้น แต่โดยทั่วไปมากขึ้น วงจรควอนตัมใดๆ สามารถย้อนกลับได้ดังที่เพิ่งอธิบาย

โดยเฉพาะอย่างยิ่ง สิ่งที่เราสามารถทำได้คือเพิ่ม Qubit อีก mmm ตัว (โดยระลึกว่าฟังก์ชัน fff มีบิตเอาต์พุต mmm บิต) ใช้ CNOT Gate เพื่อคัดลอกเอาต์พุตของ RRR ไปยัง Qubit เหล่านี้ และย้อนกลับ RRR เพื่อเก็บกวาดขยะ ภาพต่อไปนี้แสดงวงจรที่ได้และอธิบายการกระทำบนสถานะฐานมาตรฐาน

ถ้าเราใส่กล่องล้อมรอบวงจรทั้งหมดและเรียกมันว่า QQQ มันจะมีลักษณะดังนี้:

ถ้าเราละเลย Qubit workspace kkk ตัวเพิ่มเติม สิ่งที่เรามีคือวงจร QQQ ที่ทำงานเหมือน query gate สำหรับฟังก์ชัน fff พอดี ถ้าเราแค่ต้องการคำนวณฟังก์ชัน fff บนสตริง xxx บางตัว เราสามารถตั้งค่า y=0my = 0^my=0m และค่าที่ได้ f(x)f(x)f(x) จะปรากฏบน Qubit mmm ตัวล่าง หรือเราสามารถป้อนสถานะที่แตกต่างออกไปให้กับ Qubit mmm ตัวล่างถ้าต้องการ (อาจจะเพื่อใช้ประโยชน์จาก phase kickback เหมือนในอัลกอริทึมของ Deutsch หรือ Deutsch-Jozsa)

ซึ่งหมายความว่าสำหรับอัลกอริทึม query ใดๆ ถ้าเรามีวงจรบูลีนที่คำนวณฟังก์ชันอินพุต เราสามารถแทนที่แต่ละ query gate ด้วยการใช้งาน Circuit ของมัน และอัลกอริทึม query จะทำงานอย่างถูกต้อง

สังเกตว่า Qubit workspace จำเป็นเพื่อให้กระบวนการนี้ทำงานได้ แต่พวกมันถูกส่งกลับสู่สถานะเริ่มต้นเมื่อ Circuit รวมดำเนินการเสร็จสิ้น สิ่งนี้ช่วยให้ Qubit เหล่านี้สามารถใช้อีกครั้งเป็น Qubit workspace สำหรับวัตถุประสงค์อื่นๆ ยังมีกลยุทธ์ที่รู้จักในการลดจำนวน Qubit workspace ที่จำเป็น (ซึ่งมีต้นทุนทำให้วงจรใหญ่ขึ้น) แต่เราจะไม่พูดถึงกลยุทธ์เหล่านั้นที่นี่

การใช้งานฟังก์ชันที่ invertible​

การสร้างที่อธิบายไว้ช่วยให้เราจำลองวงจรบูลีนใดๆ ด้วยวงจรควอนตัมในลักษณะที่ปราศจากขยะ ถ้า CCC เป็นวงจรบูลีนที่ใช้งานฟังก์ชัน f:Σn→Σmf:\Sigma^n \rightarrow \Sigma^mf:Σn→Σm เราจะได้วงจรควอนตัม QQQ ที่ดำเนินการดังนี้บนสถานะฐานมาตรฐาน

คำตอบคือใช่ โดยต้องอนุญาตให้ใช้ Qubit workspace และนอกเหนือจากมีวงจรบูลีนที่คำนวณ fff เรายังต้องมีวงจรที่คำนวณ f−1f^{-1}f−1 ด้วย ดังนั้น นี่ไม่ใช่ทางลัดสำหรับการ invert ฟังก์ชันในเชิงการคำนวณเมื่อเราไม่รู้วิธีทำแล้ว! ภาพต่อไปนี้แสดงให้เห็นว่าสามารถทำได้อย่างไรโดยการประกอบวงจรควอนตัมสองตัว QfQ_fQf​ และ Qf−1Q_{f^{-1}}Qf−1​ ซึ่งได้มาแยกกันสำหรับฟังก์ชัน fff และ f−1f^{-1}f−1 ผ่านวิธีการที่อธิบายข้างต้น ร่วมกับ SWAP Gate nnn ตัว โดยกำหนดให้ kkk เป็นค่าสูงสุดของจำนวน Qubit workspace ที่ QfQ_fQf​ และ Qf−1Q_{f^{-1}}Qf−1​ ต้องการ
