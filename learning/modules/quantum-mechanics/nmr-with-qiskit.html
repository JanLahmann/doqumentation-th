บทนำ​

เมื่อนักเคมีทำการทดลอง NMR พวกเขาวางตัวอย่างสปินของนิวเคลียสในสนามแม่เหล็กแรงสูง ส่งพัลส์ความถี่วิทยุ (RF) แล้ววัดสัญญาณที่ตอบกลับมา เทคนิคนี้ตั้งอยู่บนแนวคิดไม่กี่ข้อจากกลศาสตร์ควอนตัมของอนุภาคสปิน 1/2 ในสนามแม่เหล็ก สปินมีระดับพลังงานสองระดับที่ห่างกันด้วยพลังงานที่สอดคล้องกับความถี่ Larmor เฉพาะตัว พัลส์เรโซแนนซ์ที่ความถี่นั้นพลิกสปินไปยังระนาบขวาง ซึ่งสปินจะหมุนควง (precess) และเหนี่ยวนำสัญญาณที่จากนั้นค่อยๆ จางลงด้วยเวลาลักษณะเฉพาะสองค่า คือ T1T_1T1​ และ T2T_2T2​

qubit แบบตัวนำยิ่งยวดคือเวอร์ชันที่ออกแบบขึ้นของวัตถุเดียวกัน คือระบบควอนตัมสองระดับที่ควบคุมได้ สถานะ ∣0⟩|0\rangle∣0⟩ และ ∣1⟩|1\rangle∣1⟩ เปรียบได้กับสปินขึ้นและสปินลง Gate ที่เราใช้หมุนมันเปรียบได้กับพัลส์ RF และมันสูญเสียความต่อเนื่องเชิงควอนตัมด้วย T1T_1T1​ และ T2T_2T2​ ของตัวเอง นี่ไม่ใช่แค่การเปรียบเทียบหลวมๆ โปรเซสเซอร์ควอนตัมเชิงทดลองยุคแรกๆ บางตัวในช่วงปลายทศวรรษ 1990 และต้นทศวรรษ 2000 ใช้ NMR

ในโมดูลนี้ คุณจะใช้คอมพิวเตอร์ควอนตัมจริงรันการทดลองระบุลักษณะแบบเดียวกับที่นักสเปกโทรสโกปี NMR (หรือวิศวกรควอนตัมที่สอบเทียบฮาร์ดแวร์) ทำ

  • Rabi / nutation — ขับสปินแล้วดูมันหมุน นี่คือวิธีสอบเทียบการหมุน π\piπ หรือ π/2\pi/2π/2

  • T1T_1T1​ — การคลายตัวแบบสปิน-แลตทิซ คือการที่สปินกระตุ้นสลายกลับสู่สมดุล

  • T2T_2T2​ — การคลายตัวแบบสปิน-สปิน (dephasing) วัดด้วยการทดลอง Ramsey และรีโฟกัสด้วย Hahn echo

  • สเปกโทรสโกปี NMR (chemical shift และ JJJ-coupling) — จำลองโมเลกุลขนาดเล็กบน qubit หลายตัวและอ่านสเปกตรัม multiplet เพื่อกู้คืนการเชื่อมต่อผ่านกฎ n+1n+1n+1

สำหรับแต่ละแนวคิด เราให้ทฤษฎีขั้นต่ำก่อน แล้วจึงสร้างการทดลองใน Qiskit ตามเวิร์กโฟลว์ Qiskit patterns สี่ขั้นตอน

import numpy as np
from itertools import combinations
from qiskit_aer import AerSimulator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import EstimatorV2 as Estimator

USE_HARDWARE = True  # <-- set True to run on the QPU selected above
USE_BATCH = False  # Safer for a class with pauses; set True for an uninterrupted run

if USE_HARDWARE:
    run_backend = backend  # the real QPU selected above
else:
    # Local testing mode: an Aer simulator that mimics the selected device -- its noise model,
    # coupling map, and qubit count -- while layout choices still use real calibration data.
    run_backend = AerSimulator.from_backend(backend)

# --- Choose connected qubits with low readout error. --------------------------------------
def readout_error(q):
    props = backend.target["measure"].get((q,))
    return props.error if props is not None and props.error is not None else 1.0

coupling_map = backend.coupling_map or backend.target.build_coupling_map()
edges = {tuple(sorted(edge)) for edge in coupling_map.get_edges() if edge[0] != edge[1]}

# AX needs one connected pair.
AX_LAYOUT = list(min(edges, key=lambda edge: sum(readout_error(q) for q in edge)))

# AX2 needs one qubit connected to two neighbours; the first entry is the central A qubit.
neighbors = {q: set() for q in range(backend.num_qubits)}
for q0, q1 in edges:
    neighbors[q0].add(q1)
    neighbors[q1].add(q0)
ax2_layouts = (
    [a, x1, x2]
    for a, adjacent in neighbors.items()
    for x1, x2 in combinations(adjacent, 2)
)
AX2_LAYOUT = min(ax2_layouts, key=lambda layout: sum(readout_error(q) for q in layout))

# Use a long-lived qubit for the single-qubit experiments.
def best_qubit(backend):
    return max(
        range(backend.num_qubits), key=lambda q: backend.qubit_properties(q).t2 or 0.0
    )

QUBIT = best_qubit(backend)
qp = backend.qubit_properties(QUBIT)
print(
    f"Using qubit {QUBIT} for single-qubit experiments: "
    f"T1 = {qp.t1 * 1e6:.0f} us, T2 = {qp.t2 * 1e6:.0f} us"
)
print(f"Using physical qubits {AX_LAYOUT} for AX")
print(f"Using physical qubits {AX2_LAYOUT} for AX2 (A first, then the two X spins)")

pm_q = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=[QUBIT]
)
pm_ax = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX_LAYOUT
)
pm_ax2 = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX2_LAYOUT
)

# Job mode is the default because a classroom pause can deactivate a Batch. On the Open plan,
# a Batch has a 10-minute maximum lifetime and deactivates after 1 minute with no queued job.
batch = Batch(backend=run_backend) if USE_BATCH else None
execution_mode = batch if batch is not None else run_backend
sampler = Sampler(mode=execution_mode)
estimator = Estimator(mode=execution_mode)
estimator.options.resilience_level = 0  # raw expectation values, no error mitigation
estimator.options.default_shots = 1000

mode_name = "Batch" if USE_BATCH else "individual jobs"
device_name = "hardware" if USE_HARDWARE else "local simulator (runtime local mode)"
print(f"Ready. Running on {device_name} using {mode_name}.")

การทดลอง: การแกว่งแบบ Rabi (nutation)​

ทฤษฎี​

ขับสปินที่เรโซแนนซ์ แล้วเวกเตอร์ Bloch ของมันจะหมุนสม่ำเสมอจากขั้วหนึ่งไปอีกขั้ว — มันนูเทต ถ้าเราใช้การหมุนด้วยมุมพลิก θ\thetaθ รอบแกน xxx กับ qubit ที่เริ่มที่ ∣0⟩|0\rangle∣0⟩ ความน่าจะเป็นที่จะพบมันใน ∣1⟩|1\rangle∣1⟩ คือ

P1(θ)=sin⁡2 ⁣(θ2)=12(1−cos⁡θ).P_1(\theta) = \sin^2\!\left(\tfrac{\theta}{2}\right) = \tfrac{1}{2}\bigl(1 - \cos\theta\bigr).P1​(θ)=sin2(2θ​)=21​(1−cosθ).

นี่คือเส้นโค้ง Rabi ค่าสูงสุดแรกคือพัลส์ π\piπ (การกลับสถานะเต็มที่ คือพัลส์ 180∘180^\circ180∘) ส่วนพัลส์ π/2\pi/2π/2 คือการหมุนหนึ่งในสี่รอบ (พัลส์ 90∘90^\circ90∘ ที่พลิกสปินไปยังระนาบขวาง) ใน NMR เส้นโค้งนี้คือวิธีที่คุณสอบเทียบพัลส์ของคุณ

ข้อควรระวังของการทดลอง

การทดลอง Rabi ตามตัวอักษร กวาดแอมพลิจูดหรือระยะเวลาของการขับตามเวลา ซึ่งต้องใช้การควบคุมระดับพัลส์ ที่ถูกถอดออกใน Qiskit v2.0 ที่นี่เราจึงกวาดมุมหมุน θ\thetaθ ของ Gate RX(θ)R_X(\theta)RX​(θ) แทน เส้นโค้งและการระบุ π\piπ/π/2\pi/2π/2 เหมือนกันทุกประการ ต่างกันแค่เราเลือกมุมโดยตรงแทนการสอบเทียบความยาวพัลส์ บนฮาร์ดแวร์ที่มี fractional gate RX(θ)R_X(\theta)RX​(θ) สำหรับ θ\thetaθ ใดๆ จะรันแบบเนทีฟ

ทฤษฎี​

เมื่อปล่อยไว้เฉยๆ สปินที่ถูกกระตุ้นจะคายพลังงานให้สิ่งแวดล้อมรอบตัว ("lattice") และคลายตัวกลับสู่สมดุลทางความร้อน ประชากรของสถานะกระตุ้นลดลงแบบเอกซ์โพเนนเชียลด้วย เวลาคลายตัวแบบ spin-lattice T1T_1T1​:

P1(τ)=e−τ/T1.P_1(\tau) = e^{-\tau/T_1}.P1​(τ)=e−τ/T1​.

สำหรับนักเคมี T1T_1T1​ กำหนด recycle delay ที่คุณต้องรอระหว่างการสแกนใน NMR เชิงปริมาณ และยังบอกถึง การหมุนควงของโมเลกุล และพลวัตด้วย สำหรับ qubit มันคือเวลาคลายตัวของพลังงาน และเป็นหนึ่งในสองค่าหลักที่ใช้สร้างแบบจำลองผลของ decoherence ในคอมพิวเตอร์ควอนตัม

# Scale the T1 delay sweep to the qubit's reported coherence, and snap each delay to an integer
# number of samples (dt) so there are no "duration rounded" warnings (as in the Ramsey/echo cells).
T1_us = (backend.qubit_properties(QUBIT).t1 or 100e-6) * 1e6  # reported T1 (us)
delays_us = np.linspace(0, 5 * T1_us, 20)  # 0 .. ~5 T1 captures the full decay
print(f"T1 sweep: 0..{5*T1_us:.0f} us in {len(delays_us)} points")

dt = backend.dt
t1_circuits = []
for tau in delays_us:
    n_dt = int(round(tau * 1e-6 / dt))  # integer samples -> no rounding warning
    qc = QuantumCircuit(1, 1)
    qc.x(0)  # pi pulse: prepare |1>
    qc.delay(n_dt, 0, unit="dt")  # wait tau
    qc.measure(0, 0)
    t1_circuits.append(qc)

t1_isa = pm_q.run(t1_circuits)

Execute​

t1_job = sampler.run([(c,) for c in t1_isa], shots=1000)

วิเคราะห์ — ฟิตเอกซ์โพเนนเชียล​

from scipy.optimize import curve_fit

p1_t1 = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in t1_res]
)

def decay(t, A, T1, B):
    return A * np.exp(-t / T1) + B

p0 = [1.0, 100.0, 0.0]
popt, _ = curve_fit(decay, delays_us, p1_t1, p0=p0, maxfev=10000)
T1_fit = popt[1]

plt.figure(figsize=(7, 4))
plt.plot(delays_us, p1_t1, "o", label="measured")

การทดลอง: T2T_2T2​, T2∗T_2^*T2∗​​

ทฤษฎี​

T1T_1T1​ วัดการสูญเสีย พลังงาน ส่วน T2T_2T2​ วัดการสูญเสีย phase coherence ในระนาบตามขวาง เราสังเกตสิ่งนี้ได้ด้วย การทดลอง Ramsey: พัลส์ π/2\pi/2π/2 หมุนสปินทั้งหมดลงมาที่เส้นศูนย์สูตร โดยทุกตัวชี้ไปทิศเดียวกัน พวกมันหมุนควงแบบ Larmor แต่แต่ละตัวหมุนควงด้วยความถี่ต่างกันเล็กน้อย จึงกระจายออกเป็นพัดตามเส้นศูนย์สูตร และสัญญาณตามขวางรวมจะสลายตัวด้วยเวลาสลายตัวลักษณะเฉพาะ T2∗T_2^*T2∗​

ข้อสังเกตสำหรับผู้อ่านสายควอนตัม: ภาพการกระจายเป็นพัดแสดงวิธีหนึ่งของการสูญเสีย coherence คือการที่เฟสที่แน่นอนหลายค่ากระจายตัวแล้วหักล้างกันไป ควรรู้ว่านี่ไม่ใช่กลไกเดียว coherence อาจสูญเสียได้เพราะเฟสพันกัน (entangle) กับสิ่งแวดล้อม จนมันไม่ใช่ค่าที่แน่นอนซึ่งระบบถืออยู่อีกต่อไปเลย เราแยกสองกลไกนี้ออกจากกันไม่ได้ด้วยการดูแค่การสลายตัวของสัญญาณ ดังนั้นภาพการกระจายเป็นพัดจึงเป็นสัญชาตญาณที่ดี แต่ระวังอย่าตีความว่าเป็นเรื่องราวที่สมบูรณ์หรือตามตัวอักษร

มีสองผลที่ทำให้สปินเสียเฟส:

  • decoherence ที่ย้อนกลับไม่ได้ (หรือแทบย้อนกลับไม่ได้) ซึ่งเกิดจากการเชื่อมโยงที่ควบคุมไม่ได้กับองศาอิสระอื่น ลักษณะเฉพาะด้วย T2T_2T2​ ที่แท้จริง ใน NMR ส่วนใหญ่มาจากการเคลื่อนที่ของโมเลกุลที่ปรับการเชื่อมโยงระหว่างสปิน ในคอมพิวเตอร์ควอนตัม มันสอดคล้องกับการเชื่อมโยงที่ไม่ต้องการระหว่าง qubit กับสิ่งแวดล้อม
  • ออฟเซตความถี่ที่คงที่หรือเปลี่ยนช้า ซึ่งย้อนกลับได้ เช่น ความไม่สม่ำเสมอของสนาม ความต่างของความถี่ระหว่าง qubit และข้อผิดพลาดจากการ calibrate เมื่อรวมกับ T2T_2T2​ ที่แท้จริง จะให้เวลาสลายตัวปรากฏที่สั้นลงคือ T2∗T_2^*T2∗​ ที่สังเกตได้ในการทดลอง Ramsey

แล้วเราจะหา T2T_2T2​ ที่แท้จริงได้อย่างไร ถ้าการทดลอง Ramsey บอกได้แค่ T2∗T_2^*T2∗​ การทดลองที่สองเรียกว่า Hahn echo ซึ่งหักล้างสัญญาณรบกวนประเภทที่สองทั้งหมดเพื่อหา T2T_2T2​ ที่แท้จริง มันเริ่มเหมือนการทดลอง Ramsey ด้วยพัลส์ π/2\pi/2π/2 แล้วสปินกระจายออกเหมือนเดิม หลังเวลาผ่านไป τ\tauτ จะใส่พัลส์ π\piπ พัลส์นี้ย้อนการสะสมเฟสที่เกิดจากออฟเซตความถี่คงที่ ทำให้สปินกลับมารวมกันอีกครั้งหลังการหน่วงครั้งที่สองที่ยาวเท่ากันคือ τ\tauτ

ทั้ง T2∗T_2^*T2∗​ และ T2T_2T2​ เป็นตัวเลขสำคัญที่ควรรู้ ทั้งในบริบทเคมีและบริบทคอมพิวเตอร์ควอนตัม ในบริบทเคมี T2∗T_2^*T2∗​ กำหนดความกว้างเส้น (linewidth) ในการทดลอง NMR มาตรฐาน (คุณจะเห็นความหมายในส่วนถัดไป) T2T_2T2​ บอกเรื่องโมเลกุลได้มาก เช่น การหมุนควงของโมเลกุล และการเปลี่ยนแปลงของ T2T_2T2​ อาจบ่งว่าโมเลกุลไปจับกับสิ่งที่ใหญ่กว่า ในบริบทคอมพิวเตอร์ควอนตัม โดยทั่วไปเราต้องการให้ทั้ง T2T_2T2​ และ T2∗T_2^*T2∗​ ยาวที่สุดเท่าที่จะทำได้ เพื่อให้มีเวลาทำการทดลองมากขึ้นก่อนที่ decoherence จะครอบงำระบบ เทคนิคทั้งตระกูลที่อิงกับ Hahn echo ช่วยยืดเวลานี้ด้วยการหักล้างสัญญาณรบกวนที่ย้อนกลับได้ ทำให้ circuit ถูกจำกัดด้วย T2T_2T2​ ที่แท้จริงในอุดมคติ ไม่ใช่ T2∗T_2^*T2∗​ เทคนิคนี้เรียกว่า "dynamical decoupling"

การทำให้เป็นจริง​

เมื่อเราทำการทดลอง Ramsey และ Hahn echo บน qubit การอ่านค่าจะต่างจากกรณี NMR เล็กน้อย ใน NMR คุณสังเกตสนามที่แกว่งซึ่งเหนี่ยวนำโดยสปินที่หมุนควงที่ความถี่ Larmor ในระนาบตามขวางได้โดยตรง แต่กับ qubit เราวัดได้เพียงการฉายลงบนแกน ZZZ คือเป็น ∣0⟩\vert 0 \rangle∣0⟩ หรือ ∣1⟩\vert 1 \rangle∣1⟩ ดังนั้นในทั้งสองการทดลอง เราจึงปิดท้ายด้วยพัลส์ π/2\pi/2π/2 เพิ่มอีกหนึ่งครั้งแล้วจึงวัด พัลส์ π/2\pi/2π/2 นี้แปลงข้อมูลเฟสของ qubit ให้เป็นประชากร

ด้านล่างเรารันแต่ละการทดลองเพื่อหา T2∗T_2^*T2∗​ และ T2T_2T2​

Ramsey (T2∗T_2^{*}T2∗​): พัลส์ π/2\pi/2π/2 สองครั้งโดยมีเวลาหน่วง τ\tauτ​

พัลส์ π/2\pi/2π/2 แรกพาเวกเตอร์ Bloch ไปที่เส้นศูนย์สูตร และพัลส์ถัดไปแปลงเฟสของเวกเตอร์ Bloch ให้เป็นประชากร เนื่องจากเฟสเปลี่ยนตามเวลาขณะที่เวกเตอร์ Bloch หมุนควง เราจึงเห็นรูปแบบไซน์ในประชากรเป็นฟังก์ชันของเวลาหมุนควง τ\tauτ เมื่อ qubit สูญเสีย phase coherence เราควรเห็นแอมพลิจูดของเส้นไซน์นี้สลายตัวลง

ความละเอียดอ่อนเพิ่มเติมสำหรับผู้อ่านสายควอนตัม: ในการทดลองคอมพิวเตอร์ควอนตัม การแกว่งที่เราเห็นไม่ใช่ที่ความถี่ Larmor จริงๆ ซึ่งอยู่ในช่วง GHz และเร็วเกินกว่าที่เราจะแยกแยะได้ การทดลองควอนตัมทำงานใน rotating frame: กรอบอ้างอิงที่หมุนไปพร้อมกับ qubit ที่ความถี่ (ใกล้) Larmor ทำให้การหมุนควงที่เร็วมองไม่เห็น และเวกเตอร์ Bloch ดูเหมือนแทบนิ่ง เพื่อให้เห็นริ้ว (fringe) เราจงใจตั้ง rotating frame ให้เพี้ยนจากความถี่ Larmor เล็กน้อย เวกเตอร์ Bloch จึงดูเหมือนหมุนควงที่ความเพี้ยนเล็กๆ นั้น และเราได้สัญญาณแกว่งที่ความถี่ของความเพี้ยน ด้านล่างนี้ เราไม่ได้ตรึงความเพี้ยนไว้ที่ค่าเดียว แต่เลือกให้มีริ้วประมาณหนึ่งโหลครอบคลุมช่วงการวัด (ซึ่งเรากำหนดขนาดตามเวลา coherence ของ qubit) ซึ่งทำให้เก็บตัวอย่างการแกว่งได้ง่ายโดยไม่เกิด aliasing อีกเรื่องที่ยุ่งยาก: ใน Qiskit เราไม่มีการควบคุมระดับพัลส์ที่จำเป็นต่อการเปลี่ยนความถี่ของพัลส์ (ซึ่งเป็นตัวกำหนดความถี่ของ rotating frame) แทนที่จะทำเช่นนั้น เราเพิ่มความเพี้ยน ประสิทธิผล ด้วยมือ โดยใช้มันกำหนดเฟสของพัลส์ Ramsey ครั้งที่สอง มันดูประดิษฐ์ไปหน่อย แต่ผลลัพธ์เหมือนกัน และการสลายตัวที่เราสังเกตก็ยังคงเป็น T2∗T_2^*T2∗​ ของจริง

มุมมองบน Bloch sphere​

พัลส์ π/2\pi/2π/2 พาสปินไปที่เส้นศูนย์สูตร จากนั้นแต่ละตัวหมุนควงด้วยอัตราต่างกันเล็กน้อยและ กระจายเป็นพัด ทำให้เวกเตอร์สุทธิ (สีแดง) หดสั้นลงเมื่อพวกมันเสียเฟส — การสลายตัวนี้คือ T2∗T_2^*T2∗​

# Adaptive Ramsey: scale the window to the reported coherence and choose the detuning so a fixed
# number of fringes span it. This decouples the point count from the window -- a long window stays
# cheap and cannot alias (we keep 8 samples per fringe).
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6  # reported (echo) T2 (us)
ramsey_span = 0.5 * T2_us  # window = half the reported T2
n_fringes = 12  # fringes across the window
f_detune = n_fringes / (
    ramsey_span * 1e-6
)  # adaptive detuning (Hz) -> low, so a long window is cheap
samp_per_fringe = 8
n_ramsey = n_fringes * samp_per_fringe + 1  # ~97 points, fixed regardless of T2
ramsey_delays_us = np.linspace(0, ramsey_span, n_ramsey)
print(
    f"Ramsey sweep: 0..{ramsey_span:.0f} us in {n_ramsey} points "
    f"(detuning {f_detune/1e3:.1f} kHz, {samp_per_fringe} samples/fringe)"
)

dt = backend.dt  # seconds per sample
delays_dt = [int(round(t * 1e-6 / dt)) for t in ramsey_delays_us]  # integer samples
actual_delays_us = np.array(delays_dt) * dt * 1e6  # true (snapped) delays for fitting

ramsey_circ = []
for n_dt, tau_us in zip(delays_dt, actual_delays_us):
    qc = QuantumCircuit(1, 1)
    qc.rx(np.pi / 2, 0)
    qc.delay(n_dt, 0, unit="dt")  # integer duration -> no rounding warning
    qc.rz(
        2 * np.pi * f_detune * tau_us * 1e-6, 0
    )  # detuning phase (uses the true delay)
    qc.rx(np.pi / 2, 0)
    qc.measure(0, 0)
    ramsey_circ.append(qc)

ramsey_isa = pm_q.run(ramsey_circ)
ramsey_res = sampler.run([(c,) for c in ramsey_isa], shots=1000).result()
p1_ramsey = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in ramsey_res]
)

ramsey_circ[len(ramsey_circ) // 2].draw("mpl")  # draw a sample circuit (mid-sweep)

Hahn echo (T2T_2T2​): เพิ่มพัลส์ π\piπ ที่ทำให้กลับมารวมกันตรงกลาง​

มุมมองบน Bloch sphere​

Hahn echo: สปินกระจายเป็นพัดเหมือนเดิม จากนั้นพัลส์ π\piπ พลิกพวกมัน ทำให้การหมุนควงต่อเนื่องของพวกมัน รวมกลับมา อีกครั้ง (เวกเตอร์สีแดงโตขึ้นอีก) ฟื้นคืน coherence ที่เสียไปจากการเสียเฟสแบบคงที่

# Scale the echo sweep to the reported (echo) T2. The echo signal is monotonic (no fringes),
# so only the range matters here; 0 .. ~2.5 T2 shows the full decay for a clean fit.
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6
echo_delays_us = np.linspace(0, 2.5 * T2_us, 24)  # total free-evolution time
print(f"Echo sweep: 0..{2.5*T2_us:.0f} us in {len(echo_delays_us)} points")

dt = backend.dt
half_dt = [
    int(round(t / 2 * 1e-6 / dt)) for t in echo_delays_us
]  # samples per half-delay
actual_echo_us = np.array(half_dt) * 2 * dt * 1e6  # true total delay for fitting

echo_circ = []
for n_half in half_dt:
    qc = QuantumCircuit(1, 1)
    qc.rx(np.pi / 2, 0)
    qc.delay(n_half, 0, unit="dt")  # half the free-evolution, integer samples
    qc.rx(np.pi, 0)  # refocusing pi pulse
    qc.delay(n_half, 0, unit="dt")
    qc.rx(-np.pi / 2, 0)
    qc.measure(0, 0)
    echo_circ.append(qc)

echo_isa = pm_q.run(echo_circ)
echo_res = sampler.run([(c,) for c in echo_isa], shots=1000).result()
p1_echo = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in echo_res]
)

echo_circ[len(echo_circ) // 2].draw("mpl")  # draw a sample circuit
Echo sweep: 0..1240 us in 24 points

วิเคราะห์: ฟิตและเปรียบเทียบการสลายตัวทั้งสอง​

# Initial guesses / bounds derived from the reported coherence so the fits track the scaled axes.
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6

# Ramsey: decaying oscillation -> extract T2*
def ramsey_fn(t, A, T2s, f, phi, B):
    return A * np.exp(-t / T2s) * np.cos(2 * np.pi * f * t + phi) + B

rp0 = [0.4, T2_us / 2, f_detune * 1e-6, 0.0, 0.5]  # T2* guess ~ half the echo T2
rbounds = (
    [0, 0.1, 0, -np.pi, 0],
    [1, 2 * T2_us, 5, np.pi, 1],
)  # keep the fit from collapsing to ~0
rpopt, _ = curve_fit(
    ramsey_fn, ramsey_delays_us, p1_ramsey, p0=rp0, bounds=rbounds, maxfev=20000
)
T2_star = abs(rpopt[1])

# Echo: simple exponential envelope -> extract T2
def env(t, A, T2, B):
    return A * np.exp(-t / T2) + B

epopt, _ = curve_fit(env, echo_delays_us, p1_echo, p0=[0.5, T2_us, 0.0], maxfev=10000)
T2 = abs(epopt[1])

fig, ax = plt.subplots(1, 2, figsize=(12, 4))
ax[0].plot(ramsey_delays_us, p1_ramsey, "o")
tt = np.linspace(0, ramsey_delays_us.max(), 400)
ax[0].plot(tt, ramsey_fn(tt, *rpopt), "-")
ax[0].set_title(rf"Ramsey: $T_2^*$ = {T2_star:.1f} µs")
ax[0].set_xlabel("τ (µs)")
ax[0].set_ylabel(r"$P_1$")
ax[1].plot(echo_delays_us, p1_echo, "o")
tt2 = np.linspace(0, echo_delays_us.max(), 400)
ax[1].plot(tt2, env(tt2, *epopt), "-")
ax[1].set_title(rf"Hahn echo: $T_2$ = {T2:.1f} µs")
ax[1].set_xlabel("τ (µs)")
plt.tight_layout()
plt.show()
print(f"T2* (Ramsey) = {T2_star:.1f} µs ;  T2 (echo) = {T2:.1f} µs")

T2* (Ramsey) = 171.2 µs ;  T2 (echo) = 326.0 µs

ตรงนี้เราเห็นทั้งการแกว่งแบบ Ramsey และสัญญาณ Hahn echo สลายตัวตามที่คาด สเกลเวลาของการสลายตัวทั้งสองคือ T2∗T_2^*T2∗​ และ T2T_2T2​ ตามลำดับ

ตรวจสอบความเข้าใจของคุณ​

โดยทั่วไปคุณควรพบว่า T2≳T2∗T_2 \gtrsim T_2^{*}T2​≳T2∗​ จงอธิบายเหตุผลในหนึ่งประโยค และบอกว่าพัลส์ π\piπ ของ Hahn echo ขจัดผลทางกายภาพอะไรได้ และอะไรที่ขจัดไม่ได้

คำตอบ

T2∗T_2^{*}T2∗​ รวมทั้งการเสียเฟสที่ย้อนกลับไม่ได้ และ การกระจายแบบคงที่ที่ย้อนกลับได้ จึงสลายตัวเร็วกว่า พัลส์ π\piπ ของ echo ทำให้การเสียเฟสแบบ คงที่และย้อนกลับได้ (ความไม่สม่ำเสมอของสนาม / ออฟเซตความถี่คงที่) กลับมารวมกัน เหลือเพียงการเสียเฟสแบบ spin-spin ที่ ย้อนกลับไม่ได้ ซึ่งคือ T2T_2T2​ ที่แท้จริง echo ไม่สามารถยกเลิกความผันผวนที่เปลี่ยนไประหว่างสองครึ่งของลำดับได้

NMR spectroscopy ของโมเลกุล: Chemical shift และ JJJ-coupling​

จากสปินเดี่ยวสู่โมเลกุล​

การทดลองที่ผ่านมาศึกษาสปินเดี่ยวที่แยกอิสระ NMR ทางเคมีจริงๆ อ่าน โมเลกุล (สปินจำนวนมากที่เชื่อมโยงกันพร้อมกัน) และใช้สเปกตรัมที่ได้เพื่ออนุมานลักษณะของโครงสร้างโมเลกุล สิ่งนี้บอกเราได้สองผล:

  • Chemical shift นิวเคลียสที่ต่างกันทางเคมีแต่ละตัวหมุนควงที่ความถี่ νi\nu_iνi​ ต่างกันเล็กน้อย เพราะอิเล็กตรอนในบริเวณใกล้เคียงกำบังสนามที่ใช้ในปริมาณต่างกัน ดังนั้น ตำแหน่ง ของพีคจึงระบุสภาพแวดล้อมทางเคมีได้ (เช่น โปรตอนของ CH3_33​ เทียบกับโปรตอนอะโรมาติก)

  • Scalar JJJ-coupling ปฏิสัมพันธ์ผ่านพันธะระหว่างสองสปินแยกแต่ละพีคเป็น multiplet นิวเคลียสที่มีเพื่อนบ้าน เทียบเท่ากัน nnn ตัวจะแยกเป็น n+1n+1n+1 เส้นที่มีความเข้มตามทวินาม เรียกว่า กฎ n+1n+1n+1 รูปแบบ การแยกเผยการเชื่อมต่อ (นิวเคลียสใดเชื่อมพันธะกัน) และระยะห่างคือค่าคงที่การเชื่อมโยง JJJ

การทดลอง​

เพื่อจำลองสิ่งนี้บนคอมพิวเตอร์ควอนตัมของเรา เราต้องสร้าง spin Hamiltonian บน qubit ในลิมิตการเชื่อมโยงอ่อนและสนามสูง (ความต่างของ chemical shift ≫\gg≫ การเชื่อมโยง) ส่วน XXXXXX และ YYYYYY ของการเชื่อมโยงเฉลี่ยหักล้างกันไป เหลือเพียง ZZZZZZ ดังนั้น Hamiltonian คือ (หน่วยความถี่เชิงมุม, ℏ=1\hbar=1ℏ=1):

H=∑iπ νi Zi⏟chemical shift  +  ∑i<jπ2 Jij ZiZj⏟J-coupling.H = \underbrace{\sum_i \pi\,\nu_i\, Z_i}_{\text{chemical shift}} \;+\; \underbrace{\sum_{i<j} \tfrac{\pi}{2}\,J_{ij}\, Z_iZ_j}_{J\text{-coupling}}.H=chemical shifti∑​πνi​Zi​​​+J-couplingi<j∑​2π​Jij​Zi​Zj​​​.

นิวเคลียสแต่ละตัวคือ หนึ่ง qubit: chemical shift คือการหมุน ZZZ บน qubit เดี่ยว และการเชื่อมโยงคือปฏิสัมพันธ์ ZZZZZZ ระหว่างสอง qubit

การทดลองดำเนินดังนี้ พัลส์ π/2\pi/2π/2 พาทุกสปินเข้าสู่ระนาบตามขวาง และสปินหมุนควงและเชื่อมโยงกันเป็นเวลา ttt เราบันทึกแมกเนไทเซชันตามขวางเชิงซ้อน s(t)=⟨X⟩+i⟨Y⟩s(t) = \langle X\rangle + i\langle Y\rangles(t)=⟨X⟩+i⟨Y⟩ ที่รวมจากทุกสปิน เช่นเดียวกับการทดลอง Ramsey ข้างต้น แมกเนไทเซชันตามขวางนี้วาดเป็นไซน์ที่สลายตัวเป็นฟังก์ชันของเวลาหมุนควง ttt เมื่อเราทำการแปลงฟูเรียร์ของสัญญาณ เราจะได้สเปกตรัมที่มีพีคที่ chemical shift νi\nu_iνi​ ซึ่งถูกแยกโดยการเชื่อมโยงสเกลาร์ JijJ_{ij}Jij​

หมายเหตุ

เราจำลองวิวัฒนาการของโมเลกุลโดยแมปเวลา ttt ไปเป็น มุมการหมุน: ttt ที่มากขึ้นหมายถึงการหมุน ZZZ และ ZZZZZZ ที่ใหญ่ขึ้น ไม่ใช่ circuit ที่ยาวหรือลึกขึ้น ดังนั้นแม้สถานะที่จำลองจะก้าวหน้าไปตาม ttt (ซึ่งทำให้ free induction decay (FID) แกว่ง) แต่ qubit จริงไม่เคยอยู่เฉยนานขึ้น และไม่มี decoherence ที่ขึ้นกับ ttt FID ที่จำลองจึงไม่สลายตัวเองเลย สำหรับ FID ในอุดมคติที่ยาวไม่สิ้นสุด เส้นสเปกตรัมจะคมไม่สิ้นสุด แต่หน้าต่างการสุ่มตัวอย่างที่จำกัดของเรากลับให้ความละเอียดจำกัดและอาจทำให้เกิดการรั่วของสเปกตรัม เส้น NMR จริงมีความกว้างจำกัดที่กำหนดโดย T2∗T_2^*T2∗​ เราเติมมันกลับโดยคูณ FID ด้วยหน้าต่าง e−t/T2∗e^{-t/T_2^{*}}e−t/T2∗​ ก่อนการแปลงฟูเรียร์ ซึ่งเรียกว่า line-broadening apodization ที่นักสเปกโทรสโกปีใช้ในการประมวลผลเพื่อกำหนดความกว้างเส้น (แลกความละเอียดกับอัตราส่วนสัญญาณต่อสัญญาณรบกวน) (เซลล์ทางเลือกในภาคผนวกของโมดูลนี้แสดงทางเลือกแบบ Trotterized ที่การสลายตัวมาจาก decoherence จริงซึ่งเพิ่มตามความลึกของ circuit)

ระบบ AX​

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import SparsePauliOp

t = Parameter(
    "t"
)  # evolution time (arbitrary units; the frequencies below are in matching units)

def fid_circuit(offsets, couplings):
    """State-preparation circuit for a set of spins: a pi/2 pulse, then evolution under the
    chemical-shift + J-coupling Hamiltonian for time t. No measurement -- the Estimator reads
    <X> and <Y> directly.

    offsets   : list of chemical-shift frequencies nu_i, one per qubit
    couplings : dict {(i, j): J_ij}
    """
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # pi/2 pulse: tip every spin into the transverse plane
    for i, nu in enumerate(offsets):
        qc.rz(2 * np.pi * nu * t, i)  # chemical-shift precession -> line at nu_i
    for (i, j), J in couplings.items():
        qc.rzz(np.pi * J * t, i, j)  # J-coupling -> splitting of size J
    return qc

def transverse_obs(n):
    """Total transverse observables (sum over spins): (sum_i X_i, sum_i Y_i)."""
    ox = SparsePauliOp.from_sparse_list(
        [("X", [i], 1.0) for i in range(n)], num_qubits=n
    )
    oy = SparsePauliOp.from_sparse_list(
        [("Y", [i], 1.0) for i in range(n)], num_qubits=n
    )
    return ox, oy

# --- time grid ---
n_t = 128  # number of FID samples
dt = 1 / 32  # time step -> Nyquist frequency = 1/(2 dt) = 16 Hz
times = np.arange(n_t) * dt

# --- Step 3-4: Estimator returns <X> and <Y> directly (both quadratures in one job) ---
def run_fid(isa_circ, n, est):
    """Complex FID s(t) = sum_i <X_i> + i <Y_i> over the time grid, via the Estimator."""
    ox, oy = transverse_obs(n)
    ox = ox.apply_layout(isa_circ.layout)  # map observables onto the transpiled qubits
    oy = oy.apply_layout(isa_circ.layout)
    params = times.reshape(-1, 1)
    res = est.run(
        [(isa_circ, ox, params), (isa_circ, oy, params)]
    ).result()  # both quadratures, one job
    return res[0].data.evs + 1j * res[1].data.evs

def spectrum(fid, T2=1.0):
    sig = fid * np.exp(-times / T2)  # apodization -> Lorentzian linewidth ~ 1/(pi T2)
    spec = np.fft.fftshift(np.fft.fft(sig))
    freq = np.fft.fftshift(np.fft.fftfreq(len(times), dt))
    return freq, np.abs(spec)

คำตอบสั้น​

  1. จงอธิบายในสองประโยคว่าทำไมพัลส์ π\piπ เพียงครั้งเดียวจึงเป็นวิธีที่แย่ในการตรวจจับความคลาดเคลื่อนของมุมพลิก 5%5\%5% และการต่อพัลส์หลายครั้งแก้ปัญหานี้อย่างไร

  2. ตัวอย่างหนึ่งแสดงเส้น NMR กว้าง ในแง่ของ T2T_2T2​ สิ่งนี้บอกอะไรคุณ และปริมาณของ qubit ที่เทียบเท่าคืออะไร

  3. จงให้ปริมาณของ qubit ที่เทียบเท่ากับแต่ละข้อ: (a) recycle delay, (b) พัลส์ 90∘90^\circ90∘, (c) chemical shift

  4. จงใช้กฎ n+1n+1n+1 อธิบายว่าทำไมหมู่เอทิล (CH3_33​CH2_22​–) จึงแสดง triplet 1:2:1 และ quartet 1:3:3:1 และระบุว่าหมู่ใดให้ multiplet ใด

โจทย์ท้าทาย​

  1. ขบวน Carr-Purcell ปรับ Hahn echo ให้แทรกพัลส์ π\piπ ที่เว้นระยะเท่ากัน nnn ครั้ง (ขบวนแบบ CPMG) และวัด T2T_2T2​ เป็นฟังก์ชันของ nnn อภิปรายว่าทำไมพัลส์ที่ทำให้กลับมารวมกันมากขึ้นจึงทำให้ T2T_2T2​ ปรากฏยาวขึ้นได้

  2. การขยายความคลาดเคลื่อนของพัลส์ สร้าง circuit ที่ใช้ RX(π)R_X(\pi)RX​(π) ซ้ำ  n\,nn ครั้งกับ ∣0⟩|0\rangle∣0⟩ และพล็อต P1P_1P1​ เทียบกับ nnn สำหรับมุมที่ตั้งผิดโดยตั้งใจ RX(1.05π)R_X(1.05\pi)RX​(1.05π) แสดงให้เห็นว่าความคลาดเคลื่อนมองเห็นได้ชัดขึ้นเมื่อ nnn โตขึ้น คำใบ้: ใส่ barrier หลังการหมุนทุกครั้ง มิฉะนั้น transpiler อาจรวมการหมุนซ้ำๆ เป็นเกตเทียบเท่าเกตเดียว

  3. หมู่เอทิล ใช้ fid_circuit สร้างสเปกตรัมโปรตอนของชิ้นส่วนเอทิล (CH3_33​–CH2_22​): ห้า qubit โดยโปรตอน CH3_33​ สามตัวใช้ chemical shift ร่วมกัน และโปรตอน CH2_22​ สองตัวอีกค่าหนึ่ง และทุกคู่ CH3_33​–CH2_22​ เชื่อมโยงด้วย JJJ เดียวกัน (ไม่มีการเชื่อมโยงภายในกลุ่มที่เทียบเท่ากัน) ทำนายรูปแบบด้วยกฎ n+1n+1n+1 แล้วจำลอง คุณควรได้ quartet 1:3:3:1 (CH2_22​) และ triplet 1:2:1 (CH3_33​)

ภาคผนวก (ทางเลือก): วิวัฒนาการแบบ Trotterized — ให้ decoherence กำหนดความกว้างเส้น​

ในส่วนNMR spectroscopy ของโมเลกุล วิวัฒนาการ e−iHte^{-iHt}e−iHt ถูกใช้ในชั้นเดียวที่ความลึก ไม่ เพิ่มตาม ttt ดังนั้น FID จึงไม่สลายตัวเอง และเรากำหนดความกว้างเส้นด้วยหน้าต่าง apodization e−t/T2e^{-t/T_2}e−t/T2​ เซลล์ทางเลือกนี้ใช้แนวทางตรงข้าม มันแบ่งวิวัฒนาการเป็น ppp ขั้น Trotter และใส่ barrier หลังแต่ละขั้น (เพื่อไม่ให้ transpiler รวมกลับเป็นชั้นเดียว) จุดเวลา kkk ใช้ kkk ขั้น ความลึกของ circuit จึงเพิ่มตามเวลา

เนื่องจากทุกพจน์ใน HHH สลับที่กันได้ วิธีนี้จึง แม่นยำ: บนซิมูเลเตอร์ไร้สัญญาณรบกวนจะได้พีคคมเหมือนกัน แต่บน backend แบบมีโมเดลสัญญาณรบกวนหรือฮาร์ดแวร์จริง ข้อผิดพลาดของเกตที่สะสมทำให้ FID สลายตัวเอง และการสลายตัวนั้นเองกำหนดความกว้างเส้น นี่คือแนวคิด T2↔T_2\leftrightarrowT2​↔ความกว้างเส้น ของส่วนการทดลอง T2T_2T2​, T2∗T_2^*T2∗​ ที่ตอนนี้เกิดจาก decoherence จริงแทนหน้าต่างการประมวลผล เรารันทั้งระบบ AX (สอง doublet) และระบบ AX2_22​ (triplet 1:2:1 กับ doublet) ด้วยวิธีนี้

มีข้อสังเกตเชิงปฏิบัติสองข้อ ข้อแรก ต้นทุนคือความลึก: circuit AX ที่ลึกที่สุดใช้เกตสอง qubit ประมาณ ∼ ⁣47\sim\!47∼47 ตัว และเวอร์ชัน AX2_22​ ราวสองเท่า ทั้งสองจึงมีสัญญาณรบกวนและแพงกว่าเวอร์ชันแม่นยำมาก ข้อสอง ระบบสปินแต่ละระบบยังถูกส่งเป็นหนึ่ง job และทุกจุดเวลาใช้เลย์เอาต์ qubit กายภาพเดิมที่เลือกไว้ในส่วนสเปกโทรสโกปี ถ้า USE_BATCH=True job เหล่านี้จะใช้ Batch ทางเลือกทั่วทั้ง notebook ด้วย

# Trotterized FID: depth grows with time, so real decoherence (not apodization) sets the linewidth.
estimator.options.default_shots = 2000  # deep circuits need more shots in this appendix
n_tr, dt_tr = (
    48,
    1 / 20,
)  # Nyquist = 1/(2 dt) = 10 Hz (covers the AX2 triplet's 8 Hz line)
times_tr = np.arange(n_tr) * dt_tr
APODIZE_TROTTER = False  # keep False so the linewidth comes from decoherence

def trotter_fid_circuit(offsets, couplings, p, step):
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # 90-degree pulse
    for _ in range(p):  # p Trotter steps, each of duration `step`
        for i, nu in enumerate(offsets):
            qc.rz(2 * np.pi * nu * step, i)  # chemical-shift evolution for one step
        for (i, j), J in couplings.items():
            qc.rzz(np.pi * J * step, i, j)  # J-coupling evolution for one step
        qc.barrier()  # <-- stops the transpiler merging the steps
    return qc

def run_trotter(offsets, couplings, n, est, pass_manager):
    # Time point k uses k Trotter steps (its own circuit). Submit every time point and both
    # quadratures together as ONE Estimator job, using one fixed physical-qubit layout.
    ox, oy = transverse_obs(n)
    pubs = []
    for k in range(n_tr):
        isa = pass_manager.run(trotter_fid_circuit(offsets, couplings, k, dt_tr))
        pubs.append((isa, ox.apply_layout(isa.layout)))  # <X> at time k
        pubs.append((isa, oy.apply_layout(isa.layout)))  # <Y> at time k
    res = est.run(pubs).result()
    return np.array(
        [res[2 * k].data.evs + 1j * res[2 * k + 1].data.evs for k in range(n_tr)]
    )

def trotter_spectrum(fid):
    sig = fid * np.exp(-times_tr / 1.0) if APODIZE_TROTTER else fid
    spec = np.abs(np.fft.fftshift(np.fft.fft(sig)))
    freq = np.fft.fftshift(np.fft.fftfreq(n_tr, dt_tr))
    return freq, spec

fid_tr = run_trotter(
    ax_offsets, ax_couplings, 2, estimator, pm_ax
)  # AX  -> two doublets
fid2_tr = run_trotter(
    ax2_offsets, ax2_couplings, 3, estimator, pm_ax2
)  # AX2 -> triplet + doublet

f_ax, s_ax = trotter_spectrum(fid_tr)
f_ax2, s_ax2 = trotter_spectrum(fid2_tr)

fig, ax = plt.subplots(1, 3, figsize=(15, 4))
ax[0].plot(times_tr, np.abs(fid_tr), "o-", label="AX")
ax[0].plot(times_tr, np.abs(fid2_tr), "s-", label="AX$_2$")
ax[0].set_xlabel("evolution time $t$")
ax[0].set_ylabel("|FID|")
ax[0].set_title("Trotter FID envelope (decays only on a noisy backend)")
ax[0].legend()
ax[1].plot(f_ax, s_ax)
ax[1].set_xlim(-12, 12)
ax[1].set_xlabel(r"frequency $\nu$ (Hz)")
ax[1].set_ylabel("intensity")
ax[1].set_title("AX: two doublets")
ax[2].plot(f_ax2, s_ax2)
ax[2].set_xlim(-12, 12)
ax[2].set_xlabel(r"frequency $\nu$ (Hz)")
ax[2].set_title("AX$_2$: 1:2:1 triplet + doublet")
plt.tight_layout()
plt.show()
print(
    f"Deepest AX circuit: {n_tr-1} two-qubit gates;  deepest AX2 circuit: {2*(n_tr-1)} two-qubit gates."
)
print(
    "Noiseless backend: |FID| stays flat, peaks razor-sharp (set APODIZE_TROTTER=True to tame ripples)."
)
print(
    "Noise-model backend / hardware: |FID| decays on its own and the peaks gain a real linewidth."
)

if batch is not None:
    batch.close()
