รันบทเรียนโดยไม่ต้องมีบัญชี IBM Quantum

บทเรียนของ IBM เขียนขึ้นสำหรับคอมพิวเตอร์ควอนตัมจริงและคาดว่าคุณมีบัญชี IBM Quantum บน doQumentation โหมด Simulator เปิดอยู่โดยค่าเริ่มต้น โค้ดที่ปกติจะส่งงานไปยัง IBM Quantum จะรันบน simulator ในเครื่องแทน คุณจึงรันบทเรียนได้โดยไม่ต้องมีบัญชี

เลือก simulator ในการตั้งค่า

แบบอุดมคติหรือแบบมีสัญญาณรบกวน

เลือก AerSimulator เพื่อผลลัพธ์แบบอุดมคติที่ไม่มีสัญญาณรบกวน หรือเลือก fake backend จากหลายสิบแบบที่จำลองสัญญาณรบกวนและผังของคอมพิวเตอร์ควอนตัม IBM จริง แถบเครื่องมือแสดงว่าตัวใดทำงานอยู่ คุณจึงรู้เสมอว่าโค้ดรันที่ไหน

สลับไปใช้ฮาร์ดแวร์จริงเมื่อคุณพร้อม

บันทึก API key และอินสแตนซ์ IBM Quantum ของคุณในการตั้งค่า แล้วสลับโหมดเป็น IBM Quantum ข้อมูลรับรองจะถูกเก็บในเบราว์เซอร์ของคุณและส่งให้ kernel เมื่อเริ่มทำงาน คุณจึงไม่ต้องวางโทเคนลงใน notebook เลย

สิ่งที่ simulator ทำไม่ได้

บางเซลล์ต้องใช้ IBM Quantum จริง เช่น เพื่อแสดงรายการงานของคุณหรืออ่านข้อมูลสอบเทียบของอุปกรณ์จริง doQumentation จะรู้จักเซลล์เหล่านี้และแจ้งให้ทราบแทนการแสดงข้อผิดพลาด

ลองใช้ในหน้าเหล่านี้

  • อัลกอริทึมของ Grover
  • การจำลองแบบแม่นยำและมีสัญญาณรบกวนด้วย Qiskit Aer
  • โหมดทดสอบในเครื่อง

คำถามที่พบบ่อย

รันบทเรียน IBM Quantum โดยไม่มีบัญชีได้ไหม

ได้ โหมด Simulator เป็นค่าเริ่มต้นบน doQumentation บทเรียนจึงรันบน simulator โดยไม่ต้องมีบัญชี ไม่ต้องมี API key และไม่ต้องตั้งค่า

fake backend คืออะไร

fake backend คือแบบจำลองของ Qiskit สำหรับคอมพิวเตอร์ควอนตัม IBM จริง ทั้งผังคิวบิต ชุดเกต และสัญญาณรบกวนที่วัดได้ ผลลัพธ์ดูเหมือนผลจากอุปกรณ์จริงโดยไม่ต้องรอคิว

จะได้ผลลัพธ์เหมือนบนฮาร์ดแวร์จริงไหม

ไม่เหมือนทั้งหมด simulator แบบอุดมคติไม่มีสัญญาณรบกวนเลย ส่วน fake backend ใช้ภาพบันทึกสัญญาณรบกวนของอุปกรณ์ ทั้งสองแบบเหมาะกับการเรียนรู้และทดสอบ และบทเรียนอธิบายว่าควรคาดหวังผลลัพธ์แบบใด

มีข้อจำกัดไหม

simulator รันบนคอมพิวเตอร์ของ kernel วงจรขนาดใหญ่ที่มีคิวบิตจำนวนมากจึงอาจช้าหรือหน่วยความจำไม่พอ บทเรียนส่วนใหญ่มีขนาดที่ยังรันได้
