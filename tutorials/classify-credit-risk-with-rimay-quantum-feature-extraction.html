จำแนกความเสี่ยงด้านเครดิตด้วย Quantum Feature Extraction ของ Rimay จาก Kipu Quantum

หมายเหตุ

Qiskit Functions เป็นฟีเจอร์ทดลองที่ใช้ได้เฉพาะผู้ใช้ IBM Quantum® Premium Plan, Flex Plan และ On-Prem (ผ่าน IBM Quantum Platform API) Plan เท่านั้น อยู่ในสถานะ preview release และอาจเปลี่ยนแปลงได้

ประมาณการการใช้งาน: 2 นาทีบนโปรเซสเซอร์ Nighthawk r2 (หมายเหตุ: นี่เป็นเพียงค่าประมาณ เวลารันจริงของคุณอาจต่างออกไป)

ผลลัพธ์การเรียนรู้​

  • เตรียมข้อมูลตารางที่มีคอลัมน์เชิงหมวดหมู่และเชิงตัวเลขสำหรับ Qiskit Function ของ Rimay

  • ฟิต feature mapping เชิงควอนตัมบนข้อมูลฝึก และแมปข้อมูลทดสอบในการรันเดียวกัน

  • ฝึกโมเดลคลาสสิกบนฟีเจอร์ที่ผ่านการแปลงควอนตัม ทั้งแบบใช้เดี่ยวๆ และรวมกับฟีเจอร์เดิม

  • เปรียบเทียบผลลัพธ์กับ baseline แบบคลาสสิกล้วน

ความรู้พื้นฐานที่ต้องมี​

ก่อนเริ่มบทเรียนนี้ คุณควรคุ้นเคยกับหัวข้อต่อไปนี้:

  • แนะนำ Qiskit Functions

  • Supervised classification ด้วย scikit-learn

ความเป็นมา​

ปัญหา machine learning จำนวนมากในอุตสาหกรรมใช้ชุดข้อมูลตารางขนาดเล็กถึงกลาง ซึ่งเพิ่มข้อมูลไม่ได้และความแม่นยำของโมเดลก็ไม่ขยับขึ้นอีก การให้คะแนนความเสี่ยงสินเชื่อเป็นตัวอย่างทั่วไป ผู้ให้กู้ใช้คุณลักษณะไม่กี่สิบข้อเพื่อตัดสินว่าผู้สมัครน่าจะชำระคืนสินเชื่อหรือไม่

Rimay ซึ่งเป็น Qiskit Function โดย Kipu Quantum เพิ่มขั้นตอน quantum preprocessing เข้าไปใน pipeline แบบนี้ โดยใช้อัลกอริทึม digitized counterdiabatic quantum feature extraction [1] ฟีเจอร์อินพุตแต่ละตัวจะถูกแมปไปยัง qubit หนึ่งตัว ค่าของฟีเจอร์และ mutual information ระหว่างฟีเจอร์กำหนด local field และ coupling ของ Hamiltonian แบบ spin-glass จากนั้นพลวัต counterdiabatic จะพัฒนาระบบควอนตัมไปสู่สถานะพลังงานต่ำ และค่าคาดหมายแบบ single-body และ two-body ที่วัดได้ตอนท้ายจะกลายเป็นฟีเจอร์ใหม่ที่ผ่านการแปลงด้วยควอนตัม ฟีเจอร์เหล่านี้จับความสัมพันธ์ไม่เชิงเส้นระหว่างอินพุต และคุณสามารถป้อนให้โมเดลคลาสสิกใดก็ได้

บทเรียนนี้ใช้ชุดข้อมูล German credit จาก OpenML [2] ซึ่งมีผู้สมัคร 1000 คนและ 20 คุณลักษณะ เพื่อฝึก random forest classifier ก่อนอื่นคุณจะสร้าง baseline แบบคลาสสิก จากนั้นส่งข้อมูลไปยัง Rimay และสุดท้ายฝึกโมเดลชนิดเดียวกันบนฟีเจอร์ที่ผ่านการแปลงด้วยควอนตัม ทั้งแบบใช้ฟีเจอร์เหล่านั้นอย่างเดียวและแบบรวมกับฟีเจอร์ดั้งเดิม

def train_random_forest(x, y, n_estimators, max_depth):
    """Train a random forest classifier with fixed hyperparameters."""
    model = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        min_samples_split=5,
        min_samples_leaf=1,
        max_features="sqrt",
        random_state=42,
        n_jobs=-1,
    )
    return model.fit(x, y)

def evaluate(model, x, y):
    """Return the classification metrics of a trained model on a test set."""
    y_pred = model.predict(x)
    y_proba = model.predict_proba(x)[:, 1]
    return {
        "Accuracy": accuracy_score(y, y_pred),
        "AUC": roc_auc_score(y, y_proba),
        "F1 score": f1_score(y, y_pred),
        "Precision": precision_score(y, y_pred),
        "Recall": recall_score(y, y_pred),
    }

คำนวณขนาดฟังก์ชัน​

ทุกงานรันที่ขนาดฟังก์ชัน S, M หรือ L ซึ่งเลือกทรัพยากรประมวลผลที่งานใช้ สำหรับ Rimay ขนาดขึ้นอยู่กับจำนวนแถวที่งานแมป โดยรวมแถวฝึกและแถวทดสอบ ถ้าคุณขอขนาดที่เล็กเกินไป งานจะล้มเหลวด้วยข้อผิดพลาด 4600 สำหรับขนาดและขีดจำกัดของแต่ละขนาด ดู Function sizes ในคู่มือ Rimay

เซลล์ต่อไปนี้กำหนดตัวคำนวณขนาด มันรันบนเครื่องของคุณ อ่านเฉพาะข้อมูลที่คุณส่งให้ และไม่ส่งอะไรออกไป

from os import PathLike
from typing import Any, Literal, Sequence, Sized

Size = Literal["S", "M", "L"]

# Upper bounds (inclusive) in samples.
_SMALL = 2_999
_MEDIUM = 9_999

FIT_TRANSFORM, TRANSFORM, DELETE = "fit-transform", "transform", "delete"

# Which positions of input_file hold samples, per mode. The labels in
# y_train submit no circuits of their own, so they are not counted.
SAMPLE_POSITIONS = {FIT_TRANSFORM: (0, 2), TRANSFORM: (0,)}

def calculate_function_size(problem: Sequence[Sized], **kwargs: Any) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    metrics = _measure(problem, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def _measure(problem: Sequence[Sized], **kwargs: Any) -> dict:
    """The samples the job submits."""
    return {"samples": count_samples(problem, kwargs.get("mode"))}

def count_samples(problem: Sequence[Sized], mode: Any) -> int:
    """Rows across the data sets of ``problem`` that carry samples."""
    if mode == DELETE:
        return 0
    if mode not in SAMPLE_POSITIONS:
        raise ValueError(f"cannot size mode {mode!r}")
    if _is_name(problem) or (
        isinstance(problem, (list, tuple))
        and any(_is_name(data) for data in problem)
    ):
        raise TypeError(
            "pass the data, not the file name: read each input_file, e.g. with "
            "pandas.read_csv, and pass the data sets in input_file order"
        )
    if not isinstance(problem, (list, tuple)):
        raise TypeError(
            "pass a list of data sets in input_file order, e.g. [x_train, y_train], "
            f"not a single {type(problem).__name__}"
        )
    return sum(
        len(problem[i]) for i in SAMPLE_POSITIONS[mode] if i < len(problem)
    )

def _is_name(value: Any) -> bool:
    """A file name or path rather than data."""
    return isinstance(value, (str, bytes, PathLike))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return metrics["samples"] <= _SMALL

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return metrics["samples"] <= _MEDIUM

สรุป​

สิ่งที่คุณทำสำเร็จ​

ในบทเรียนนี้ คุณทำสิ่งต่อไปนี้สำเร็จ

  1. เตรียมชุดข้อมูลความเสี่ยงสินเชื่อจากโลกจริงที่มีคุณลักษณะแบบหมวดหมู่และตัวเลข สำหรับ quantum feature extraction

  2. สร้าง baseline random forest แบบคลาสสิก

  3. ใช้ Rimay fit การแมปฟีเจอร์ควอนตัมบนฮาร์ดแวร์ควอนตัม และแมปชุดฝึกและชุดทดสอบในการรันเดียว

  4. ฝึกโมเดลเดียวกันบนฟีเจอร์ที่ผ่านการแปลงด้วยควอนตัมและบนฟีเจอร์รวม แล้วเปรียบเทียบกับ baseline

ประเด็นสำคัญ​

  • Rimay เข้ากับ machine learning pipeline ที่มีอยู่ได้ในฐานะขั้นตอน preprocessing เพิ่มเติมหนึ่งขั้น คุณยังคงการเตรียมข้อมูลและโมเดลคลาสสิกของคุณไว้

  • จำนวน qubit เป็นตัวจำกัดจำนวนฟีเจอร์อินพุต และจำนวนแถวคูณ shots เป็นตัวจำกัดขนาดของงานหนึ่งงาน

  • ใช้ฟีเจอร์ที่ผ่านการแปลงด้วยควอนตัมรวมกับฟีเจอร์ดั้งเดิมเป็นค่าเริ่มต้น เพราะโมเดลใช้ได้ทั้งสองอย่าง
