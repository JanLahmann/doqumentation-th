การจำลอง kicked Ising model ด้วยฟังก์ชัน TEM

วิธี Tensor-network Error Mitigation (TEM) ของ Algorithmiq เป็นอัลกอริทึมแบบไฮบริดควอนตัม-คลาสสิกที่ขจัดผลของ noise จากฮาร์ดแวร์ทั้งหมดในขั้นตอนประมวลผลหลังแบบคลาสสิก circuit รันบน QPU ตามที่เขียนไว้ โดยมีการวัดแบบ informationally complete (IC) ในตอนท้าย จากนั้นใช้ tensor network ที่ผกผัน noise ของอุปกรณ์ที่เรียนรู้มากับผลการวัด เพื่อให้ได้ค่าคาดหวังที่ผ่านการ mitigate error แล้ว

บทเรียนนี้จำลองซ้ำที่ 31 qubit ซึ่งเป็นการทดลองพลวัตหลายวัตถุแบบเดียวกับที่รันถึง 91 qubit ใน L. E. Fischer et al., Nat. Phys. (2026) บทเรียนนี้แสดงให้เห็นว่า

  • noise ของฮาร์ดแวร์ทำลายสัญญาณไปมากเพียงใดใน dynamics circuit ระดับ utility-scale และ TEM กู้คืนกลับมาได้มากเพียงใด

  • TEM เปรียบเทียบกับ probabilistic error cancellation (PEC) และ zero-noise extrapolation (ZNE) บน circuit เดียวกันได้อย่างไร

การวัดแบบ IC ยังทำให้สามารถประมาณ observable ที่ไม่ได้ร้องขอตอนรัน circuit ได้ โดยรันเฉพาะการประมวลผลหลังแบบคลาสสิกซ้ำ สำหรับตัวอย่างที่ประมาณ light cone ทั้งหมดของ chain ดู Run 4: measure the light cone from the same data

หากต้องการปรับความแม่นยำของ TEM เทียบกับต้นทุน QPU และต้นทุนแบบคลาสสิก ดูตัวอย่างประกอบ Tune the TEM function for accuracy and cost

ประมาณการการใช้งาน: ประมาณ 20 วินาที QPU สำหรับ TEM บน ibm_phoenix (เวลา QPU ขึ้นอยู่กับอุปกรณ์ที่เลือกเป็นอย่างมาก) การเปรียบเทียบ PEC และ ZNE ที่เป็นทางเลือกใช้เวลา QPU เพิ่มอีกประมาณ 35 นาที เกือบทั้งหมดเป็นของ PEC

ความเป็นมา: kicked Ising chain​

โมเดล kicked Ising สลับระหว่างวิวัฒนาการแบบ Ising บน chain ของ NNN qubit

H^I=J∑n=0N−2Z^nZ^n+1+h∑n=0N−1Z^n,\hat{H}_{\text{I}} = J \sum_{n=0}^{N-2} \hat{Z}_n \hat{Z}_{n+1} + h \sum_{n=0}^{N-1} \hat{Z}_n ,H^I​=J∑n=0N−2​Z^n​Z^n+1​+h∑n=0N−1​Z^n​,

กับ transverse kick

H^K=b∑n=0N−1X^n.\hat{H}_{K} = b \sum_{n=0}^{N-1} \hat{X}_n .H^K​=b∑n=0N−1​X^n​.

หนึ่งคาบของพลวัตคือ Floquet unitary U^KI=e−iH^Ke−iH^I\hat{U}_{\text{KI}} = e^{-i \hat{H}_K} e^{-i \hat{H}_I}U^KI​=e−iH^K​e−iH^I​ บนคอมพิวเตอร์ควอนตัม แต่ละคาบคือ brickwork ของการหมุน ZZZZZZ แบบ two-qubit ตามด้วยการหมุนแบบ single-qubit ดังนั้น circuit จึงมี two-qubit gate layer ที่ต่างกันเพียงสองชั้นซ้ำกัน

ปริมาณที่สนใจคือ autocorrelation function ที่อุณหภูมิอนันต์ของ spin ตัวแรก reference paper แสดงว่าวัดได้โดยเตรียม qubit ตัวแรกใน ∣+⟩|+\rangle∣+⟩ และ qubit คู่อื่น ๆ ทุกคู่ในสถานะ Bell (∣00⟩+∣11⟩)/2(|00\rangle + |11\rangle)/\sqrt{2}(∣00⟩+∣11⟩)/2​ ให้วิวัฒนาการเป็นเวลา ttt คาบ และวัด Pauli operator แบบ single-qubit X^n\hat{X}_nX^n​

ที่จุด dual unitary ∣J∣=∣b∣=π/4|J| = |b| = \pi/4∣J∣=∣b∣=π/4 โมเดลนี้แก้ได้แบบตรงตัว

  • สหสัมพันธ์เดินทางไปตาม chain ด้วยความเร็วสูงสุด ดังนั้นหลังจาก ttt คาบ มีเพียง qubit n=tn = tn=t ที่นำสหสัมพันธ์นั้น และ ⟨X^n≠t⟩=0\langle \hat{X}_{n \neq t} \rangle = 0⟨X^n=t​⟩=0

  • บน qubit นั้น ⟨X^n=t⟩=[cos⁡(2h)]t\langle \hat{X}_{n=t} \rangle = [\cos(2h)]^t⟨X^n=t​⟩=[cos(2h)]t

ค่าที่แน่นอนเหล่านี้ทำให้โมเดลนี้เป็น benchmark ที่คมชัดสำหรับ error mitigation: สัญญาณที่ไปถึง qubit ttt ผ่านทุก layer ของ circuit จึงได้รับ noise ทั้งหมดของอุปกรณ์ แต่ค่าในกรณีไม่มี noise เป็นที่ทราบ เมื่ออยู่ห่างจากจุด dual unitary circuit แบบเดียวกันจะจำลองแบบคลาสสิกได้ยาก ซึ่งเป็นจุดที่บทความใช้ TEM เพื่อก้าวข้ามวิธีที่แน่นอน

TEM ทำงานสามขั้นตอน: เรียนรู้ noise ของ two-qubit gate layer ที่ไม่ซ้ำกันแต่ละชั้นและ readout error, รัน circuit พร้อมการวัดแบบ IC และสุดท้ายใช้ tensor network ที่ผกผัน noise กับผลการวัดบน IBM Cloud®

ขั้นตอนที่ 1: สร้าง circuit และ observable​

บทแนะนำนี้ใช้ Circuit ที่นำ kicked Ising model ที่อธิบายไว้ในส่วนก่อนหน้ามาใช้งาน Circuit ถูกเตรียมดังนี้ ขั้นแรกมีช่วงการเตรียมสถานะ ซึ่ง Qubit แรกอยู่ในสถานะ ∣+⟩|+\rangle∣+⟩ ในขณะที่ Qubit อื่นๆ อยู่ใน Bell pairs (∣00⟩+∣11⟩)/2(|00\rangle + |11\rangle)/\sqrt{2}(∣00⟩+∣11⟩)/2​ ตามด้วยโครงสร้าง brickwork ที่นำการวิวัฒนาการ unitary U^KI\hat{U}_{\text{KI}}U^KI​ มาใช้ จำนวนขั้นเวลาทางฟิสิกส์สอดคล้องกับ t/2t/2t/2 เลเยอร์ของ Circuit โค้ดต่อไปนี้สร้าง Circuit ที่ใช้ในบทแนะนำนี้

from qiskit import QuantumCircuit

def kicked_ising_circuit(n_qubits, t_steps):
    """Kicked Ising circuit at the dual unitary point (J = b = pi/4, h = 0)."""
    circuit = QuantumCircuit(n_qubits)

    # State preparation: |+> on qubit 0, Bell pairs on (1, 2), (3, 4), ...
    circuit.h(0)
    for i in range(1, n_qubits - 1, 2):
        circuit.h(i)
        circuit.x(i + 1)
        circuit.cx(i, i + 1)
    circuit.barrier()

    # Clifford two-qubit block: one ZZ rotation, X kick, one ZZ rotation
    block = QuantumCircuit(2)
    block.sdg([0, 1])
    block.cx(0, 1)
    block.sdg(0)
    block.h([0, 1])
    block.s(1)
    block.cx(0, 1)
    block.s(0)
    block.h(0)
    block.sdg(0)
    block.y(1)
    block.h(1)

    # Brickwork: even periods act on (0, 1), (2, 3), ...; odd periods on (1, 2), (3, 4), ...
    for step in range(t_steps):
        for q in range(step % 2, n_qubits - 1, 2):
            circuit.compose(block, [q, q + 1], inplace=True)
        circuit.barrier()
    return circuit

ถัดไป สร้าง observable X^n=t\hat{X}_{n=t}X^n=t​ โดยสร้างเป็น Pauli string ง่ายๆ ที่มีลำดับตรงกับที่ Qiskit ใช้:

def xt_observable(n_qubits, t_steps):
    pauli_str = "".join(["I" * t_steps, "X", "I" * (n_qubits - t_steps - 1)])
    pauli_str = pauli_str[::-1]  # Reverse the string to match qiskit order
    return SparsePauliOp(data=pauli_str, coeffs=1.0)

การทดลองใช้ 31 qubit และ 15 คาบที่ h=0h = 0h=0 ดังนั้นค่าที่แน่นอนของ ⟨X^n=15⟩\langle \hat{X}_{n=15} \rangle⟨X^n=15​⟩ คือ 1 นี่คือ circuit ระดับ utility-scale ที่มี two-qubit gate 465 ตัว: 15 ตัวที่เตรียมคู่ Bell และ 30 ตัวในแต่ละคาบ สัญญาณที่ไปถึง qubit 15 ผ่านเกตเหล่านี้หลายร้อยตัว

t_steps = 15
h = 0.0

# Build the circuit for the kicked Ising model

# Build the observable for the kicked Ising model

Transpile circuit สำหรับอุปกรณ์ที่เลือกหนึ่งครั้ง และแมป observable ไปยัง qubit ที่ circuit ถูกวางไว้ TEM รับ circuit แบบ instruction set architecture (ISA) นี้ตามที่เป็น และการเปรียบเทียบ PEC และ ZNE ในขั้นตอนที่ 3 ใช้ circuit เดียวกัน ดังนั้นทุกวิธีจึงรัน gate เดียวกันบน qubit เดียวกัน

from qiskit_ibm_runtime import QiskitRuntimeService

ตัวเลือกต่อไปนี้อิงตามฟิสิกส์ของ circuit

  • max_layers_to_learn: 4: ขอบเขตบนของจำนวน layer ที่แตกต่างกันของ two-qubit gate ที่จะเรียนรู้ noise โครงสร้าง brickwork มีเพียงสอง layer ที่แตกต่างกัน จึงเรียนรู้เฉพาะสองอันนั้น

  • default_shots: 100_000: จำนวน shot ของการวัด IC ซึ่งกำหนดความแม่นยำทางสถิติของค่าประมาณ

  • tem_max_bond_dimension: 128 และ tem_compression_cutoff: 1e-14: bond dimension ระดับปานกลางที่ช่วยให้การประมวลผลหลังการวัดแบบคลาสสิกเร็วที่ 31 qubit พร้อม cutoff ค่าเล็กเพื่อไม่ให้ bond dimension ถูกตัดทอนเพิ่มอีก

  • private: False: ทำให้ดาวน์โหลดผลลัพธ์ของ job ได้ภายหลัง ตั้งเป็น True สำหรับ circuit ที่เป็นความลับ

ตัวอย่างการปรับแต่งประสิทธิภาพ อธิบายแต่ละตัวเลือกเหล่านี้โดยละเอียด

คำนวณขนาดของ function ที่ job ต้องการด้วยเครื่องมือคำนวณขนาดที่ IBM® จัดให้ แล้วส่งให้ tem.run เป็น function_size เครื่องมือนี้จะ map circuit ลงบน backend และคืนค่า S, M หรือ L โดยไม่ส่งอะไรไปรัน ดู Function sizes

# Calculate the function size a circuit needs, before submitting it.
#
# Call ``calculate_function_size(pubs, backend)``: it returns "S", "M" or "L" and submits
# nothing. Pass the whole list of PUBs -- a job runs at one size, and the heaviest PUB
# decides it. The circuit is measured after being mapped onto ``backend``, since mapping
# can add both qubits and depth.

from typing import Any, Literal

from qiskit.circuit import Barrier
from qiskit.circuit.equivalence_library import SessionEquivalenceLibrary
from qiskit.transpiler import PassManager

    ApplyLayout,

    BasisTranslator,
    EnlargeWithAncilla,
    FilterOpNodes,
    FullAncillaAllocation,

    SabreSwap,

    UnitarySynthesis,

Size = Literal["S", "M", "L"]
_ORDER = {"S": 0, "M": 1, "L": 2}

# Limits are provided by IBM
_SMALL_QUBITS, _SMALL_DEPTH_2Q = 40, 40
_MEDIUM_QUBITS, _MEDIUM_DEPTH_2Q = 100, 100

# Any fixed value works; what matters is that it does not change between calls.
_SEED_TRANSPILER = 42

# Added by BarrierBeforeFinalMeasurements so routing cannot move gates past a measurement,
# then removed again once routing is done.
_PROTECTION_BARRIER = "qiskit.transpiler.internal.routing.protection.barrier"

def calculate_function_size(
    circuit: QuantumCircuit | Iterable[Any], backend, **kwargs: Any
) -> Size:
    """Return the size ("S", "M" or "L") required to run the function."""
    circuits = pub_circuits(circuit)
    if not circuits:
        raise ValueError(
            "No circuit to size: pass a QuantumCircuit or a non-empty list of PUBs."
        )
    return max(
        (_calculate_circuit_size(qc, backend, **kwargs) for qc in circuits),
        key=_ORDER.__getitem__,
    )

def _calculate_circuit_size(
    circuit: QuantumCircuit, backend, **kwargs: Any
) -> Size:
    """Return the size required to run a single circuit."""
    metrics = _measure(circuit, backend, **kwargs)
    if _is_small(metrics):
        return "S"
    if _is_medium(metrics):
        return "M"
    return "L"

def pub_circuits(problem: Any) -> list[QuantumCircuit]:
    """Return the circuits in ``problem``: one circuit, or one per PUB in a list."""
    if isinstance(problem, QuantumCircuit):
        return [problem]
    circuits: list[QuantumCircuit] = []
    for index, pub in enumerate(problem):
        if isinstance(pub, QuantumCircuit):
            circuit = pub
        elif isinstance(getattr(pub, "circuit", None), QuantumCircuit):
            circuit = pub.circuit
        elif (
            isinstance(pub, (tuple, list))
            and pub
            and isinstance(pub[0], QuantumCircuit)
        ):
            circuit = pub[0]
        else:
            raise ValueError(f"PUB #{index} has no QuantumCircuit to size.")
        circuits.append(circuit)
    return circuits

def _pass_manager(target) -> PassManager:
    """Return the pass manager used to map a circuit onto ``target``.

    Fixed and seeded, so the same circuit always gives the same size.
    """
    basis = list(target.operation_names)
    library = SessionEquivalenceLibrary
    return PassManager(
        [
            UnitarySynthesis(
                basis, approximation_degree=1.0, min_qubits=3, target=target
            ),
            HighLevelSynthesis(
                target=target,
                equivalence_library=library,
                basis_gates=basis,
                min_qubits=3,
            ),
            BasisTranslator(library, basis, target=target, min_qubits=3),
            TrivialLayout(target),
            FullAncillaAllocation(target),
            EnlargeWithAncilla(),
            ApplyLayout(),
            BarrierBeforeFinalMeasurements(label=_PROTECTION_BARRIER),
            SabreSwap(
                target, heuristic="basic", seed=_SEED_TRANSPILER, trials=5
            ),
            FilterOpNodes(lambda node: node.label != _PROTECTION_BARRIER),
            UnitarySynthesis(basis, approximation_degree=1.0, target=target),
            HighLevelSynthesis(
                target=target,
                equivalence_library=library,
                basis_gates=basis,
                use_qubit_indices=True,
            ),
            BasisTranslator(library, basis, target=target),
        ]
    )

def _count(isa: QuantumCircuit) -> dict:
    """Return the active qubits and two-qubit-gate depth of a mapped circuit."""
    active = {
        q
        for instr in isa.data
        if not isinstance(instr.operation, Barrier)
        for q in instr.qubits
    }
    return {
        "num_qubits": len(active),
        "depth_2q": isa.depth(
            filter_function=lambda instr: len(instr.qubits) == 2
            and not isinstance(instr.operation, Barrier)
        ),
    }

def _measure(circuit: QuantumCircuit, backend, **kwargs: Any) -> dict:
    """Map ``circuit`` onto ``backend`` and return its metrics."""
    return _count(_pass_manager(backend.target).run(circuit))

def _is_small(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'S'."""
    return (
        metrics["num_qubits"] <= _SMALL_QUBITS
        and metrics["depth_2q"] <= _SMALL_DEPTH_2Q
    )

def _is_medium(metrics: dict) -> bool:
    """Determine if the metrics fit T-size 'M'."""
    return (
        metrics["num_qubits"] <= _MEDIUM_QUBITS
        and metrics["depth_2q"] <= _MEDIUM_DEPTH_2Q
    )
size = calculate_function_size(pubs, backend)  # "S", "M" or "L"

ขั้นตอนที่ 3: เปรียบเทียบกับ PEC และ ZNE​

metadata ของผลลัพธ์ยังมีค่าประมาณแบบไม่ผ่านการลดข้อผิดพลาด ซึ่งคำนวณจากผลการวัดชุดเดียวกันโดยไม่ใช้เครือข่ายที่ผกผัน noise การเปรียบเทียบทั้งสองค่ากับค่าที่แน่นอนแสดงให้เห็นว่า noise ทำลายสัญญาณไปมากเพียงใด และ TEM กู้คืนได้เท่าใด: เพื่อให้เห็นบริบทของผลลัพธ์ TEM ให้รัน circuit เดียวกันด้วยวิธีลดข้อผิดพลาดอีกสองวิธี ได้แก่ probabilistic error cancellation (PEC) และ zero-noise extrapolation (ZNE) แบบ probabilistic error amplification (PEA)
