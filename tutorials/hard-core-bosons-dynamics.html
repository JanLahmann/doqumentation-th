Hard-core boson บนโครงตาข่ายสี่เหลี่ยม

ประมาณการการใช้งาน: ประมาณ 2 นาทีของการคำนวณแบบคลาสสิกและไม่ใช้เวลา QPU เพราะชิปเป็น backend จำลอง (หมายเหตุ: นี่เป็นเพียงค่าประมาณ เวลารันจริงของคุณอาจแตกต่าง)

บทเรียนนี้แนะนำ qiskit-bosons เฟรมเวิร์กสำหรับสำรวจฟิสิกส์ของโบซอนบนคอมพิวเตอร์ควอนตัม คุณ อธิบายโมเดลโบซอนหนึ่งครั้งเป็น BosonOperator และ BosonicCircuit แล้วแพ็กเกจจัดการส่วนที่เหลือ: transpiler preset ลด circuit ลงเป็น qubit ตามการตัดทอนโหมดและการเข้ารหัสระดับที่คุณเลือก บทเรียนนี้ใช้ hard-core boson บนโครงตาข่ายสี่เหลี่ยมเป็นโมเดลตัวอย่าง ฟิสิกส์ของมันเรียบง่ายพอที่จะตรวจสอบกับค่าอ้างอิงที่แน่นอนได้ คุณจึงโฟกัสที่ ตัวเฟรมเวิร์กได้: คุณสร้าง circuit จากขนาดโครงตาข่ายเพียงอย่างเดียว ลดลงเป็น qubit วัดข้อผิดพลาด Trotter และ ต้นทุนของมัน และวางลงบนโครงตาข่ายสี่เหลี่ยมของชิป Nighthawk การสำรวจจริงเริ่มต้นตรงที่โมเดลนี้จบลง และหัวข้อสุดท้าย แสดงก้าวแรกที่เลยไปจากมัน

ผลลัพธ์การเรียนรู้​

เมื่อเรียนบทเรียนนี้จบ คุณจะเข้าใจข้อมูลต่อไปนี้:

  • qiskit-bosons ถูกจัดระเบียบอย่างไร: โมเดลโบซอนและ circuit ของมันเขียนเพียงครั้งเดียว โดยไม่ขึ้นกับการตัดทอนโหมด ddd และ การเข้ารหัสระดับ และ transpiler preset ลดมันลงเป็น qubit บทเรียนนี้ใช้มันกับกรณีที่ง่ายที่สุด d=2d = 2d=2
  • ทำไม hard-core boson จึงเป็นกรณี d=2d = 2d=2 ความสัมพันธ์กับโมเดล Bose-Hubbard และกับเฟอร์มิออนอิสระ และทำไม โซ่ 1D จึงง่ายสำหรับคอมพิวเตอร์คลาสสิกในขณะที่โครงตาข่าย 2D ไม่ใช่
  • วิธีสร้างแฮมิลโทเนียนการกระโดดบนโครงตาข่ายสี่เหลี่ยมเป็น BosonOperator ที่จัดกลุ่มตามสีของขอบ และ circuit วิวัฒนาการตามเวลา ของหนึ่ง Trotter step เป็น BosonicCircuit ที่ไม่ขึ้นกับขนาดโครงตาข่าย
  • วิธีที่ transpiler preset ของ qiskit-bosons ลด circuit นั้นลงเป็น qubit สำหรับการเข้ารหัสระดับสี่แบบ และทำไมโค้ดแบบกะทัดรัดจึง ถูกกว่าแบบ unary ประมาณหนึ่งลำดับขนาดที่ d=2d = 2d=2
  • วิธีตรวจสอบ circuit กับค่าอ้างอิงที่แน่นอน และข้อผิดพลาด Trotter ลดลงอย่างไรตามจำนวน step สำหรับอันดับหนึ่งและ อันดับสอง
  • ทำไมการฝังโครงตาข่ายลงบนโครงตาข่ายสี่เหลี่ยมของชิป Nighthawk ตามธรรมชาติจึงไม่ต้องมีการ routing ที่ขนาดใดก็ตามที่พอดีกับชิป
  • อะไรเปลี่ยนไปเมื่อคุณออกจากขีดจำกัด hard-core: เฟรมเวิร์กเดียวกันอธิบาย soft-core boson ได้ แต่ต้นทุนโตเร็ว

  1. โมเดลและฟิสิกส์

  2. สร้าง BosonicCircuit

  8. ข้อสรุปและขั้นตอนถัดไป

def plain_log_ticks(axis, ticks, which="y"):
    """Log axis with plain tick labels (10, 20, 50 ...) instead of powers of ten."""
    formatter = plt.ScalarFormatter()
    getattr(axis, f"{which}axis").set_major_formatter(formatter)
    getattr(axis, f"set_{which}ticks")(ticks)
    getattr(axis, f"{which}axis").set_minor_formatter(plt.NullFormatter())

def plot_quench(times, panels, t_curves=T_CURVES):
    """The exact curves (lines) and the Trotterized circuit for several step lengths (dots), one panel per observable.

    `panels` maps a title to {"ylabel", "ylim", "exact": values at `times`, "circuit": {step length: values at its multiples}}.
    Pure plotting: nothing is computed here."""
    figure, axes = plt.subplots(
        1, len(panels), figsize=(14, 4), layout="constrained"
    )
    colors = dict(
        zip(
            sorted(next(iter(panels.values()))["circuit"], reverse=True),
            ("tab:red", "tab:orange", "tab:green"),
        )
    )
    for ax, (title, panel) in zip(axes, panels.items()):
        ax.plot(
            times,
            panel["exact"],
            "-",
            color="k",
            lw=2,
            label="exact (plain numpy)",
        )
        for dt, values in panel["circuit"].items():
            ax.plot(
                np.arange(len(values)) * dt,
                values,
                "o",
                ms=4,
                color=colors[dt],
                label=f"circuit, $dt = {dt}$ ({int(round(t_curves / dt))} steps)",
            )
        ax.set(
            xlabel="$t$ (units of $1/t_{hop}$)",
            ylabel=panel["ylabel"],
            title=title,
            ylim=panel["ylim"],
        )
        ax.grid(axis="y")
    axes[-1].legend(fontsize=8)
    plt.close(
        figure
    )  # drawn once, by being the cell's value; otherwise the inline backend shows it a second time
    return figure

def fitted_slope(rows, last=3):
    """Slope of log(max density error) against log(steps) over the last `last` points."""
    return float(
        np.polyfit(np.log(rows[-last:, 0]), np.log(rows[-last:, 1]), 1)[0]
    )

ORDER_COLORS = {
    1: "tab:green",
    2: "tab:blue",
}  # the product-formula order, in every plot
ORDERINGS = {  # how the Pauli terms are listed -> (marker, how much of the color is kept: 1 is full, 0 is white)
    "sorted by color": ("x", 1.0),
    "bond by bond": ("s", 0.65),
    "preserve_order=False": ("^", 0.4),
}

def curve_style(order, ordering=None):
    """(label, color, marker + line style).

    The bosonic circuit is a solid line with circles in the color of its order. A single gate is dashed with one marker per
    ordering of the Pauli terms, and the color of the order is tinted towards white for the later orderings."""
    if ordering is None:
        return f"bosonic, order {order}", ORDER_COLORS[order], "o-"
    marker, keep = ORDERINGS[ordering]
    color = tuple(1 - (1 - c) * keep for c in to_rgb(ORDER_COLORS[order]))
    return f"qubit-based, order {order}, {ordering}", color, marker + "--"

def plot_trotter_error(
    trotter_rows, depths, qubit_rows=None, qubit_depths=None, t_final=T_FINAL
):
    """Left: error against the number of Trotter steps with the ideal slopes. Right: error against the two-qubit depth.

    `trotter_rows` maps the order to rows (steps, max density error), `depths` maps it to the two-qubit depth of each row.
    `qubit_rows` and `qubit_depths` do the same for the single-gate variants (key (order, ordering)), drawn on top if given."""
    order_colors = ORDER_COLORS
    figure, axes = plt.subplots(1, 2, figsize=(11, 4), layout="constrained")
    steps = trotter_rows[1][:, 0]
    for order in order_colors:  # legend order: the ideal slopes, the bosonic curves, then the qubit-based curves
        r = trotter_rows[order]
        axes[0].loglog(
            steps,
            r[-1, 1] * (steps / steps[-1]) ** -float(order),
            ":" if order == 1 else "-.",
            color="0.5",
            lw=1,
            label=f"ideal slope $-{order}$",
        )
    for order, color in order_colors.items():
        r = trotter_rows[order]
        axes[0].loglog(
            r[:, 0],
            r[:, 1],
            "o-",
            color=color,
            label=f"bosonic, order {order} (fitted slope {fitted_slope(r):.2f})",
        )
    for (order, ordering), rows in (qubit_rows or {}).items():
        label, color, style = curve_style(order, ordering)
        axes[0].loglog(
            rows[:, 0],
            rows[:, 1],
            style,
            color=color,
            lw=1,
            mew=1.5,
            label=label,
        )
    axes[0].set(
        xlabel=f"Trotter steps up to $T = {t_final:g}$",
        ylabel="error against the exact state",
        title="Trotter error, $4\\times4$ Néel quench",
    )
    axes[0].grid(axis="y")
    axes[0].legend(fontsize=7, loc="lower left")
    plain_log_ticks(axes[0], [int(n) for n in steps], "x")
    for order, color in order_colors.items():
        axes[1].loglog(
            depths[order],
            trotter_rows[order][:, 1],
            "o-",
            color=color,
            label=f"bosonic, order {order}",
        )
        for n, x, y in zip(steps, depths[order], trotter_rows[order][:, 1]):
            axes[1].annotate(
                f"{int(n)}",
                (x, y),
                fontsize=7,
                color=color,
                xytext=(4, 4),
                textcoords="offset points",
            )
    for (order, ordering), rows in (qubit_rows or {}).items():
        label, color, style = curve_style(order, ordering)
        axes[1].loglog(
            qubit_depths[order, ordering],
            rows[:, 1],
            style,
            color=color,
            lw=1,
            mew=1.5,
            label=label,
        )
    axes[1].set(
        xlabel="two-qubit depth of the whole circuit (abstract register)",
        ylabel="max density error",
        title="error versus cost (labels: Trotter steps)",
    )
    axes[1].grid(axis="y")
    axes[1].legend(fontsize=7)
    plt.close(figure)
    return figure

def square_bonds(lx, ly):
    """Nearest-neighbor bonds (i, j) of an open lx x ly lattice, site s = lx * y + x."""
    bonds = []
    for y in range(ly):
        for x in range(lx):
            s = lx * y + x
            if x + 1 < lx:
                bonds.append((s, s + 1))
            if y + 1 < ly:
                bonds.append((s, s + lx))
    return bonds

def hardcore_dense(num_sites, bonds, tunneling=1.0):
    """Hard-core hopping as a matrix on bit strings: a boson hops when exactly one of the two sites is occupied."""
    dim = 2**num_sites
    h = np.zeros((dim, dim))
    for state in range(dim):
        for i, j in bonds:
            if ((state >> i) & 1) != ((state >> j) & 1):
                h[state ^ (1 << i) ^ (1 << j), state] += -tunneling
    return h

def free_fermion_matrix(num_sites, bonds, tunneling=1.0):
    """Free fermions on the same bonds, as a qubit matrix from qiskit-fermions' Jordan-Wigner mapper."""
    terms = {}
    for i, j in bonds:
        terms[(f_cre(i), f_ann(j))] = -tunneling
        terms[(f_cre(j), f_ann(i))] = -tunneling
    return (
        jordan_wigner(FermionOperator.from_dict(terms), num_sites)
        .simplify()
        .to_matrix()
    )

def spectrum_gap(num_sites, bonds):
    """Largest difference between the hard-core and the free-fermion eigenvalues over all particle-number sectors."""
    boson, fermion = (
        hardcore_dense(num_sites, bonds),
        free_fermion_matrix(num_sites, bonds),
    )
    popcount = np.array([bin(s).count("1") for s in range(2**num_sites)])
    gap = 0.0
    for n in range(1, num_sites):
        keep = popcount == n
        gap = max(
            gap,
            np.abs(
                np.linalg.eigvalsh(boson[np.ix_(keep, keep)])
                - np.linalg.eigvalsh(fermion[np.ix_(keep, keep)])
            ).max(),
        )
    return gap, bool(np.allclose(boson, fermion))

def hardcore(lx, ly, tunneling=1.0):
    """Hard-core hopping on an open lx x ly lattice, grouped by edge color. Returns (operator, {bond: color})."""
    color_of = {
        (i, j): (i % lx) % 2 if j == i + 1 else 2 + (i // lx) % 2

def exact_hamiltonian(num_sites, bonds, tunneling=1.0):
    states = np.arange(2**num_sites, dtype=np.int64)
    rows, cols = [], []
    for i, j in bonds:
        differs = ((states >> i) & 1) != ((states >> j) & 1)
        source = states[differs]
        rows.append(source ^ ((1 << i) | (1 << j)))
        cols.append(source)
    rows, cols = np.concatenate(rows), np.concatenate(cols)
    return sp.csr_matrix(
        (np.full(len(rows), -tunneling), (rows, cols)),
        shape=(len(states),) * 2,
    )

def basis_state(bits):
    vector = np.zeros(2 ** len(bits), dtype=complex)
    vector[sum(b << i for i, b in enumerate(bits))] = 1.0
    return vector

def site_densities(state, num_sites):
    probabilities = np.abs(state) ** 2
    states = np.arange(len(state))
    return np.array(
        [
            probabilities[(states >> i) & 1 == 1].sum()
            for i in range(num_sites)
        ]
    )

def imbalance(density, lx, ly):
    sign = np.array([(-1) ** (x + y) for y in range(ly) for x in range(lx)])
    return float(np.mean(sign * (2 * density - 1)))

    step = to_qubits(
        bosonic_circuit(
            HARDCORE, dt, BosonicSuzukiTrotter(order=order, reps=1)

4. วัดปริมาณ Trotter error​

ข้อผิดพลาดเชิงตัวเลขเพียงอย่างเดียวของ circuit คือ Trotter error ระหว่างสี ที่ระดับ bosonic ส่วนอีกสองจุดที่ข้อผิดพลาดอาจแทรกเข้ามาได้นั้นแม่นยำโดยโครงสร้างอยู่แล้ว

  • ฝั่ง qubit เทอม Pauli ของสีเดียวกันสับเปลี่ยนกันได้ เพราะพันธะ (bond) ของสีเดียวกันไม่ใช้ไซต์ร่วมกัน การสังเคราะห์แต่ละสีจึงไม่ต้องใช้การประมาณเพิ่มเติม และ circuit คือผลคูณตามลำดับของเลขชี้กำลังของแต่ละสีที่แม่นยำ

  • การเข้ารหัส (encoding) ที่ d=2d = 2d=2 LevelEncoding ทั้งสี่แบบเป็นตัวแทนที่ต่างกันของระบบสองระดับเดียวกัน จึงให้ circuit เดียวกันจนถึงต้นทุน (หัวข้อ 5)

ไม่มีข้อผิดพลาดจาก "การตัด (truncation)" เช่นกัน เพราะค่าตัดขาด d=2d = 2d=2 กำหนด โมเดลนี้ (หัวข้อ 1) ไม่ใช่การประมาณเชิงตัวเลขของสิ่งที่ใหญ่กว่า

หัวข้อนี้สำรวจ BosonicSuzukiTrotter โดยวัด Trotter error เทียบกับค่าอ้างอิงที่แน่นอนจากหัวข้อ 3 ที่เวลาสุดท้ายหนึ่งค่าคือ T=2T = 2T=2 เทียบกับจำนวน step สำหรับอันดับหนึ่งและอันดับสอง ที่ใช้ T=2T = 2T=2 ไม่ใช่ปลายของเส้นโค้งด้านบนก็โดยเจตนา เพราะเมื่อถึง t=3t = 3t=3 สัญญาณสลายไปใกล้ค่าระยะยาวแล้ว ข้อผิดพลาดตรงนั้นจึงเล็กและกระจายไปมาตามจำนวน step แต่ที่ T=2T = 2T=2 พลวัตยังชัดเจนอยู่

def xx_yy_operator(lx, ly, by_color=True):
    """The qubit operator of the hard-core lattice, as plain Pauli terms: -1/2 (XX + YY) per bond, sorted by edge color or not."""
    color_of = hardcore(lx, ly)[1]
    bonds = (
        sorted(color_of, key=lambda bond: (color_of[bond], bond))
        if by_color
        else list(color_of)
    )
    terms = [
        (pauli, [i, j], -0.5) for i, j in bonds for pauli in ("XX", "YY")
    ]
    return SparsePauliOp.from_sparse_list(terms, num_qubits=lx * ly)

def single_gate(operator, order, time_=T_FINAL, steps=1, **formula):

    circuit = QuantumCircuit(operator.num_qubits)
    circuit.append(
        PauliEvolutionGate(operator, time=time_, synthesis=synthesis),
        circuit.qubits,
    )
    return circuit

def bose_hubbard(num_sites, tunneling=1.0, interaction=2.0):
    """Grouped Bose-Hubbard Hamiltonian on an open chain: group 0 = even bonds, 1 = odd bonds, 2 = on-site."""
    edges = [(i, i + 1) for i in range(num_sites - 1)]
    terms = {}
    for i, j in edges:
        terms[(cre(i), ann(j))] = -tunneling
        terms[(cre(j), ann(i))] = -tunneling
    for i in range(num_sites):
        terms[(cre(i), cre(i), ann(i), ann(i))] = 0.5 * interaction
    operator = BosonOperator.from_dict(terms)

    def group_of(actions):
        creations = sorted(m for a, m in actions if a)
        annihilations = sorted(m for a, m in actions if not a)
        if creations == annihilations:
            return 2
        return (
            edges.index(tuple(sorted(set(creations) | set(annihilations))))
            % 2
        )

    raw = [group_of(actions) for actions, _ in operator.iter_terms()]
    remap = {g: i for i, g in enumerate(sorted(set(raw)))}
    operator.groups = [remap[g] for g in raw]
    return operator

จากตัวเลขเหล่านี้ คุณสามารถสรุปประเด็นสำคัญระดับสูงได้บางข้อ ข้อแรกๆ เกี่ยวกับเฟรมเวิร์ก ซึ่งคือสิ่งที่คุณนำไปใช้กับโมเดล bosonic อื่นได้ ข้อหลังๆ เกี่ยวกับสิ่งที่ผลลัพธ์แสดงสำหรับ hard-core boson ซึ่งเป็นกรณีทดสอบแบบง่าย

  • เฟรมเวิร์กสำหรับฟิสิกส์ bosonic qiskit-bosons แยกสามสิ่งออกจากกัน คือโมเดล (BosonOperator ซึ่งจัดกลุ่มที่นี่ตามสีของขอบ) circuit (gate Evolution หนึ่งตัวและสูตร Trotter ที่แยกมัน) และการลดระดับลงเป็น qubit (การตัดโหมด ddd และ LevelEncoding ที่เลือกเมื่อ transpiler preset ทำงาน) การเปลี่ยนหนึ่งในนั้นไม่กระทบอีกสองอย่าง (หัวข้อ 2 และ 7)

  • ทำไมต้อง Trotterize ที่ระดับ bosonic การจัดกลุ่มอยู่ในตัวดำเนินการ circuit แบบ Trotter จึงได้ความลึกคงที่โดยไม่ต้องจัดลำดับด้วยมือ PauliEvolutionGate ตัวเดียวบนตัวดำเนินการระดับ qubit เดียวกันมีอันดับและการสเกลของ Trotter error เท่ากัน และเมื่อเรียงเทอมตามสีก็เป็น circuit ที่เหมือนกันทุกประการ ในลำดับอื่น ความลึกเพิ่มตามแลตทิซ (84 เทียบกับ 8 สำหรับหนึ่ง step อันดับหนึ่งที่ 10×1210\times1210×12) หรือจำนวน gate สูงขึ้นประมาณหนึ่งในสาม (หัวข้อ 4 และ 5)

  • ความแม่นยำ ข้อผิดพลาดเชิงตัวเลขเพียงอย่างเดียวคือ Trotter error ระหว่างสี และลดลงตามจำนวน step ตามที่คาดสำหรับอันดับหนึ่งและสอง (หัวข้อ 4) ฝั่ง qubit และการเข้ารหัสไม่เพิ่มอะไร

  • การเข้ารหัสคือการเลือกต้นทุน ที่ d=2d = 2d=2 การเข้ารหัสทั้งสี่แบบให้ฟิสิกส์เดียวกัน รหัสแบบกะทัดรัดใช้ qubit เพียงครึ่งเดียวและถูกกว่ารหัส unary ประมาณ 20 เท่าทั้งในความลึกและจำนวน gate (หัวข้อ 5)

  • ฮาร์ดแวร์ ด้วยการฝังแลตทิซแบบธรรมชาติ ทุก gate อยู่บน coupler ของ Nighthawk อยู่แล้ว ชิปจึงรัน circuit โดยไม่มีภาระ routing ในทุกขนาดจนถึงทั้งชิป (หัวข้อ 6)

  • Hard-core boson คือจุดเริ่มต้น ไม่ใช่เป้าหมาย มันคือลิมิต U→∞U\to\inftyU→∞ ของ Bose-Hubbard โดยมีโมเดล XY เป็นสิ่งเทียบเท่าแบบ spin-1/2 มันเป็น free fermion พอดีบนสายโซ่เปิดแต่ไม่ใช่บนแลตทิซสี่เหลี่ยม ซึ่งทำให้ 2D เป็นกรณีที่น่าสนใจ (หัวข้อ 1) การเพิ่มการตัดเป็น d=3d = 3d=3 นำอันตรกิริยา on-site กลับมาและต้นทุนพุ่งขึ้น (สายโซ่ 4 ไซต์เพิ่มจากความลึก two-qubit 4 เป็น 95 ในรหัส Gray หัวข้อ 7) นั่นคือจุดที่การสำรวจฟิสิกส์ bosonic เริ่มต้น และเฟรมเวิร์กเดียวกันรองรับได้ ข้อควรระวัง ความลึกทั้งหมดเป็นของ fake backend ที่ไม่มีสัญญาณรบกวน (FakeNighthawk) และ basis คงที่หนึ่งชุด (cz, rz, sx, x ระดับ optimization 3) ซึ่งเปรียบเทียบโครงสร้าง ไม่ใช่ความเที่ยงตรง (fidelity) ตัวเลขที่ route แล้วเท่ากับตัวเลขนามธรรมก็เพราะการฝังแบบธรรมชาติวางทุก gate บน coupler เท่านั้น Néel quench เป็นสถานะเริ่มต้นเพียงหนึ่งเดียว Trotter error ขึ้นกับสถานะและ TTT ไม่มีอะไรในที่นี้รันบนฮาร์ดแวร์จริง

ขั้นตอนถัดไป Hard-core boson เป็นโมเดลที่ง่ายและตรวจสอบได้สำหรับเรียนรู้เฟรมเวิร์ก จากตรงนี้ องค์ประกอบเดียวกันใช้ได้กับโมเดลที่ยากจะจัดการแบบคลาสสิก

  • ค่าตัดขาด ddd ที่ใหญ่ขึ้น (soft-core boson โมเดล Bose-Hubbard เต็มรูปแบบ) ซึ่งการเลือกการเข้ารหัสและสูตร Trotter สำคัญกว่าที่นี่มาก (หัวข้อ 7)

  • Hamiltonian อื่นๆ เช่น boson ที่มีอันตรกิริยาต่างออกไปหรือการคัปปลิงกับสิ่งแวดล้อมต่างออกไป

  • แลตทิซอื่นๆ เช่นสามเหลี่ยมหรือรังผึ้ง (honeycomb) ซึ่งต้องการการระบายสีขอบและการฝังฮาร์ดแวร์แบบอื่น
