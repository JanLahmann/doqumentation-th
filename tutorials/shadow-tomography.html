Shadow tomography ของสถานะ Greenberger-Horne-Zeilinger

ประมาณการการใช้งาน: ไม่ถึง 10 วินาทีบนโปรเซสเซอร์ Heron r2 (หมายเหตุ: นี่เป็นเพียงค่าประมาณ เวลารันจริงของคุณอาจแตกต่างไป)

ผลลัพธ์การเรียนรู้​

  • shadow tomography สร้าง classical shadow ของสถานะควอนตัมได้อย่างไร และทำไมจึงต้องใช้การวัดน้อยกว่า full state tomography แบบเอกซ์โพเนนเชียล

  • วิธีทำ local Pauli shadow tomography โดยใช้ Qiskit เพื่อประมาณค่าแมกเนไทเซชันของคิวบิตเดี่ยว, correlator สองจุด และ reduced density matrix ของสองคิวบิต

  • วิธีใช้ qiskit-paulice สำหรับการตรวจจับ error แบบ overhead ต่ำโดยใช้ spacetime code ในการทดลองฮาร์ดแวร์ขนาดใหญ่

ความรู้พื้นฐานที่ต้องมี​

  • การวัด

  • Quantum state tomography

  • การตรวจจับ error โดยใช้ spacetime code

ความเป็นมา​

Full quantum state tomography ของระบบ NNN คิวบิตต้องใช้การวัดจำนวนมากแบบเอกซ์โพเนนเชียลเพื่อประมาณพารามิเตอร์อิสระทั้งหมด 4N−14^N -14N−1 ตัวของ density matrix ตัวอย่างเช่น สำหรับระบบ 50 คิวบิต กระบวนการนี้ต้องใช้ shot ในระดับ 103010^{30}1030 ซึ่งมากกว่าจำนวนดาวฤกษ์ในเอกภพที่สังเกตได้มากกว่าพันล้านเท่า Shadow tomography [1] เป็นโปรโตคอลสารสนเทศควอนตัมที่สร้าง “classical shadow” ของสถานะควอนตัม ซึ่งใช้ประมาณค่า observable เป้าหมายได้ด้วยจำนวน shot ที่เพิ่มขึ้นเป็นลอการิทึมตามจำนวน observable และไม่ขึ้นกับขนาดระบบ NNN ทำให้เกี่ยวข้องกับหลายสาขาในการคำนวณควอนตัม เช่น การประมาณพลังงาน เอนโทรปีของ entanglement และการคำนวณฟังก์ชันสหสัมพันธ์ การประมาณ kernel ใน quantum machine learning และอื่นๆ

บทเรียนนี้แสดงวิธีใช้ shadow tomography เพื่อประมาณ observable เฉพาะที่ เช่น แมกเนไทเซชันของคิวบิตเดี่ยว ⟨Zi⟩\langle Z_i \rangle⟨Zi​⟩ สำหรับคิวบิต iii, ฟังก์ชันสหสัมพันธ์สองจุด ⟨ZiZj⟩\langle Z_i Z_j\rangle⟨Zi​Zj​⟩ และ reduced density matrix ของสองคิวบิต (2-RDM) ของสถานะ Greenberger-Horne-Zeilinger (GHZ) ที่พัวพันกันสูง บทเรียนเริ่มด้วยการแสดง workflow ของ shadow tomography ขนาดเล็กบนสถานะ GHZ 10 คิวบิตโดยใช้การจำลอง statevector จากนั้นแสดงการสาธิต 100 คิวบิตบนฮาร์ดแวร์ควอนตัมจริง

คำศัพท์ที่ใช้ในตารางมีความหมายดังนี้:

  • "sample complexity" หมายถึงจำนวนการวัดที่ต้องใช้สำหรับ shadow tomography รูปแบบนั้นๆ

  • "ความลึกของ circuit" อธิบายว่าการวัดมีค่าใช้จ่ายสูงเพียงใดในการทำบนฮาร์ดแวร์ควอนตัม

  • NNN คือจำนวนคิวบิต

  • kkk คือความเป็นเฉพาะที่ (locality) ของ observable (เช่น ⟨Zi⟩\langle Z_i \rangle⟨Zi​⟩ มี k=1k=1k=1 และ ⟨ZiZj⟩\langle Z_i Z_j\rangle⟨Zi​Zj​⟩ มี k=2k=2k=2)

  • MMM คือจำนวน observable ที่ต้องการประมาณพร้อมกัน

  • ε\varepsilonε คือค่าความคลาดเคลื่อนแบบบวกที่ยอมรับได้

  • μ\muμ คือจำนวนเฟอร์มิออน

แม้ local Pauli ensemble จะเหมาะกับฮาร์ดแวร์ที่สุด แต่ก็ต้องจ่ายค่าปรับ sample complexity เป็น 3k3^k3k ทำให้ไม่เหมาะกับการประมาณคุณสมบัติที่ไม่เฉพาะที่ โดยทั่วไปแล้ว ขอบเขต sample complexity ของ local shadow เพิ่มตาม 4k4^k4k และดีขึ้นเป็น 3k3^k3k ในกรณีพิเศษของ observable แบบ tensor-product

ในทางกลับกัน แม้ global Clifford ensemble จะใช้ประมาณ observable ที่ไม่เฉพาะที่ได้ แต่ความลึกของ circuit ไม่เอื้ออำนวย Fermionic Gaussian shadow มีประโยชน์ในการจำลองฟิสิกส์หลายวัตถุ เคมี และวัสดุ แต่ต้องใช้ matchgate circuit ซึ่งอาจมี overhead สูงบนอุปกรณ์แบบ gate ทั่วไป

Shallow shadows มีความลึกของ circuit อยู่ระหว่าง local Pauli และ global Clifford ทำให้เป็นรูปแบบที่น่าสนใจมากสำหรับการใช้งานจริง แม้ยังมีคำถามเปิดบางข้อเกี่ยวกับความลึกของ circuit ที่เหมาะสมที่สุดสำหรับ observable หนึ่งๆ

ขณะที่แนวหน้าของงานวิจัย shadow tomography ขยายตัวต่อไป ปัญหาที่เกี่ยวข้องที่สุดบางข้อที่ต้องแก้ ได้แก่ การเลือก measurement ensemble ที่เหมาะสมที่สุดสำหรับชุด observable เป้าหมาย การปรับปรุงขอบเขต sample complexity และการขยายโปรโตคอลไปยัง observable ที่วิวัฒน์ตามเวลา อย่างไรก็ตาม shadow tomography ยังคงเป็นหนึ่งใน workflow ชั้นนำสำหรับดึงข้อมูลคลาสสิกสูงสุดจากสถานะควอนตัมโดยใช้การวัดน้อยที่สุด ซึ่งทำให้เหมาะอย่างยิ่งสำหรับการระบุลักษณะของสถานะควอนตัมในสเกลที่ทั้ง full tomography และการจำลองแบบคลาสสิกเป็นไปไม่ได้

Local Pauli ensemble​

บทเรียนนี้ใช้ basis แบบ Pauli สุ่ม หรือก็คือ Clifford gate คิวบิตเดี่ยว เพื่อเก็บ shadow และประมาณคุณสมบัติของสถานะ GHZ โปรดทราบว่าการวัดแบบ Pauli เป็นตัวเลือกที่ยอดเยี่ยมสำหรับการประมาณ observable เฉพาะที่ (เช่น ความหนาแน่นสปิน ฟังก์ชันสหสัมพันธ์เฉพาะที่ และความหนาแน่นความน่าจะเป็นของตำแหน่ง) แต่ไม่เหมาะกับ observable ระดับโลก (เช่น พลังงานรวม โมเมนตัม และประจุ)

ที่นี่ จะสุ่มเลือก basis แบบ Pauli {X,Y,Z}\{X, Y, Z\}{X,Y,Z} ต่อคิวบิตอย่างเป็นอิสระต่อกัน แล้วใช้การหมุนคิวบิตเดี่ยวที่สอดคล้องกัน ตามด้วยการวัด:

U=U0⊗U1⊗⋯⊗Un−1,Uq∈{I,H,S†H}(1) \begin{equation} U = U_0 \otimes U_1 \otimes \cdots \otimes U_{n-1}, U_q \in \{I, H, S^{\dagger}H\} \end{equation} \tag{1} U=U0​⊗U1​⊗⋯⊗Un−1​,Uq​∈{I,H,S†H}​(1)

สำหรับ ensemble นี้ ตัวผกผันของ measurement channel คือ:

ρ^q=3Uq†∣bq⟩⟨bq∣Uq−I(2) \begin{equation} \hat{\rho}_q=3U_q^{\dagger}\ket{b_q}\bra{b_q}U_q - I \end{equation} \tag{2}ρ^​q​=3Uq†​∣bq​⟩⟨bq​∣Uq​−I​(2)

ตัวคูณ 333 มาจากการเฉลี่ยบน basis แบบ Pauli ทั้งสาม ซึ่งให้ depolarizing channel ที่มีพารามิเตอร์ 13\frac{1}{3}31​ จากนั้น estimator เต็มรูปจะแยกตัวประกอบเป็นผลคูณของ estimator คิวบิตเดี่ยว ดังที่แสดงในตาราง สำหรับ observable MMM ตัว แต่ละตัวมี locality kkk จำนวน Pauli shadow ที่ต้องใช้เพื่อประมาณ observable ทั้งหมดให้ได้ความคลาดเคลื่อนแบบบวก ε\varepsilonε ด้วยความน่าจะเป็นสูงคือ O(3klog(M)ε2)\mathcal{O}(\frac{3^k\text{log}(M)}{\varepsilon^2})O(ε23klog(M)​) ขนาดของระบบไม่มีผลต่อต้นทุนการวัด ตราบใดที่ observable ยังเป็นเฉพาะที่ ดังนั้นจึงประมาณ observable จำนวนมากแบบเอกซ์โพเนนเชียลพร้อมกันได้ด้วยต้นทุนเพียงระดับลอการิทึม

Median of means​

ค่าเฉลี่ยธรรมดาบน snapshot TTT ตัวลดความแปรปรวนของค่าประมาณ observable จากการวัดครั้งเดียวเป็น 1T\frac{1}{T}T1​ แต่ไวต่อค่านอกเกณฑ์ (outlier) สามารถใช้ median of means เพื่อแก้ปัญหานี้ได้ กระบวนการประกอบด้วย:

  • แบ่ง snapshot TTT ตัวออกเป็น KKK กลุ่มขนาดเท่ากัน
  • คำนวณค่าเฉลี่ยภายในแต่ละกลุ่ม
  • คืนค่ามัธยฐานของค่าเฉลี่ยของกลุ่มทั้งหมด

def bad_cz(target, threshold: float = 0.01) -> list:
    "Return edges whose CZ error exceeds threshold."
    edges = []
    for edge in backend.target.build_coupling_map().get_edges():
        if (edge[1], edge[0]) not in edges:
            edges.append(edge)
    cz_errors = {edge: target["cz"][edge].error for edge in edges}
    worst = sorted(cz_errors.items(), key=lambda x: x[1], reverse=True)
    return [list(edge) for edge, error in worst if error > threshold]

def bad_readout(target, threshold: float = 0.01) -> list:
    "Return nodes whose measurement error exceeds threshold."
    meas_errors = {
        node: target["measure"][(node,)].error
        for node in range(backend.num_qubits)
    }
    worst = sorted(meas_errors.items(), key=lambda x: x[1], reverse=True)
    return [node for node, error in worst if error > threshold]

def bad_coherence(target, threshold: float = 60) -> list:
    "Return nodes whose T2 value is below threshold."
    t2s = {
        node: (target.qubit_properties[node].t2 or 0) * 1e6
        for node in range(backend.num_qubits)
    }
    return [
        node
        for node, val in sorted(t2s.items(), key=lambda x: x[1])
        if val < threshold
    ]

def parallel_ghz(
    root: int, num_qubits: int, backend, bad_edges: list, skip: list
) -> tuple:
    "Build a GHZ circuit of size num_qubits using BFS from root, one neighbor per layer."
    edges = [
        e
        for e in [list(e) for e in backend.coupling_map.get_edges()]
        if e not in bad_edges
        and [e[1], e[0]] not in bad_edges
        and e[0] not in skip
        and e[1] not in skip
    ]
    adj = defaultdict(list)
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)

    qc = QuantumCircuit(backend.num_qubits)
    visited = [root]
    queue = deque([root])
    explored = defaultdict(set)
    layers = []
    qc.h(root)

    while queue and len(visited) < num_qubits:
        layer = []
        for node in list(queue):
            queue.popleft()
            unvisited = [
                nb
                for nb in adj[node]
                if nb not in visited and nb not in explored[node]
            ]
            if unvisited:
                nb = unvisited[0]
                visited.append(nb)
                queue.append(node)
                queue.append(nb)
                explored[node].add(nb)
                layer.append((node, nb))
                if len(visited) == num_qubits:
                    break
        if layer:
            layers.append(layer)
        else:
            break

    for layer in layers:
        for q1, q2 in layer:
            qc.cx(q1, q2)
        qc.barrier()

    return qc, visited, layers

def weighted_coverage(
    layers: list, parities: list, w_idle: float = 0.2, w_gate: float = 0.8
) -> float:
    "Compute weighted fraction of wires covered by at least one parity check."
    wires = active_wires(layers)
    covered_by_any = {n_layer: set() for n_layer in range(len(layers))}
    for parity in parities:
        for n_layer, qs in z_trace_backward(layers, parity).items():
            covered_by_any[n_layer] |= qs
    covered_weight = total_weight = 0
    for n_layer in range(len(layers)):
        idle = wires[n_layer]["idle"]
        gate = wires[n_layer]["gate"]
        total_weight += w_idle * len(idle) + w_gate * len(gate)
        covered_weight += w_idle * len(
            covered_by_any[n_layer] & idle
        ) + w_gate * len(covered_by_any[n_layer] & gate)
    return covered_weight / total_weight if total_weight > 0 else 0

def active_wires(layers: list) -> dict:
    """
    Returns per-layer dict with two sets:
    - 'idle': activated wires that are idle in this layer
    - 'gate': activated wires that are control/target of a CNOT at this layer
    """
    first_activation = {}
    for n_layer, layer in enumerate(layers):
        for c, t in layer:
            first_activation.setdefault(c, n_layer)
            first_activation.setdefault(t, n_layer)
    result = {}
    for n_layer in range(len(layers)):
        active = {
            q
            for q, n_layer0 in first_activation.items()
            if n_layer >= n_layer0
        }
        gate = {q for c, t in layers[n_layer] for q in (c, t)}
        result[n_layer] = {"idle": active - gate, "gate": gate}
    return result

def z_trace_backward(layers: list, initial_Zs: list) -> dict:
    """
    Backward propagate Zs with parity cancellation.
    Returns {layer: set of qubits with odd parity Z at that layer}.
    """
    wires = active_wires(layers)
    support = set(initial_Zs)
    trace = {}
    for n_layer in range(len(layers) - 1, -1, -1):
        active = wires[n_layer]["idle"] | wires[n_layer]["gate"]
        trace[n_layer] = support & active
        new_support = set()
        for q in support:
            hit = False
            for c, t in layers[n_layer]:
                if q == t:
                    new_support ^= {t, c}
                    hit = True
                    break
                elif q == c:
                    new_support ^= {c}
                    hit = True
                    break
            if not hit:
                new_support ^= {q}
        support = new_support
    return trace

def add_measurements(
    qc: QuantumCircuit, ghz_qubits: list, checks: list
) -> QuantumCircuit:
    "Add GHZ and check qubit measurements into separate classical registers."
    c1 = ClassicalRegister(len(ghz_qubits), "c1")
    qc.add_register(c1)
    for q, c in zip(ghz_qubits, c1):
        qc.measure(q, c)
    c2 = ClassicalRegister(len(checks), "c2")
    qc.add_register(c2)
    for q, c in zip(checks, c2):
        qc.measure(q, c)
    return qc

def build_shadow_circuits(
    base_circuit: QuantumCircuit,
    n_measure: int,
    ghz_qubits: list,
    checks: list,
) -> tuple:
    "Build n_measure circuits by appending random Pauli basis rotations to each GHZ qubit."
    n = base_circuit.num_qubits
    all_bases = rng.integers(0, 3, size=(n_measure, n))
    circuits = []
    for m in range(n_measure):
        qc = base_circuit.copy()
        qc.barrier()
        for q in ghz_qubits:
            b = all_bases[m, q]
            if b == 1:
                qc.h(q)
            elif b == 2:
                qc.sdg(q)
                qc.h(q)
        add_measurements(qc, ghz_qubits, checks)
        circuits.append(qc)
    return circuits, all_bases

def parse_hw_results_w_checks(
    result, bases: np.ndarray, ghz_qubits: list, checks: list
) -> list:
    "Parse hardware bitstrings into (ghz_bits, check_bits, bases) triples."
    snapshots = []
    n_ghz = len(ghz_qubits)
    n_checks = len(checks)
    for t, pub_result in enumerate(result):
        ghz_strings = (
            pub_result.data.c1.get_bitstrings()
        )  # one entry per shot
        chk_strings = pub_result.data.c2.get_bitstrings()
        for ghz_bitstring, check_bitstring in zip(ghz_strings, chk_strings):
            ghz_bits = [
                int(ghz_bitstring[n_ghz - 1 - i]) for i in range(n_ghz)
            ]
            check_bits = [
                int(check_bitstring[n_checks - 1 - i])
                for i in range(n_checks)
            ]
            snapshots.append((ghz_bits, check_bits, bases[t]))
    return snapshots

def adapt_to_flat_bits(
    ghz_bits: list, ghz_qubits: list, n_total: int
) -> list:
    "Map GHZ-register bits back to a full n_total-length bit vector."
    bits = [0] * n_total
    for i, q in enumerate(ghz_qubits):
        bits[q] = ghz_bits[i]
    return bits

def estimate_zz_nn_hw(
    snapshots: list, ghz_qubits: list, n_total: int, n_groups: int
) -> np.ndarray:
    "Estimate <ZiZi+1> for each neighboring GHZ qubit pair from flat-bit snapshots."
    pairs = list(zip(ghz_qubits[:-1], ghz_qubits[1:]))
    all_est = np.column_stack(
        [
            snapshot_estimate(
                ["Z" if q in pair else "I" for q in range(n_total)], snapshots
            )
            for pair in pairs
        ]
    )
    return mom(all_est, n_groups).real

    """0 -> Z basis (I), 1 -> X basis (H), 2 -> Y basis (Sdg;H)."""

        qc.h(0)
    elif b == 2:

    return qc

def collect_shadow_snapshots(psi, n_snapshots, num_qubits):
    snapshots = []
    for _ in range(n_snapshots):
        bases = rng.integers(0, 3, size=num_qubits)
        rot = QuantumCircuit(num_qubits)
        for q, b in enumerate(bases):
            rot.compose(_basis[b], qubits=[q], inplace=True)
        evolved = psi.evolve(rot)
        evolved.seed(int(rng.integers(0, 2**31)))
        bitstr = next(
            iter(evolved.sample_counts(shots=1))
        )  # Born rule internal
        bits = [int(x) for x in bitstr[::-1]]  # little-endian -> qubit
        snapshots.append((bits, bases))
    return snapshots

def shadow_estimator(P, b, bit):  # P is a label char, e.g. "X"
    UPU = _U[b] @ _P[P] @ _U[b].adjoint()  # Uᵢ P Uᵢ†
    return (3 * UPU.data[bit, bit] - np.trace(_P[P].data)).real

def mom(estimates: np.ndarray, n_groups: int) -> np.ndarray:
    "Median-of-means outlier suppression."
    T = len(estimates)
    spg = T // n_groups  # shots per group
    trimmed = estimates[
        : spg * n_groups
    ]  # drop any leftover shots that don't cleanly fit into a group
    groups = trimmed.reshape(n_groups, spg, *estimates.shape[1:])
    means = groups.mean(axis=1)  # take the mean of each group
    return np.median(means.real, axis=0) + 1j * np.median(
        means.imag, axis=0
    )  # take the median of means for real and imaginary parts separately

def snapshot_estimate(
    pauli_string, snapshots
):  # full-width label, len == num_qubits
    out = np.empty(len(snapshots), dtype=complex)
    for t, (bits, bases) in enumerate(snapshots):
        e = 1.0 + 0j
        for q, P in enumerate(pauli_string):
            e *= shadow_estimator(P, bases[q], bits[q])
        out[t] = e
    return out

ในบทเรียนนี้ใช้ snapshot 5,000 ตัวเพื่อประมาณ observable เราประเมินการสเกลตามจำนวน shot ของ shadow tomography โดยพล็อตค่าความคลาดเคลื่อนเฉลี่ยของฟังก์ชันที่ประมาณได้ตัวหนึ่งเทียบกับงบจำนวน shot ที่ต่างกัน ความคลาดเคลื่อนของตัวสัมพันธ์สอง Qubit ลดลงตาม 1/T1/\sqrt{T}1/T​ ซึ่งเป็นไปตามที่คาดไว้สำหรับการลู่เข้าทางสถิติมาตรฐานของ mean estimator ความสำคัญของ shadow tomography คือสัมประสิทธิ์คงที่ที่คูณหน้า 1/T1/\sqrt{T}1/T​ ไม่เพิ่มขึ้นตามจำนวน Qubit สำหรับ observable เชิงท้องถิ่น เช่นที่ตรวจสอบในบทเรียนนี้

ตัวอย่างบนฮาร์ดแวร์ขนาดใหญ่​

การจำลองก่อนหน้านี้ยืนยันว่า local Pauli shadow tomography กู้คืน observable ที่ถูกต้องได้บน statevector ที่ไม่มีสัญญาณรบกวน การรันโปรโตคอลเดียวกันด้วย 100 Qubit บนฮาร์ดแวร์จริงทำให้เกิดความท้าทายสองข้อที่ไม่ปรากฏในการจำลอง คือ ข้อผิดพลาดของ Gate และการอ่านค่าสะสมไปตามวงจร GHZ ที่ลึก และการหา layout ของ Qubit ที่เหมาะสมที่สุดต้องค้นหาในกราฟการเชื่อมต่อของอุปกรณ์ แทนที่จะเลือก layout ด้วยมือ

เพื่อรับมือกับความท้าทายข้อแรก ให้ใช้การตรวจจับข้อผิดพลาดแบบ low-overhead ด้วย spacetime codes [6] โดยใช้ ancilla Qubit จำนวนเล็กน้อยที่อยู่ติดกับต้นไม้ GHZ เป็น parity check ancilla แต่ละตัวถูกพันกับเพื่อนบ้าน GHZ สองตัวก่อนการวัด ดังนั้นข้อผิดพลาดแบบ bit-flip เพียงครั้งเดียวที่เพื่อนบ้านตัวใดตัวหนึ่งจะพลิกผลลัพธ์ของ ancilla จาก 0 เป็น 1 snapshot ที่ check ancilla ตัวใดอ่านได้ 1 จะถูกทิ้ง เหลือชุดย่อยที่สะอาดกว่าสำหรับใช้ประมาณ ⟨ZiZi+1⟩\langle Z_i Z_{i+1}\rangle⟨Zi​Zi+1​⟩

ความท้าทายข้อที่สองจัดการโดยการค้นหา layout ของต้นไม้ GHZ ที่เป็นตัวเลือก แล้วเลือกอันที่ทำให้ parity-check coverage สูงสุด คือสัดส่วนของสายใน Circuit ที่ถูกตรวจสอบโดย check อย่างน้อยหนึ่งตัว ภายใต้การเพิ่มขึ้นของความลึกของ Circuit ที่ยอมรับได้

ขั้นตอนที่ 1-4 (ทำในโค้ดบล็อกเดียว)​

ตอนนี้นำเวิร์กโฟลว์สี่ขั้นตอนเดียวกันไปใช้กับสถานะ GHZ 100 Qubit บนฮาร์ดแวร์ควอนตัมจริง โดยเพิ่มคุณสมบัติเฉพาะฮาร์ดแวร์สองอย่างที่ไม่เกิดขึ้นในการจำลอง

  • ขั้นตอนที่ 1 ระบุลักษณะสัญญาณรบกวนของ Backend (ข้อผิดพลาดของ Gate ข้อผิดพลาดในการอ่านค่า และเวลา T2) เพื่อตัด Qubit และเอจที่ไม่น่าเชื่อถือออกจาก layout ของ Circuit

  • ขั้นตอนที่ 2 ค้นหา layout ของต้นไม้ GHZ ที่เป็นไปได้ เพื่อหาอันที่ทำให้ parity-check coverage สูงสุดภายในความลึกของ Circuit ที่ยอมรับได้ แทนที่โซ่แบบง่ายที่ใช้ในการจำลอง

  • ขั้นตอนที่ 3 สร้าง shadow circuit (หนึ่งวงจรต่อหนึ่งฐาน Pauli แบบสุ่ม) ทรานสไพล์เป็น Gate เนทีฟของฮาร์ดแวร์ และส่งไปยังพริมิทีฟ Sampler ด้วย shots=8 (แต่ละ Circuit สร้าง bitstring อิสระแปดตัว)

  • ขั้นตอนที่ 4 เลือก snapshot ที่ check qubit ทั้งหมดอ่านได้ 0 (ตรวจไม่พบข้อผิดพลาด) ด้วย postselection จากนั้นประมาณ ⟨ZiZi+1⟩\langle Z_i Z_{i+1}\rangle⟨Zi​Zi+1​⟩ ทั้งแบบมีและไม่มี postselection เพื่อแสดงให้เห็นว่าการตรวจจับข้อผิดพลาดช่วยปรับปรุงผลได้

backend = service.least_busy(
    operational=True, simulator=False, min_num_qubits=133
)
coupling_map = backend.target.build_coupling_map()
n_total = backend.num_qubits

bad_edges = bad_cz(backend.target, threshold=thresh_cz)
bad_nodes_readout = bad_readout(backend.target, threshold=thresh_meas)
dead_qubits = bad_readout(backend.target, threshold=0.4)
bad_nodes = list(
    set(bad_nodes_readout)
    | set(bad_coherence(backend.target, threshold=thresh_t2))
)

# ── Step 2: Optimize for quantum hardware execution ───────────────────────────
# Search over starting qubits and random node-skip sets to find the GHZ layout
# with the best parity-check coverage within an acceptable circuit depth.
ghz_size = 100
max_skips, shuffles, max_depth_increase = 10, 200, 10
w_idle, w_gate = 0.2, 0.8

# Find the root that yields the shallowest GHZ — exclude bad_nodes from the start
best_root = None
base_depth = float("inf")
for root in range(backend.num_qubits):
    if root in bad_nodes:
        continue
    qc, ghz_qubits, _ = parallel_ghz(
        root, ghz_size, backend, bad_edges, bad_nodes
    )
    if len(ghz_qubits) != ghz_size:
        continue
    depth = qc.depth(lambda x: x.operation.num_qubits == 2)
    if depth < base_depth:
        best_root, base_depth = root, depth
if best_root is None:
    raise Exception(
        "No qualifying GHZ root layout found. Relax error thresholds."
    )

qc, ghz_qubits, layers = parallel_ghz(
    best_root, ghz_size, backend, bad_edges, bad_nodes
)

degree_two_nodes = [
    i
    for i in ghz_qubits
    if all(n in ghz_qubits for n in coupling_map.neighbors(i))
    and len(coupling_map.neighbors(i)) >= 2
]

best_covered_fraction = -1
best_qc = best_checks = best_parities = best_layers = best_ghz_qubits = None

for num_skips in range(max_skips):
    for _ in range(shuffles):
        skip_trial = list(
            rng.choice(degree_two_nodes, num_skips, replace=False)
        )
        qc, ghz_qubits, layers = parallel_ghz(
            best_root, ghz_size, backend, bad_edges, skip_trial + bad_nodes
        )
        if len(ghz_qubits) != ghz_size:
            continue
        depth = qc.depth(lambda x: x.operation.num_qubits == 2)
        checks, parities = [], []
        for ancilla, neighbors in get_low_overhead_ancillas(
            coupling_map, ghz_qubits
        ).items():
            if ancilla in dead_qubits:
                continue
            good_neighbors = [
                n
                for n in neighbors
                if [ancilla, n] not in bad_edges
                and [n, ancilla] not in bad_edges
            ]
            if len(good_neighbors) < 2:
                continue
            checks.append(ancilla)
            parities.append((good_neighbors[0], good_neighbors[1]))
            qc.cx(good_neighbors[0], ancilla)
            qc.cx(good_neighbors[1], ancilla)
        covered_fraction = weighted_coverage(
            layers=layers, parities=parities, w_idle=w_idle, w_gate=w_gate
        )
        if (
            covered_fraction > best_covered_fraction
            and depth <= base_depth + max_depth_increase
        ):
            best_covered_fraction = covered_fraction
            (
                best_qc,
                best_ghz_qubits,
                best_checks,
                best_parities,
                best_layers,
            ) = qc, ghz_qubits, checks, parities, layers
