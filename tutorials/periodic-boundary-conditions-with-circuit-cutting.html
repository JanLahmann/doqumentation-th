Circuit cutting สำหรับเงื่อนไขขอบเขตเป็นคาบ

ประมาณการใช้งาน: 2 นาทีบน ibm_boston (หมายเหตุ: นี่เป็นเพียงการประมาณเท่านั้น เวลาจริงอาจแตกต่างกัน)

ผลลัพธ์การเรียนรู้​

  • ใช้การเชื่อมต่อเสมือนเพื่อ transpile โซ่แบบคาบโดยไม่ต้องกำหนดเส้นทางให้เกตที่ขอบเขต

  • แทนที่เกตเหล่านั้นด้วยการทดลอง circuit-cutting และสร้างค่าคาดหมายขึ้นใหม่จากผลลัพธ์ของ Sampler

  • เปรียบเทียบวงจรที่ตัดและไม่ตัด โดยพิจารณาความลึกของวงจรและต้นทุนการสุ่มตัวอย่าง

ความรู้พื้นฐานที่ต้องมี​

คุณควรคุ้นเคยกับ Qiskit patterns, transpilation และ Sampler primitive

พื้นฐาน​

เงื่อนไขขอบเขตเป็นคาบเชื่อมคิวบิตสุดท้ายในโซ่เข้ากับตัวแรก ถ้าคิวบิตเหล่านี้อยู่ไกลกันบนโปรเซสเซอร์ควอนตัม การทำปฏิสัมพันธ์ของมันต้องมีการกำหนดเส้นทาง ซึ่งอาจเพิ่มเกตสองคิวบิตและเพิ่มความลึกของวงจร

Gate cutting แทนที่เกตสองคิวบิตด้วยผลรวมถ่วงน้ำหนักของการดำเนินการคิวบิตเดี่ยวและการวัด การรันการทดลองเหล่านี้และรวมผลลัพธ์จะสร้างค่าคาดหมายของวงจรต้นฉบับขึ้นใหม่ วิธีนี้ลดค่าโสหุ้ยการกำหนดเส้นทางได้ โดยแลกกับการสุ่มตัวอย่างเพิ่มเติม ดู circuit cutting explanation สำหรับการแยกส่วนแบบ quasiprobability ที่อยู่เบื้องหลัง

ก่อนอื่นคุณจะตรวจสอบเวิร์กโฟลว์นี้บนซิมูเลเตอร์ไร้สัญญาณรบกวนหกคิวบิต จากนั้นนำไปใช้กับโซ่อย่างน้อย 30 คิวบิตบนฮาร์ดแวร์ และเปรียบเทียบผลที่ตัดและไม่ตัด วงจรใช้พารามิเตอร์ที่ทราบค่าคาดหมายเชิงวิเคราะห์ ดังนั้นการเปรียบเทียบบนฮาร์ดแวร์จึงไม่ต้องใช้การจำลอง statevector ขนาดใหญ่

ตัวอย่างซิมูเลเตอร์ขนาดเล็ก​

ใช้วงแหวนหกคิวบิตที่มีเกตเอนแทงเกิลสองชั้น อุปกรณ์จำลองมีการเชื่อมต่อแบบเส้นตรง ดังนั้นเส้นปิดของวงแหวนจึงต้องมีการกำหนดเส้นทาง เว้นแต่จะถูกตัด

ขั้นตอนที่ 1: แมปอินพุต classical ไปยังปัญหา quantum​

ฟังก์ชันต่อไปนี้สร้างชั้นการหมุน RX สลับกับเกต CX บนเส้นเชื่อมสลับกันของวงแหวน การทำซ้ำสองครั้งให้เกตขอบเขตสองตัวที่ต้องตัด ตั้งสองชั้นการหมุนแรกเป็นศูนย์ และชั้นสุดท้ายเป็น π\piπ ผลลัพธ์ในอุดมคติจึงเป็น ∣1⟩⊗n|1\rangle^{\otimes n}∣1⟩⊗n จนถึงเฟสรวม

วัดค่าคาดหมาย Z คิวบิตเดี่ยวเฉลี่ยและค่าคาดหมาย ZZ ของคู่ที่อยู่ติดกันเฉลี่ย รวมคู่แบบคาบ:

MZ=1n∑i=0n−1⟨Zi⟩,CZZ=1n∑i=0n−1⟨ZiZ(i+1) mod n⟩.M_Z = \frac{1}{n}\sum_{i=0}^{n-1}\langle Z_i\rangle, \qquad C_{ZZ} = \frac{1}{n}\sum_{i=0}^{n-1}\langle Z_i Z_{(i+1)\bmod n}\rangle.MZ​=n1​i=0∑n−1​⟨Zi​⟩,CZZ​=n1​i=0∑n−1​⟨Zi​Z(i+1)modn​⟩.

ค่าในอุดมคติของมันคือ −1-1−1 และ +1+1+1 ตามลำดับ พารามิเตอร์เหล่านี้เป็นเกณฑ์วัดสำหรับเวิร์กโฟลว์ แต่ไม่ได้แสดงการคำนวณที่ยากสำหรับคลาสสิก

def build_periodic_problem(num_qubits, num_reps=2):
    """Build a periodic benchmark circuit and its Z and ZZ observables."""
    edges = [(i, (i + 1) % num_qubits) for i in range(num_qubits)]
    circuit = n_local(
        num_qubits,
        rotation_blocks="rx",
        entanglement_blocks="cx",
        entanglement=edges[::2] + edges[1::2],
        reps=num_reps,
    )
    parameters = np.zeros(circuit.num_parameters)
    parameters[-num_qubits:] = np.pi
    circuit = circuit.assign_parameters(parameters)

    terms = [("Z", [i], 1) for i in range(num_qubits)]
    terms += [("ZZ", [i, (i + 1) % num_qubits], 1) for i in range(num_qubits)]
    observables = SparsePauliOp.from_sparse_list(terms, num_qubits)
    return circuit, observables

num_qubits = 6
circuit, observables = build_periodic_problem(num_qubits)
ideal_expvals = np.array(
    [
        Statevector(circuit).expectation_value(p).real
        for p in observables.paulis
    ]
)
print("Ideal averages:", ideal_expvals.reshape(2, num_qubits).mean(axis=1))
circuit.draw("mpl", style="iqp", fold=60)

เพิ่ม virtual connection ระหว่าง physical qubit ที่ปลายทั้งสองของ chain ทำ Transpile หนึ่งครั้งโดยใช้ coupling map ที่ขยายนี้และ basis แบบ CX virtual connection ช่วยไม่ให้ Transpiler ต้อง route Gate ที่ขอบ แต่ Circuit ที่ได้ยังรันบนอุปกรณ์จริงไม่ได้

ค้นหาและตัด CX Gate ที่ขอบสองตัว ใช้ virtual layout กับ observable และสร้างพจน์การแยกส่วนทั้งหมดด้วย num_samples=np.inf ซึ่งทำให้สัมประสิทธิ์การแยกส่วนแม่นยำเป๊ะ แต่การวัดยังคงใช้จำนวน shot จำกัด

สุดท้าย แปลงการทดลองให้เป็น Gate เนทีฟของอุปกรณ์ และแก้ทิศทางของ Gate ตามที่จำเป็น pass เหล่านี้คงการจัดวาง physical qubit ไว้ และไม่ต้องเลือก layout กับ routing ซ้ำสำหรับทุกการทดลอง helper จะคืนค่า observable ที่แมปแล้วซึ่งต้องใช้ในการสร้างผลลัพธ์กลับ

def prepare_cut_experiments(circuit, observables, backend, initial_layout):
    """Compile with a virtual edge, cut it, and translate to native gates."""
    boundary = {initial_layout[0], initial_layout[-1]}
    virtual_map = CouplingMap(list(backend.coupling_map.get_edges()))
    virtual_map.make_symmetric()
    virtual_map.add_edge(initial_layout[-1], initial_layout[0])
    virtual_map.add_edge(initial_layout[0], initial_layout[-1])

    virtual_pm = generate_preset_pass_manager(
        optimization_level=1,
        coupling_map=virtual_map,
        basis_gates=["rz", "sx", "x", "cx"],
        initial_layout=initial_layout,
        seed_transpiler=1234,
    )
    virtual_circuit = virtual_pm.run(circuit)
    cut_indices = [
        i
        for i, instruction in enumerate(virtual_circuit.data)
        if instruction.operation.name == "cx"
        and {virtual_circuit.find_bit(q).index for q in instruction.qubits}
        == boundary
    ]
    mapped_observables = observables.apply_layout(virtual_circuit.layout)
    qpd_circuit, bases = cut_gates(virtual_circuit, cut_indices)
    experiments, coefficients = generate_cutting_experiments(
        circuits=qpd_circuit,
        observables=mapped_observables.paulis,
        num_samples=np.inf,
    )
    native_pm = PassManager(
        [
            BasisTranslator(
                SessionEquivalenceLibrary,
                target_basis=backend.operation_names,
                target=backend.target,
            ),
            GateDirection(backend.coupling_map, target=backend.target),
            BasisTranslator(
                SessionEquivalenceLibrary,
                target_basis=backend.operation_names,
                target=backend.target,
            ),
            Optimize1qGatesDecomposition(target=backend.target),
        ]
    )
    isa_experiments = native_pm.run(experiments)
    print(f"Boundary gates cut: {len(cut_indices)}")
    print(f"Number of experiments: {len(isa_experiments)}")
    print(
        f"Sampling overhead: {np.prod([basis.overhead for basis in bases])}"
    )
    return isa_experiments, coefficients, mapped_observables

isa_experiments, coefficients, mapped_observables = prepare_cut_experiments(
    circuit, observables, simulation_backend, initial_layout
)

เพื่อเปรียบเทียบ ให้ Transpile สำเนาของ Circuit ที่ไม่ได้ตัดซึ่งมีการวัด โดยใช้ coupling map จริง measure_all() จะบันทึก logical qubit ดั้งเดิมไว้ใน register meas การ Transpile คงการแมป classical bit นั้นไว้ ดังนั้นสามารถประเมินผล counts ด้วย observable ดั้งเดิมได้

ขั้นตอนที่ 4: Post-process และแสดงผลลัพธ์ในรูปแบบ classical ที่ต้องการ​

สร้างค่าคาดหวังของ Pauli แต่ละตัวกลับโดยใช้ observable ที่แมปแล้วชุดเดียวกันและลำดับการทดลองเดียวกับตอนสร้าง จากนั้นหาค่าเฉลี่ยของ nnn ค่าแรกสำหรับ MZM_ZMZ​ และ nnn ค่าที่เหลือสำหรับ CZZC_{ZZ}CZZ​ สำหรับ Circuit ที่ไม่ได้ตัด ให้คำนวณค่าคาดหวังจาก counts ที่วัดได้โดยตรง

cut_expvals = reconstruct_expectation_values(

def compare_results(cut_expvals, uncut_expvals, num_qubits):
    """Display average Z and periodic ZZ values against the ideal values."""
    cut_averages = np.asarray(cut_expvals).reshape(2, num_qubits).mean(axis=1)
    uncut_averages = (
        np.asarray(uncut_expvals).reshape(2, num_qubits).mean(axis=1)
    )
    print("Cut averages (Z, ZZ):", cut_averages)
    print("Uncut averages (Z, ZZ):", uncut_averages)
    print("Absolute cut errors:", np.abs(cut_averages - [-1, 1]))
    print("Absolute uncut errors:", np.abs(uncut_averages - [-1, 1]))

    fig, ax = plt.subplots(figsize=(7, 4))
    positions = np.arange(2)
    for offset, values, label, color in [
        (-0.25, [-1, 1], "Ideal", "#4589ff"),
        (0, cut_averages, "Cut", "#a56eff"),
        (0.25, uncut_averages, "Uncut", "#009d9a"),
    ]:
        ax.bar(
            positions + offset, values, width=0.25, label=label, color=color
        )

ผลลัพธ์แบบไม่มี noise ควรใกล้เคียงค่าในอุดมคติ การสร้างกลับด้วย shot จำกัดอาจแกว่งได้ และค่าประมาณที่สร้างกลับอาจอยู่นอกช่วง [−1,1][-1,1][−1,1] การตัดไม่ได้ช่วยปรับปรุงผลลัพธ์ที่ไม่มี noise อยู่แล้ว ตัวอย่างนี้ใช้ตรวจสอบการแยกส่วน การแมป layout และการสร้างกลับ ก่อนรันบนฮาร์ดแวร์

ตัวอย่างฮาร์ดแวร์ขนาดใหญ่​

ใช้เวิร์กโฟลว์ซ้ำบน QPU ที่พร้อมใช้งานและคิวน้อยที่สุดซึ่งมีอย่างน้อย 120 qubit เลือก shortest path ที่ยาวที่สุดใน coupling graph แบบไม่มีทิศทางของมัน: แต่ละคู่ที่อยู่ติดกันเชื่อมต่อกัน ขณะที่ปลายทั้งสองอยู่ห่างกัน วิธีนี้ปรับ chain ให้เข้ากับอุปกรณ์ที่เลือก แทนที่จะพึ่ง layout Eagle แบบตายตัว โค้ดจะตรวจสอบว่า chain มี qubit อย่างน้อย 30 ตัว และปลายทั้งสองไม่ได้เป็นเพื่อนบ้านกัน

บล็อกต่อไปนี้รวมสี่ขั้นตอนเข้าด้วยกัน Gate twirling, measurement twirling และ dynamical decoupling ถูกปิดทั้งสองเวอร์ชัน ทั้งสองงานรันใน batch เดียวกันและได้รับแท็กของบทเรียน TUT_CCPBC การทดลองที่ตัดยังคงใช้ shot รวมมากกว่า ดังนั้นให้เปรียบเทียบทั้งความแม่นยำและการใช้งาน QPU

คำแนะนำ

  • ลองดูการตัด Circuit เพื่อลด depth สำหรับอันตรกิริยาแบบไม่ท้องถิ่นอื่น ๆ

  • ลองwire cutting สำหรับการประมาณค่าคาดหวัง เพื่อแบ่ง Circuit เป็นระบบย่อยที่เล็กลง

  • อ่านเอกสารอธิบายเรื่อง circuit cutting เพื่อทำความเข้าใจ tradeoff ระหว่างการตัดกับ sampling overhead
