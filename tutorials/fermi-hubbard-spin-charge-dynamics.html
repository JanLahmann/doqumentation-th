พลวัตของสปินและประจุในโมเดล Fermi-Hubbard

ประมาณการการใช้งาน: 5 นาทีบนตัวประมวลผล Heron r3 (หมายเหตุ: เป็นเพียงการประมาณ เวลารันจริงของคุณอาจต่างออกไป)

ความเป็นมา​

โมเดล Fermi-Hubbard อธิบายอิเล็กตรอนที่กระโดดบนแลตทิซ โดยมีบทลงโทษด้านพลังงานเมื่อมีอิเล็กตรอนสองตัวอยู่ที่ไซต์เดียวกัน บนสายโซ่หนึ่งมิติที่มี LLL ไซต์และขอบเปิด Hamiltonian ถูกกำหนดดังนี้

H=−∑i=0L−2∑σ∈{↑,↓}th,i(ciσ†ci+1,σ+h.c.)+∑i=0L−1Ui ni↑ni↓−∑i=0L−1∑σμi niσ,H = -\sum_{i=0}^{L-2} \sum_{\sigma \in \{\uparrow,\downarrow\}} t_{h,i} \left( c^\dagger_{i\sigma} c_{i+1,\sigma} + \mathrm{h.c.} \right) + \sum_{i=0}^{L-1} U_i\, n_{i\uparrow} n_{i\downarrow} - \sum_{i=0}^{L-1} \sum_\sigma \mu_i\, n_{i\sigma},H=−i=0∑L−2​σ∈{↑,↓}∑​th,i​(ciσ†​ci+1,σ​+h.c.)+i=0∑L−1​Ui​ni↑​ni↓​−i=0∑L−1​σ∑​μi​niσ​,

โดยที่ ciσ†c^\dagger_{i\sigma}ciσ†​ สร้างเฟอร์มิออนที่มีสปิน σ\sigmaσ บนไซต์ iii และ niσ=ciσ†ciσn_{i\sigma} = c^\dagger_{i\sigma} c_{i\sigma}niσ​=ciσ†​ciσ​ นับจำนวนของมัน สามพจน์คือแอมพลิจูดการกระโดด th,it_{h,i}th,i​ บนพันธะระหว่างไซต์ iii และ i+1i+1i+1 อันตรกิริยาบนไซต์ UiU_iUi​ และศักย์เคมี μi\mu_iμi​ บทเรียนนี้วัดพลังงานในหน่วย tht_hth​ และเวลาในหน่วย 1/th1/t_h1/th​

พลวัตเรียลไทม์ของโมเดลนี้คำนวณด้วยวิธีคลาสสิกได้ยาก Exact diagonalization หยุดอยู่ราว L≲14L \lesssim 14L≲14 ไซต์ และหลัง quench เอนโทรปีของ entanglement ของ tensor-network solver จะโตเชิงเส้นตามเวลา ทำให้ bond dimension ที่ต้องใช้เพื่อความแม่นยำคงที่โตแบบเอกซ์โพเนนเชียล

ในหนึ่งมิติ การกระตุ้นพื้นฐานคือ spinon ซึ่งมีสปินแต่ไม่มีประจุ และ holon ซึ่งมีประจุแต่ไม่มีสปิน ทั้งสองแพร่ด้วยความเร็วต่างกัน ดังนั้นการรบกวนเฉพาะที่จึงแยกเป็น front เร็วและ front ช้า ปรากฏการณ์นี้เรียกว่า spin-charge separation และบทเรียนนี้วัดมัน [1]

บทเรียนนี้ใช้ Dynamics Simulator Qiskit Function ซึ่งรับ Hamiltonian สถานะเริ่มต้น ตาราง Trotter และรายการ observable แล้วส่งคืนค่าคาดหมาย มันจัดการ Jordan-Wigner mapping, Trotterization, ผัง qubit และการกดทอน error ภายในเอง จึงไม่มี circuit ให้สร้างหรือ transpile ในบทเรียนนี้

กำหนด Hamiltonian​

ฟังก์ชันรับโมเดลเป็น dictionary ที่มีสามคีย์ แต่ละคีย์รับได้ทั้ง float ค่าเดียวซึ่งใช้เท่ากันตลอดสายโซ่ หรือลิสต์ที่ระบุค่าทีละไซต์ ลิสต์มี L−1L-1L−1 รายการสำหรับ hopping_amplitude เพราะสายโซ่เปิดมีพันธะน้อยกว่าไซต์หนึ่งพันธะ และมี LLL รายการสำหรับ on_site_interaction และ chemical_potential

บทเรียนนี้ใช้สายโซ่สม่ำเสมอ 31 ไซต์ที่มีอันตรกิริยาแบบผลัก U/th=8U/t_h = 8U/th​=8 ศักย์เคมีที่สม่ำเสมอให้เพียงเฟสรวมเมื่อจำนวนอนุภาคคงที่ ตัวอย่างนี้จึงตั้งเป็นศูนย์ ศักย์เคมีมีความสำคัญเมื่อมันเปลี่ยนไปตามไซต์เท่านั้น เช่น เพื่อเพิ่ม disorder หรือสิ่งเจือปนเดี่ยว

ตั้งค่าตาราง Trotter​

dictionary simulation เก็บขนาดก้าวเวลา (Δt\Delta tΔt) และจำนวนก้าว Trotter โดยเวลาวิวัฒนาการรวมคือผลคูณของทั้งสอง ก้าวที่ใหญ่กว่าไปถึงเวลาที่ไกลกว่าที่ความลึก circuit คงที่ แต่เกิด Trotter error มากขึ้น ซึ่งโตตาม UUU เพราะพจน์ของ Hamiltonian สลับที่กันได้น้อยลง การศึกษาบนฮาร์ดแวร์ที่ตีพิมพ์ใช้ Δt=0.15\Delta t = 0.15Δt=0.15 สำหรับ U/th=8U/t_h = 8U/th​=8 [2] และบทเรียนนี้ใช้ค่าเดียวกัน ความลึก circuit โตเชิงเส้นตามจำนวนก้าวและไม่ขึ้นกับ LLL เลย

time_step = 0.15

เตรียมสถานะเริ่มต้น​

แต่ละไซต์มีสปินออร์บิทัลสองตัว ดังนั้นสายโซ่ LLL ไซต์ใช้ 2L2L2L qubit สถานะเริ่มต้นเป็นสตริงการครอบครองแบบ Fock ที่มีหนึ่งตัวอักษรต่อไซต์

empty (e)⟷(ni,↑,ni,↓)=(0,0),up (u)⟷(ni,↑,ni,↓)=(1,0),down (d)⟷(ni,↑,ni,↓)=(0,1),both (b)⟷(ni,↑,ni,↓)=(1,1).\begin{aligned} \texttt{empty (e)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,0), \\ \texttt{up (u)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,0), \\ \texttt{down (d)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (0,1), \\ \texttt{both (b)} &\longleftrightarrow \left(n_{i,\uparrow}, n_{i,\downarrow}\right) = (1,1). \end{aligned}empty (e)up (u)down (d)both (b)​⟷(ni,↑​,ni,↓​)=(0,0),⟷(ni,↑​,ni,↓​)=(1,0),⟷(ni,↑​,ni,↓​)=(0,1),⟷(ni,↑​,ni,↓​)=(1,1).​

สตริงถูกอ่านโดยเริ่มจากไซต์ที่มีนัยสำคัญน้อยที่สุด ดังนั้นตัวอักษรขวาสุดคือไซต์ 0 และดัชนีไซต์จริงของตัวอักษรที่ kkk นับจากซ้ายคือ i=L−1−ki = L - 1 - ki=L−1−k สตริง udud จึงหมายความว่าไซต์ 0 คือ d, ไซต์ 1 คือ u, ไซต์ 2 คือ d และไซต์ 3 คือ u

ถัดไป เตรียมสถานะ Néel แบบเติมครึ่ง สลับ u และ d โดยแทนไซต์กลางด้วยที่ว่าง ที่ว่างนี้คือการรบกวนที่เราติดตามการแผ่ขยายของมัน

สร้าง observable​

observable แต่ละตัวเป็น dictionary ที่แทนผลรวมถ่วงน้ำหนักของผลคูณของตัวดำเนินการการครอบครอง

O=∑αcα∏(σ,j)∈Tαnj,σ.O = \sum_{\alpha} c_{\alpha} \prod_{(\sigma, j) \in T_{\alpha}} n_{j,\sigma}.O=α∑​cα​(σ,j)∈Tα​∏​nj,σ​.

ทุกรายการของ operators คือหนึ่งพจน์ TαT_{\alpha}Tα​ เขียนเป็นลิสต์ของคู่ [name, site] ที่คูณกัน และรายการที่ตรงกันของ coefficients คือน้ำหนักของมัน ชื่อทั้งสองคือ "Nup" สำหรับ nj,↑n_{j,\uparrow}nj,↑​ และ "Ndn" สำหรับ nj,↓n_{j,\downarrow}nj,↓​ observable จุดเดียวหนึ่งตัว n3,↑n_{3,\uparrow}n3,↑​ เขียนได้ดังนี้

observables = []
charge_indices = []
spin_indices = []
correlator_indices = []

# Charge density: n_i = n_{i,up} + n_{i,down}
for site in range(site_count):
    charge_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [1.0, 1.0],
        }
    )

# Local spin: S^z_i = (n_{i,up} - n_{i,down}) / 2
for site in range(site_count):
    spin_indices.append(len(observables))
    observables.append(
        {
            "operators": [[["Nup", site]], [["Ndn", site]]],
            "coefficients": [0.5, -0.5],
        }
    )

# Spin correlator: S^z_i S^z_{i_*}, expanded into four two-point terms.
correlator_sites = [
    site for site in range(site_count) if site != vacancy_site

ดึงความเร็วของ wavefront​

แปลง heatmap เป็นตัวเลขโดยทำตามโปรโตคอลการตรวจจับจากงานวิจัยที่ตีพิมพ์ [2] ที่แต่ละช่วงเวลา ให้ทำให้โปรไฟล์เชิงพื้นที่สมมาตรรอบตำแหน่งที่ว่าง ซึ่งจะเฉลี่ยส่วนที่ไม่สมมาตรของสัญญาณรบกวนจากฮาร์ดแวร์ให้หายไป จากนั้น normalize ด้วยแอมพลิจูดนอกศูนย์กลางที่ใหญ่ที่สุด และบันทึกไซต์นอกสุดที่อยู่เหนือค่าขีดแบ่ง จากนั้นแบ่งการตรวจจับเป็นช่วงของ time step ที่ต่อเนื่องกัน และ fit เฉพาะช่วงที่ยาวที่สุด ซึ่งช่วยกันไม่ให้ transient ช่วงต้นปนเข้าไปในผลลัพธ์

def front_distance(profile, center, threshold):
    """Distance from `center` to the outermost site above a relative threshold."""
    values = np.nan_to_num(np.asarray(profile, dtype=float))
    length = values.size

    symmetrized = values.copy()
    for site in range(length):
        mirror = 2 * center - site
        if 0 <= mirror < length:
            symmetrized[site] = 0.5 * (values[site] + values[mirror])

    amplitude = np.abs(symmetrized)
    off_center = np.ones(length, dtype=bool)
    off_center[center] = False

    peak = amplitude[off_center].max()
    if peak <= 0.0:
        return np.nan
    above = np.flatnonzero((amplitude / peak > threshold) & off_center)
    return float(np.abs(above - center).max()) if above.size else np.nan

def longest_run(mask):
    """Indices of the longest run of consecutive True values."""
    best, current = [], []
    for index, keep in enumerate(mask):
        current = current + [index] if keep else []
        if len(current) > len(best):
            best = current
    return np.array(best, dtype=int)

def front_velocity(tracer, center, threshold=0.3, quantile=0.75, min_block=5):
    """Fit front position against time, using only the longest contiguous run."""
    distances = np.array(
        [
            front_distance(tracer[:, k], center, threshold)
            for k in range(tracer.shape[1])
        ]
    )
    edge = max(center, tracer.shape[0] - 1 - center)
    usable = (
        np.isfinite(distances) & (distances >= 2) & (distances <= edge - 2)
    )

    block = longest_run(usable)
    if block.size < min_block:
        return np.nan, distances, np.array([], dtype=int), np.nan

    candidates = [
        stats.theilslopes(distances[block[:k]], times[block[:k]]).slope
        for k in range(min_block, block.size + 1)
    ]
    cutoff = np.quantile(candidates, quantile)
    keep = max(i for i, value in enumerate(candidates) if value >= cutoff)

    fit_block = block[: keep + min_block]
    slope, intercept = np.polyfit(times[fit_block], distances[fit_block], 1)
    return float(slope), distances, fit_block, float(intercept)

ความเร็วที่ fit ได้ขึ้นกับค่าขีดแบ่งในการตรวจจับและ quantile ที่ใช้ตัดทอน และความไวนี้มีผลมากกว่า shot noise ให้สแกนทั้งสองค่าแล้วรายงานค่ามัธยฐานพร้อมช่วงครอบคลุมทั้งหมด เหมือนที่การวิเคราะห์ในงานวิจัยทำ

thresholds = [0.15, 0.225, 0.30, 0.375, 0.45]
quantiles = [0.60, 0.675, 0.75, 0.825, 0.90]

def velocity_envelope(tracer, center):
    """Median, minimum, and maximum velocity over the parameter scan."""
    values = [
        front_velocity(tracer, center, threshold=p, quantile=q)[0]
        for p in thresholds
        for q in quantiles
    ]
    values = np.array([v for v in values if np.isfinite(v)])
    if values.size == 0:
        return np.nan, np.nan, np.nan
    return float(np.median(values)), float(values.min()), float(values.max())

แนวหน้า charge วิ่งเร็วกว่าแนวหน้า spin โฮลในพื้นหลัง Mott หนึ่งมิติไม่ได้เคลื่อนที่เหมือนอิเล็กตรอน แต่จะแตกเป็น holon ที่พา charge กับ spinon ที่พาการรบกวนของ spin และที่ U/th=8U/t_h = 8U/th​=8 spinon เป็นตัวที่ช้ากว่า

ลำดับนี้ขึ้นกับอันตรกิริยา ที่ U=0U = 0U=0 โมเดลเป็นเฟอร์มิออนอิสระที่มี vc=2v_c = 2vc​=2 และ vs=4v_s = 4vs​=4 ดังนั้น spin เร็วกว่า แรงผลักทำให้การขนส่ง spin ถูกกดลงโดยแทบไม่แตะการขนส่ง charge และเมื่อถึง U/th=8U/t_h = 8U/th​=8 ค่าจากฮาร์ดแวร์ที่ตีพิมพ์คือ vc=1.78v_c = 1.78vc​=1.78 และ vs=1.46v_s = 1.46vs​=1.46 [2] การรันซ้ำด้วยค่า UUU หลายค่าแล้วพล็อต vs/vcv_s / v_cvs​/vc​ จะแสดงจุดตัดผ่านของลำดับนี้

ข้อควรระวังเกี่ยวกับตัวเลข การตรวจจับด้วยค่าขีดแบ่งมีความเอนเอียงต่ำลงเล็กน้อย จึงคาดได้ว่าความเร็ว charge จะต่ำกว่าค่าที่ตีพิมพ์ไม่กี่เปอร์เซ็นต์ ช่วงครอบคลุมของ spin กว้างเพราะ connected correlator อยู่ใกล้ noise floor มากกว่า นี่คือเหตุผลที่รายงานค่ามัธยฐานของการสแกนแทนการ fit ครั้งเดียว
