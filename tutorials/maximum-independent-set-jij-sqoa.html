แก้ปัญหา maximum independent set ที่มีตัวแปรมากกว่าจำนวน qubit ด้วย SQOA Solver ของ JIJ

หมายเหตุ

Qiskit Functions เป็นฟีเจอร์ทดลองที่ใช้ได้เฉพาะผู้ใช้ IBM Quantum® Premium Plan, Flex Plan และ On-Prem (ผ่าน IBM Quantum Platform API) Plan เท่านั้น อยู่ในสถานะ preview release และอาจเปลี่ยนแปลงได้

ประมาณการการใช้งาน: 10 วินาทีบนโปรเซสเซอร์ Heron r2 (หมายเหตุ: นี่เป็นเพียงค่าประมาณ รันไทม์จริงของคุณอาจต่างออกไป)

ภูมิหลัง​

บทช่วยสอนนี้แสดงวิธีใช้ SQOA Solver ซึ่งเป็น Qiskit Function โดย JIJ เพื่อแก้ปัญหา maximum independent set (MIS) ที่มีตัวแปรไบนารีมากกว่าจำนวน qubit ของ QPU ที่เลือก ขั้นตอนหลักคือโหลดอินสแตนซ์ MIS จาก Quantum Optimization Benchmarking Library (QOBLIB) [1] เขียนเป็นรูปแบบ quadratic unconstrained binary optimization (QUBO) ด้วย qiskit-addon-opt-mapper ส่งให้ SQOA Solver รันบน IBM® QPU และตรวจสอบคำตอบที่ได้กลับมา

ปัญหา maximum independent set​

independent set คือเซตย่อยของโหนดในกราฟที่ไม่มีโหนดสองตัวที่เลือกไว้ใช้ขอบร่วมกัน maximum independent set (MIS) คือ independent set ที่มีจำนวนโหนดมากที่สุดเท่าที่เป็นไปได้ การประยุกต์ใช้ MIS ได้แก่ การจัดตารางเวลา การจัดสรรทรัพยากร และการออกแบบเครือข่าย

MIS เป็นปัญหา NP-hard ในการค้นหาแบบทั่วถึง ทุกโหนดที่เพิ่มเข้ามาจะทำให้จำนวนเซตย่อยที่ต้องพิจารณาเพิ่มเป็นสองเท่า วิธีนี้จึงใช้ไม่ได้จริงแม้กับกราฟขนาดปานกลาง QOBLIB รวม MIS เป็นหนึ่งในสิบคลาสปัญหา จึงเป็นเบนช์มาร์กที่มีประโยชน์ในการประเมิน workflow การหาค่าเหมาะที่สุดเชิงควอนตัมบนฮาร์ดแวร์จริง

ทำไมต้องใช้ SQOA Solver?​

แนวทางการหาค่าเหมาะที่สุดเชิงควอนตัมหลายแบบกำหนดหนึ่ง qubit ต่อหนึ่งตัวแปรไบนารี ดังนั้นความจุของฮาร์ดแวร์ควอนตัมจึงจำกัดขนาดปัญหาโดยตรง SQOA Solver รวมเทคนิคการลดขนาดและการคำนวณแบบไฮบริดหลายอย่างเพื่อลดข้อจำกัดนี้:

  • รับมือกับปัญหาที่มีตัวแปรไบนารีมากกว่าจำนวน qubit ของ QPU ได้ Presolve ใช้กฎการลดขนาดที่ตรึงตัวแปรและทำให้ QUBO ที่เหลือง่ายขึ้น โดยยังคงคำตอบที่เหมาะที่สุดไว้อย่างน้อยหนึ่งคำตอบ จากการสังเกต presolve ยังทำให้ QUBO ที่เหลือเบาบางลงได้ ซึ่งช่วยการเข้ารหัสแบบ QRAC ที่ตามมา

    จากนั้น solver ใช้การเข้ารหัสแบบ QRAC ที่มาจาก Quantum Random Access Optimization (QRAO) [3] เพื่อแทนหลายตัวแปร (สูงสุดสามตัว) ที่ไม่มีอันตรกิริยา QUBO โดยตรงต่อกันบน qubit เดียวกัน

    การลดขนาดจาก presolve และการเข้ารหัสขึ้นกับโครงสร้างของปัญหา ตัวอย่างเช่น ในบทช่วยสอนนี้ ปัญหา 200 ตัวแปรใช้เพียง 67 qubit

  • อาจไวต่อสัญญาณรบกวนของฮาร์ดแวร์น้อยกว่า Sample-based quantum diagonalization [4], [5] ใช้ QPU สุ่มตัวอย่าง bitstring แต่ทำ diagonalization แบบคลาสสิก วิธีนี้หลีกเลี่ยงการประเมินบน QPU ซ้ำๆ เพื่ออัปเดตพารามิเตอร์แบบแปรผัน และช่วยลดผลกระทบของสัญญาณรบกวนต่อ workflow การหาค่าเหมาะที่สุด

  • ทำ workflow ตั้งแต่ presolve จนถึง post-processing โดยอัตโนมัติ คุณให้อินสแตนซ์ QUBO ที่จัดรูปแบบถูกต้องและเลือก backend จากนั้น SQOA Solver จะรัน workflow ทั้งหมดให้อัตโนมัติ โดยใช้ presolve, แมปตัวแปรคลาสสิกไปเป็นปัญหาควอนตัมแบบผ่อนคลาย, สร้างและ transpile วงจรสำหรับการสุ่มตัวอย่าง, ทำการสุ่มตัวอย่างเชิงควอนตัมและ diagonalization แบบคลาสสิก, ปัดเศษและปรับปรุงการกำหนดค่า และสร้างกลับพร้อมประเมินคำตอบแบบคลาสสิก

SQOA Solver รับปัญหา QUBO เป็นดิกชันนารีของสัมประสิทธิ์ในรูปแบบ tuple-string ที่ฟังก์ชันการหาค่าเหมาะที่สุดของ IBM® ใช้ กำหนดฟังก์ชันตัวช่วยที่แปลง QUBO ที่ OptimizationProblemToQubo คืนมาให้เป็นรูปแบบนี้

ตัวแปลงจะคืนปัญหา minimization เสมอ ซึ่งตรงกับวิธีที่ SQOA Solver จัดการปัญหาแบบดิกชันนารี คีย์ใช้ดัชนีตัวแปรของ QUBO และทุกตัวแปรจะมีรายการเชิงเส้น แม้สัมประสิทธิ์เป็นศูนย์ เพื่อให้คำตอบที่คืนมาครอบคลุมทุกตัวแปร

def to_problem_dict(qubo: OptimizationProblem) -> dict[str, float]:
    """Convert a QUBO from OptimizationProblemToQubo to the SQOA Solver dictionary format."""
    objective = qubo.objective
    payload = {"()": objective.constant}
    # Keep every variable in the problem, even with a zero linear coefficient.
    payload.update({f"({i},)": 0.0 for i in range(qubo.get_num_vars())})
    for i, coefficient in objective.linear.to_dict().items():
        payload[f"({i},)"] += coefficient
    for (i, j), coefficient in objective.quadratic.to_dict().items():
        # Fold a binary diagonal term x_i * x_i = x_i into the linear term.
        key = f"({i},)" if i == j else f"({i}, {j})"
        payload[key] = payload.get(key, 0.0) + coefficient
    return {key: float(value) for key, value in payload.items()}

  • เชื่อมต่อกับ SQOA Solver

  • ทำความเข้าใจเฟรมเวิร์ก SQOA

  • โหลดอินสแตนซ์ของปัญหา

  • เขียน QUBO และแปลงเพื่อส่ง

QOBLIB_URL = "https://raw.githubusercontent.com/ZIB-AOPT/QOBLIB/refs/heads/main/07-independentset"

def fetch_qoblib_graph(name: str) -> nx.Graph:
    """Download a QOBLIB independent-set instance as a NetworkX graph."""
    with urllib.request.urlopen(
        f"{QOBLIB_URL}/instances/{name}.gph"
    ) as response:
        lines = response.read().decode().splitlines()
    graph = nx.Graph()
    for fields in map(str.split, lines):
        if fields and fields[0] == "p":
            # Header: p edge <number of nodes> <number of edges>
            graph.add_nodes_from(range(int(fields[2])))
        elif fields and fields[0] == "e":
            # DIMACS labels nodes from 1; relabel them to start from 0.
            graph.add_edge(int(fields[1]) - 1, int(fields[2]) - 1)
    return graph

def fetch_reference_objective(name: str) -> float:
    """Read the objective value of the QOBLIB reference solution."""
    with urllib.request.urlopen(
        f"{QOBLIB_URL}/solutions/{name}.opt.sol"
    ) as response:
        for line in response.read().decode().splitlines():
            if line.startswith("# Objective value"):
                return float(line.split("=")[1])
    raise ValueError(f"No objective value found for {name}.")

เขียน QUBO​

สร้างสูตร binary linear จากส่วนภูมิหลังเป็น OptimizationProblem ที่มีหนึ่งตัวแปรไบนารีต่อโหนด ฟังก์ชันเป้าหมายที่นับโหนดที่เลือก และหนึ่งข้อจำกัดต่อขอบ จากนั้นแปลงด้วย OptimizationProblemToQubo

ด้วยน้ำหนักการลงโทษ 2 ตัวแปลงจะแทนที่ข้อจำกัดของแต่ละขอบด้วยเทอมลงโทษ 2xvxw2 x_v x_w2xv​xw​ และเปลี่ยน maximization เป็น minimization ดังนั้นปัญหาที่แปลงแล้วคือสูตร binary unconstrained ของ QOBLIB ที่กลับเครื่องหมาย ดัชนีตัวแปรของ QUBO คือป้ายโหนดของกราฟ คลาสแอปพลิเคชัน IndependentSet ใน qiskit_addon_opt_mapper.applications สร้างโมเดลที่มีข้อจำกัดแบบเดียวกันด้วย IndependentSet(G).to_optimization_problem()

สุดท้าย แปลง QUBO เป็นรูปแบบดิกชันนารีด้วย to_problem_dict() เนื่องจากปัญหาเป็น QUBO แบบไบนารี คำขอใน Step 2 จึงประกาศโดเมนตัวแปรเป็น "binary" ฟังก์ชันจะทำ presolve การแมปเชิงควอนตัม และการสร้างวงจรหลังส่ง

SQOA Solver ทำการแมปเชิงควอนตัมและการเตรียมฮาร์ดแวร์ภายในฟังก์ชัน ก่อนอื่นมันใช้ presolve กับ QUBO จากนั้นแมปตัวแปรที่เหลือไปเป็นแฮมิลโทเนียนแบบผ่อนคลายโดยใช้การเข้ารหัสแบบ QRAC

สำหรับการสุ่มตัวอย่างเชิงควอนตัม มันสร้างวงจรตามแฮมิลโทเนียนแบบผ่อนคลายและ transpile วงจรเหล่านั้นสำหรับ backend ที่เลือก การลดขนาดปัญหาและจำนวน qubit จาก presolve และการเข้ารหัสขึ้นกับปัญหา ดังนั้นให้ตั้งค่า solver โดยไม่สมมติตัวประกอบการลดขนาดที่คงที่

ตั้งค่าอินพุตของ solver​

SQOA Solver ต้องการอินพุตสองอย่าง:

  • problem คือดิกชันนารีจาก Step 1

  • variable_type ซึ่งเป็น "binary" สำหรับ QUBO นี้

มันยังรับอินพุตเสริมอีกสองอย่าง:

  • backend_name เลือก QPU เมื่อไม่ระบุหรือเป็น None ฟังก์ชันจะเลือก QPU ที่พร้อมใช้งานและว่างที่สุดที่อินสแตนซ์ของคุณเข้าถึงได้

  • options คือดิกชันนารีที่ควบคุมงบประมาณการสุ่มตัวอย่าง (shots) seed แบบคลาสสิก (seed) การใช้ session (session) การค้นหาเฉพาะที่แบบคลาสสิก (postprocessing_level) และแท็กของ job (job_tags) ถ้าเพิ่ม shots สถิติการสุ่มตัวอย่างอาจดีขึ้น

รวบรวมค่าที่คืนมาตามลำดับของดัชนีตัวแปร และแมปกลับไปยังตัวแปรของปัญหาเดิมด้วย interpret() โหนดที่เลือกคือตัวแปรที่มีค่า 1 และ is_feasible() ตรวจสอบการกำหนดค่าเทียบกับข้อจำกัดของขอบในปัญหาเดิม

x_qubo = [result["solution"][f"x_{i}"] for i in range(qubo.get_num_vars())]
x = converter.interpret(x_qubo)
selected_nodes = [node for node, value in enumerate(x) if value > 0.5]

เปรียบเทียบกับคำตอบก่อน post-processing​

เนื่องจาก postprocessing_level เป็น 1 solver_info จึงบันทึกการกำหนดค่าที่ปัดเศษแล้วจากก่อนการค้นหาเฉพาะที่แบบคลาสสิกไว้ใน solution_before_postprocessing ด้วย โดยใช้คีย์เดียวกับ solution

ประเมินมันบน QUBO เพื่อดูว่าการปรับปรุงทำให้ผลลัพธ์ดีขึ้นเท่าไร ทั้งสองค่าเป็นค่าฟังก์ชันเป้าหมายของ QUBO แบบ minimization ที่ส่งไป ดังนั้นค่าที่ต่ำกว่าดีกว่า ฟิลด์นี้จะถูกละไว้เมื่อการค้นหาเฉพาะที่ไม่ทำงาน เช่น เมื่อ presolve ตรึงทุกตัวแปรแล้ว

before = solver_info.get("solution_before_postprocessing")
if before is None:
    print("The classical local search did not run for this problem.")
else:
    x_before = [before[f"x_{i}"] for i in range(qubo.get_num_vars())]
    changed = sum(
        before[key] != value for key, value in result["solution"].items()
    )
    print(
        f"Objective before local search: {qubo.objective.evaluate(x_before)}"
    )
    print(f"Objective after local search: {result['objective_value']}")
    print(f"Variables changed by local search: {changed}")

ตรวจสอบข้อจำกัด independence​

เนื่องจาก QUBO แทนการอยู่ติดกันผ่านเทอมลงโทษแทนที่จะเป็นข้อจำกัดโดยตรง ผลลัพธ์แบบฮิวริสติกจึงอาจยังเลือกโหนดที่อยู่ติดกันได้ ตรวจสอบโหนดที่คืนมากับกราฟโดยตรง สำหรับการเปรียบเทียบและการแสดงภาพในส่วนถัดไป ให้คัดลอกเซตที่คืนมาและลบปลายหนึ่งข้างของแต่ละความขัดแย้งที่ตรวจพบแบบ greedy

returned_set = set(selected_nodes)
conflicts = [
    (u, v) for u, v in G.edges if u in returned_set and v in returned_set
]
print(f"Conflicting edges in the returned set: {len(conflicts)}")

independent_set = returned_set.copy()
for u, v in conflicts:
    if u in independent_set and v in independent_set:
        # Drop the endpoint that has more selected neighbors.
        drop = max(
            (u, v),
            key=lambda node: sum(nb in independent_set for nb in G[node]),
        )
        independent_set.remove(drop)

assert all(
    not (u in independent_set and v in independent_set) for u, v in G.edges
)
print(f"Independent set size after repair: {len(independent_set)}")
Conflicting edges in the returned set: 0
Independent set size after repair: 35

ใน Step 1 คุณดาวน์โหลดค่าฟังก์ชันเป้าหมายของคำตอบอ้างอิงของ QOBLIB คำตอบอ้างอิงของ QOBLIB อาจเป็นคำตอบที่เหมาะที่สุดหรือดีที่สุดเท่าที่ทราบ ดังนั้นให้เปรียบเทียบกับค่าฟังก์ชันเป้าหมายอ้างอิงโดยไม่สมมติว่าเป็นค่าเหมาะที่สุดที่ได้รับการรับรองเสมอไป

บทสรุป​

ในบทช่วยสอนนี้ คุณดาวน์โหลด MIS instance จาก QOBLIB, formulate เป็น QUBO ด้วย qiskit-addon-opt-mapper, เชื่อมต่อกับ SQOA Solver, ตั้งค่าและส่ง workload, แมปคำตอบที่ได้กลับไปยังกราฟ และตรวจสอบโหนดที่เลือกเทียบกับกราฟต้นฉบับ

คุณยังเปรียบเทียบผลลัพธ์กับคำตอบอ้างอิงของ QOBLIB, ตรวจสอบส่วนที่ classical post-processing มีส่วนช่วย และดูการใช้ทรัพยากรของแต่ละเฟสการรัน

SQOA Solver รวม presolve, QRAO ที่ใช้การเข้ารหัสแบบ QRAC, การสร้าง sampling circuit, hardware-aware transpilation, sample-based diagonalization, rounding และ classical refinement เข้าด้วยกัน เวิร์กโฟลว์นี้แมปตัวแปรไบนารีได้มากกว่าการเข้ารหัสแบบหนึ่งตัวแปรต่อหนึ่ง qubit ปริมาณที่ลดลงจาก presolve และการเข้ารหัสขึ้นอยู่กับโครงสร้างของปัญหา และคุณภาพของคำตอบขึ้นอยู่กับ sample ที่ได้

การตั้งค่า shots และ postprocessing_level ควบคุมงบ quantum sampling และ classical refinement ตามลำดับ โดยไม่เปลี่ยนเวิร์กโฟลว์การส่งงาน

ภาคผนวก: ส่งปัญหาเป็น OMMX instance​

SQOA Solver ยังรับ ommx.v1.Instance จาก OMMX SDK ด้วย แพ็กเกจ OMMX Quantum Benchmarks แจกจ่ายปัญหา QOBLIB เป็น OMMX instance พร้อมคำตอบอ้างอิง คุณจึงโหลด QUBO เดียวกันได้โดยไม่ต้อง formulate เอง

เมื่อใช้ OMMX เป็นอินพุต objective_value จะถูกประเมินตามความหมายของ instance และผลลัพธ์จะมี ommx.v1.Solution แบบ canonical ด้วย ติดตั้งแพ็กเกจ ซึ่งจะติดตั้ง OMMX SDK ด้วย:

# %pip install ommx-quantum-benchmarks

โหลดโมเดล binary_unconstrained ของ instance เดียวกัน ตัวโหลด dataset จะพิมพ์ข้อความแสดงความคืบหน้า โค้ดจึงดักจับข้อความเหล่านั้นไว้เพื่อให้เอาต์พุตกะทัดรัด

%%capture
from ommx_quantum_benchmarks.qoblib import IndependentSet

ommx_instance, _ = IndependentSet()("binary_unconstrained", INSTANCE_NAME)

SQOA Solver รับ OMMX instance เป็นสตริง Base64 แบบ padded มาตรฐาน และส่งคืนคำตอบ canonical ในรูปแบบเดียวกัน กำหนดฟังก์ชันช่วยสองตัวสำหรับการแปลงนี้:

  • to_problem_payload() แปลง ommx.v1.Instance เป็นสตริงที่คุณส่งเป็น problem

  • to_ommx_solution() ถอดรหัส ommx.v1.Solution แบบ canonical จากผลลัพธ์

import base64

from ommx.v1 import Instance, Solution

def to_problem_payload(instance: Instance) -> str:
    """Serialize an OMMX instance into the `problem` string for SQOA Solver."""
    return base64.b64encode(instance.to_bytes()).decode()

def to_ommx_solution(result: dict) -> Solution:
    """Decode the canonical OMMX solution from a SQOA Solver result."""
    payload = result["metadata"]["solver_info"]["ommx_solution"]
    return Solution.from_bytes(base64.b64decode(payload, validate=True))

ส่ง instance ด้วยอินพุตเดียวกับก่อนหน้า โดยเปลี่ยนเฉพาะ problem จากนั้นถอดรหัสคำตอบ canonical และอ่านโหนดที่เลือกตามชื่อตัวแปร

ommx_job = solver.run(
    **{**sqoa_input, "problem": to_problem_payload(ommx_instance)}
)
ommx_result = ommx_job.result()

ommx_solution = to_ommx_solution(ommx_result)
x_values = ommx_solution.extract_decision_variables("x")
ommx_nodes = sorted(
    node for (node,), value in x_values.items() if value > 0.5
)

print(f"Objective value: {ommx_result['objective_value']}")
print(f"Selected nodes: {len(ommx_nodes)}")

คำแนะนำ
  • นำเวิร์กโฟลว์นี้ไปใช้กับปัญหา QUBO ของคุณเอง สร้าง OptimizationProblem ตามที่แสดงในคู่มือ SQOA Solver ขั้นตอนการแปลงและการส่งงานเหมือนเดิม แต่ให้ปรับการตรวจสอบให้เหมาะกับโครงสร้างของปัญหาของคุณ

  • สำรวจ independent-set instance อื่นๆ ในที่เก็บ QOBLIB หรือผ่าน OMMX Quantum Benchmarks
  • เรียนรู้เพิ่มเติมเกี่ยวกับการสร้างโมเดลด้วย qiskit-addon-opt-mapper หรือ JijModeling และการแลกเปลี่ยนปัญหาด้วย OMMX
